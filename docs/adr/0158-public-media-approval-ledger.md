# ADR0158：公共媒体批准账本与可信观察分离

日期：2026-10-24。状态：采纳，V48-05工程增量。

公共媒体批准归现有Store唯一owner管理。单独SQL结构源定义空增量表，事务建表不替换已有业务记录；重启恢复在既有事务中撤销全部公共批准并留审计。批准与审计原子提交，显式撤销先写持久拒绝意图，审计失败不能恢复权限。工作区回收撤权，永久清理纳入既有业务清单与外键顺序。

批准须由本工作区Admin及本会话owner通过进程内root接口明确确认完整hash，绑定角色版本、会话epoch、不可变发布快照、完整来源闭包hash。最长30秒、每工作区最多200条未过期批准，无续期；实际媒体许可依旧最多500ms。数据库里的批准不能推导设备、许可或平台权限。存储权威适配器只填批准字段，公共权益、实际音画资源、输出支持及guard必须由独立可信root观察端口提供，缺失拒绝。

现有私有snapshot经来源有效性校验后只能作为被审阅内容的来源；额外的公共批准不改变原snapshot的private标记，不恢复其私有许可为公共许可。root仍须提供实际公共权限与守门依据。当前没有生产观察端口、公开批准IPC/UI、公共媒体数据通道或播放完成证据，因此本增量不开放公共播出，V48-05和164ACC状态不升级。

批准记录与权威适配器使用既有Protobuf bundle，新增的进程内Rust接口不跨进程，不引入自定义JSON控制协议或新的常驻依赖。
