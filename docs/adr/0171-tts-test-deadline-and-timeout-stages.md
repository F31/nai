# ADR 0171：TTS测试期限和等待阶段

2026-10-25，已采纳。用户实际模型测试返回超时，但旧码不能区分连接/服务等待/音频下载。本轮网络探针未复现连接故障，不能据此断言供应商/代理根因。

固定短句模型测试等待上限设为45秒，业务预演继续15秒；core提供各自常量，root按用途固定选择，监督期限随本次请求配置加250ms收尾，不接受网页任意设置。连接期限仍3秒，样本/字符/音频字节限制、媒体短租约和P0不变。45秒是本地等待策略，不是供应商SLA。

传输有限错误码区分CONNECT_TIMEOUT、CONNECTION_FAILED、RESPONSE_TIMEOUT、AUDIO_DOWNLOAD_TIMEOUT，持久化与UI白名单同步。HTTP成功头之后的音频体超时不伪装为正文生成超时；非成功HTTP已取得的状态不因错误体读取超时被丢弃。原始错误、Key、代理配置不回显，不重试。

仅使用无Key固定HEAD及本地服务测试。相同reqwest库自动系统代理/直连分别快速获得HTTP404，只证明该时点能收到HTTP响应，不能授POST合成、认证/余额或真实音画可用通过。详见[报告](../reports/2026-10-25-v48-05-tts-timeout-stages.md)。
