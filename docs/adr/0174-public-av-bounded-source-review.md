# ADR0174：固定短租约内的来源复核与公共音画验收

日期：2026-10-25；状态：采纳。

真实本地Qwen业务原文验收暴露了来源重复读取、串行待机心跳和固定追加等待对250ms观察/500ms执行租约的挤占。不得通过延长期限、复用失效批准或跳过事实校验解决。

存储新增PublicCandidateSource，持有单writer的独占借用与已验证来源。guard review消耗该值后归还Store；期间不能执行其他Store命令变更模型、角色、事实。review仍复检取消、StopFence代次、角色scope和当前文档闭包；后续执行/每轮续租仍重新走当前权威读取。相同authority.read内部只去掉重复的第二次source读取，不增加跨命令授权缓存。

宿主续租错误先清理执行和准备，再返回有限错误码，未知/畸形响应拒绝。验收工具独立维护待机健康，不以健康授执行权；按100ms目标周期扣除处理耗时。dev仅定向优化校验相关包，debug断言/溢出检查和所有期限不变。

本次真实2D/字幕/扬声器SDK提交与OBS应用音轨实录只证明选定组合单句链路。主观听感、硬件完成、长稳、其他形象/设备/平台仍需独立证据；164ACC不自动升级。
