# ADR 0170：模型设置测试不要求金额预留

2026-10-25，按用户明确要求采纳；限于模型设置内固定内容测试。

LLM测试采用FoundationModelTest，TTS测试移除金额字段并保留旧字段号不复用。测试不要求金额或费用勾选，不调用工作区预算准入、不创建新budget_reservations；不以隐藏默认0.01/0.10元模拟移除。独立身份/角色、模型版本与凭据、单飞、取消、期限、固定短句、256输出token及不重试仍执行。真实费用以供应商为准，测试不要求本地价格；request_started和供应商usage继续记录，但不声称未知费用为免费或已结算。

业务备稿和本句语音预演的费用/来源守门保持既有语义。本次不清理、释放或改写历史预算记录/用户模型和Key。工件Schema仅对测试解除reserved_minor必填并增加请求发送审计字段；现有业务字段不放宽。

错误分类共享于LLM/TTS传输，只检查最多4096字节错误JSON，不回显原文/认证头。402或明确余额不足证据提示余额不足，普通403不判欠费；401、404、429、5xx及期限/网络/格式分别反馈。持久任务只接受有限安全错误词表，未知原始错误归PROVIDER_FAILED。

本地HTTP、存储、跨语言与Windows原生测试只证明工程行为，未调用真实付费API，不授V48-05真实音画或任何ACC通过。详见[报告](../reports/2026-10-25-v48-05-one-click-model-tests.md)。
