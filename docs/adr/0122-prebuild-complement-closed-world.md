# ADR 0122：预构建处方的补集 —— 只判围栏内的行，只认 `--no-run`，历史按路径段排除

- 状态：已接受（W148，2026-10-18）
- 基线：`docs/直播数字人 + 智能体系统技术方案 V3.11.md`
- 相关：ADR 0121（W147 立了块内的双向对账，本 ADR 补的是它的补集）、
  `docs/engineering.md`（活文档，处方正文）、`scripts/contracts/gate-coverage.mjs`、
  `tests/contracts/gate-coverage.test.mjs`、`scripts/contracts/git-index.mjs`（W75，路径集来源）

## 背景

W147 的 `prebuildRecipeErrors()` 只判**标记块内**：文档每条命令 == 门控某条测试步 + 恰好一个
`--no-run`，且双向一一对应。它没有回答另一半问题——**块外还有没有第二份**。W147 报告 §八把
这个缺口具名登记为两条：

1. 块外的散文与围栏不受判据约束；
2. `testCommandsOf` 没有一条「不许被过滤」的守卫。

第 2 条本轮先量成数字。对 `testCommandsOf` 注入两种过滤形状，每次跑
`node --test tests/contracts/gate-coverage.test.mjs` 并逐字节还原（基线指纹
`41dcd8ba99cc7199487fccdb4b2c0eb61dd55f59b45aa329ce347d342c8e566b`）：

| 注入 | 结果 |
| --- | --- |
| 黑名单 `if (values.includes('--exclude')) continue;` | 25 pass / 6 fail |
| 白名单 `if (!values.includes('--locked')) continue;` | **31 pass / 0 fail** |

零信号不是「判据缺失」，而是**夹具是一致性样本**：那份测试里每一条 `["test", …]` 夹具都带
`--locked`，白名单过滤在它们身上是**恒等变换**。故 §八第 3 条的正确措辞是：判据对
「只保留含某旗标」这一形态零信号，成因在夹具而不在判据。

第 1 条的域也量清了：`docs/` 下 50 份活文档、2096 行围栏内容里，围栏内的预构建处方只有
`engineering.md` 标记块那两条；而 `docs/adr/0121`（2 条）与 `docs/reports/`（3 条）另有 5 条副本。

## 决定

### 一、只判**围栏内**的行，不判散文

围栏内的行是**可复制执行**的；散文里的命令是**用来说明的**。`docs/engineering.md` L34–36 就有一条
反例：`cargo build --workspace --all-targets` 写在那里是为了说明**它为什么不算预构建**。
判据要是也扫散文，就得为这条反例开一个豁免名单——而豁免名单是判据退化的入口（下一版会有人往里
加第二条、第三条）。围栏内外之差恰好是「可执行 / 用来说明」这条真界线，不需要名单。

代价如实登记：**有人在散文里写一条错的处方，判据看不见**。这不划算地修——散文不具可复制性，
而且真写错时读者会先看到散文里的命令与围栏里的命令不一致。

### 二、处方只认带 `--no-run` 的 `cargo` 命令

不带 `--no-run` 的 `cargo test …` 是门控那一步**本身**，活文档里到处都有（说明、示例、对比）。
拿它当第二真源会把说明判成缺陷。带 `--no-run` 的命令才唯一地是「手工预构建」。

### 三、匹配用**多重集**，配额先由承载块的那份文档消费

块自身那两行天然命中；配额被它们消费之后，任何第三处出现都必然落空。顺序上先扫承载块的文档，
所以被点名的是**副本**，不是块本身——报成「块内那条重复」会把读者引到对的那一处去改。

### 四、域 = 活文档，`docs/adr/` 与 `docs/reports/` 按**路径段**排除

那两段是**已发布的历史记录**，按纪律不可就地订正。把历史圈引的处方判成「第二真源」，
是把「记录该有的样子」判成缺陷，而唯一能消除它的动作恰好是纪律禁止的（改历史）。

排除 MUST 由断言付代价：测试实测那边**确实**有 5 条围栏内副本，并且反向注入（把两段纳入域）
实测 4 条用例变红。注释里的理由不算凭据。

域本身只有一处定义（`isLiveDocument`）：测试从 `.git/index` 取路径集合（W75），再用它划分。
测试若自己再写一份正则，域的边界就有两处，改一处不会让另一处跟上。

## 后果

- **门控零改动**：`xtask/src/lib.rs` 一字节不改，不新增子命令 ⇒ 不撞 `xtask-commands.test.mjs`
  逐字钉住的 24 条签名清单，也不动 `superseded-by-workspace-run` 的凭据。
- 判据从 31 条用例长到 34 条；`prebuildRecipeErrors` 的输入多两项（`documents` / `documentPath`），
  调用点只有测试一处，未扩散。
- 新增一类具名失败：**围栏不配对**。它此前不是任何判据的输入；现在边界不可判定即报错，
  MUST NOT 把「后面全算围栏内」当成事实。
- 明文残余：
  - 散文里的处方不在判据域内（理由见决定一）；
  - **未跟踪**的活文档不在域内（路径集来自 `.git/index`；登记可见性由 W135 的
    `pending-registration` 管，两者不互相替代）；
  - `docs/adr/`、`docs/reports/` 里的副本永远是域外事实——它们会随每一次引用继续增加，
    这是记录的正常形态，不是漂移。
