# ADR 0195：当前TTS部署改为CosyVoice3

日期：2026-11-07。状态：Accepted，依据用户明确移除Qwen并安装Fun-CosyVoice3-0.5B的指令；替代ADR0194中当前TTS部署选择，其余单视觉引擎/独立媒体进程/M0约束不变。

当前目标地址由用户提供为http://127.0.0.1:50000/，接入协议以实际服务探测为准，不是Qwen的/v1/audio/speech。无需继续安装Qwen流式候选或下载0.6B。Rust内核保持服务无关，CosyVoice运行在独立现有Python容器；不把模型推理移入Rust内核。

2026-11-08用户选定：单TTS常驻服务、短语义句流式、最多下一句的有界预取和插问优先调度。GPU推理仍一次一个请求；旧预取可撤销交付，但不冒充GPU抢占，确认原请求排空后才发下一次合成。vLLM并发不进入当前主线，不为比较而安装或替换服务。先落实有限语音纵向链路，再接FlashHead与公共音画。

进程配置显示Fun-CosyVoice3-0.5B，模型配置24kHz。真实流式、Windows可达性、实际权重指纹、共享GPU性能及音色使用权分别核验；更新本决策不自动更新数据库或宣称验收通过。不保留Qwen协议兼容层作为新主线要求，旧报告只读历史。
