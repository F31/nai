# ADR 0155：手动备播记录与执行证据分离

日期：2026-10-24；状态：采纳；V48-04。

新增manual_run_draft作为工作区私有用户记录，复用preparation Schema与CAS/不可变对象版本，不创建新服务或数据库writer。持久进度仅表示手动选择，不是播放ACK、用户已读或公共播出证据。人工标记只作为后续复盘输入，不自动修改事实或发布。

绑定发布快照和单元序列，新建需验证引用；后续不允许换绑或将结束记录重新开启。仍由已有preview/readPreview独立核验每次实际呈现的权限、撤销和有效期。结束及切段先停止旧预演；重启仅恢复选择，绝不自动重放。记录更新失败不回退已生效停止。

本轮不启用LLM/TTS或公共媒体输出，不从旧线继承生产播放证据。实际零API手动体验和后续OBS验收独立记录，164ACC不因草稿或前端回执自动升级。
