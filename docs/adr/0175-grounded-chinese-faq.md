# ADR0175：已发布FAQ的有界中文引用检索

日期：2026-10-25；状态：采纳。

V48-06先交付零模型调用的资料问答纵向路径，沿现有私有候选、引用、TTL、取消与草稿采用。精确匹配优先，其后为声明版本的中文二元组/英文数字词检索；双方覆盖阈值、分差门槛和有依据FAQ约束显式执行，歧义/缺依据拒答。

结果只引用FAQ原答案，新增Retrieved原因和策略/原问题/整数排序分数，不把词法相关度称语义理解或置信概率。UI显示原问题和适用条件，采用不授发布/播放。新增元数据从Schema生成；不重写已有不可变精确匹配工件、无需表迁移。

没有新增向量服务、推理依赖或API调用。完整Harness/LiveContext、实时问题池、检索后生成及场次归位仍需后续实现；本轮20例是小型固定回归集，不是生产知识库召回认证。
