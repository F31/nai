# ADR 0126：指针的域扩到全仓，代码段里的链接形状不是指针

- 状态：已采纳
- 日期：2026-10-19
- 关联：ADR 0125（指针可达性判据本身的立项）、ADR 0075（域由 `.git/index` 派生）

## 背景

ADR 0125 立的判据把域定在 `docs/**/*.md`。那个边界是 W151 的产物，不是判断的结果：当时先量了
`docs/`，那里有 36 处现成的红，就先把这一格关上。域外还剩 661 份已跟踪 `*.md` 从没被看一眼。

本轮先量再扩（全仓实测）：

| 域 | 文档 | 链接 | 其中相对 | 扩域后走不到 |
| --- | --- | --- | --- | --- |
| `docs/` | 330 | 830 | 793 | **0**（W151 的修复成立） |
| `openspec/` | 649 | 11 | 10 | **3** |
| 根目录 `*.md` | 2 | 113 | 113 | 0 |
| 其他已跟踪 | 10 | 9 | 9 | 0 |
| 合计 | **991** | **963** | **925** | **3** |

3 处全在 `openspec/changes/archive/` 的归档变更文档里，全是**层级写错**：`../../docs/adr/…`
从第 4 层出发解析到 `openspec/changes/docs/adr/…`，目标文件在 `docs/adr/` 里好好躺着。

扩域还顺手暴露了判据自己的一个缺陷，而且这个缺陷**只有扩域才看得见**：`docs/` 里
「代码段内的链接形状」是 **0** 条，`openspec/` 有 **4** 条——两份规格（归档 delta 与主规格）
各自在反引号里举了两个坏例子（`[ADR 0016](adr/0016-…md)`、`[ADR 0051](0051-*.md)`），
用来说明「这样写是坏的」。判据把它们当成断链，等于**要求作者不能举例**。

## 决策

1. **域 = 仓库内全部已跟踪 `*.md`**。理由不是「更大更全」，而是：`openspec/` 的变更与规格文档、
   根目录 README/AGENTS 同样是记录，它们指向 ADR 与基线的方式和 `docs/` 一模一样。域由
   `.git/index` 派生（ADR 0075），未跟踪文件不在域内。
2. **文档域的过滤条件只有一个落点 `documentPathsOf`**，调用方 MUST 用它构造文档集。两处各写一遍
   过滤条件，迟早一处漂移而另一处替它掩护。
3. **代码段（围栏块 + 行内代码）在判定前遮蔽**，行号保持不变。遮蔽而不是「跳过含反引号的行」：
   链接与反引号可以同处一行，按行跳过会因为一个反引号丢掉同一行里的真指针。
   围栏闭合 MUST 同字符且不短于开启；落单的反引号是字面量，不开启代码段。
4. **遮蔽不许变成「不判」**：同一个链接形状落在代码段之外 MUST 照旧失败，这条由用例的
   判别性样本守（`#5` 里三组：代码段内不判、代码段外判、同行混排只判一个）。
5. **规格的改名用 `REMOVED` + `ADDED`，不用 `MODIFIED`**：`docs/` 那条 Requirement 的标题
   「under docs/」在扩域后就是不实陈述，改正文而不改名等于留一句谎；而项目的 spec-merge 判据
   的段标记闭集里只有 `ADDED`/`MODIFIED`/`REMOVED`（`RENAMED` 不在集内，`MODIFIED` 要求名字不变）。
   两者都不能既改名又可重放，于是显式写成「删掉旧的、加上新的」——这是三次里最诚实的表达。

## 后果

- 判据从 330 份扩到 **991** 份文档、793 条扩到 **925** 条相对链接，一次性成本约 1.3 s（本机）。
- `DOCS_ROOT` 导出被删除：域变了，留着它就是一处没人用的声明。
- 3 处归档文档的就地订正只改 URL 字符串，正文一字未动（ADR 0125 的第一类处置）。
- 判据现在会看着 `openspec/changes/` 下的**活跃**变更：正在写的 proposal/design 里若有断链，
  归档前就会红。这是本轮扩域的正面副作用，但也是它唯一的代价——写变更文档时要多留一次心。

## 残余（具名，本轮不做）

1. **围栏豁免没有真实样本**：注入 I4（只遮蔽行内、放过围栏）只打红合成样本 `#5`/`#6`，
   **不**红真实语料 `#1`。也就是说「围栏里的链接形状」今天一句都没有，这条规则目前只有
   合成样本支撑。如实登记，MUST NOT 记作「已被真实语料验证」。
2. **锚点（`#fragment`）仍不在域内**：扩域后全仓仍是 **0** 条。slug 规则随渲染器变，没有真值可校准。
3. **引用式链接定义行（`[x]: url`）仍不在域内**：扩域后全仓仍是 **0** 条，解析器也没实现。
4. **「能点开」≠「点开是那件事」**：内容正确性仍是语义，判据不判。
5. **外部链接 38 条一条未测**（扩域后比 `docs/` 的 37 条多 1 条）：判它要么引入网络依赖、
   要么引入缓存快照（第二处定义），都不做。
6. **`node_modules` 里的 markdown 不在域内**：它们不可跟踪（`.gitignore`），按「域由索引派生」
   本来就不该在域内——这里只登记一次，免得下次被当成漏掉的格子。

## 勘误（2026-10-19，W153）

**残余 2（锚点不在域内）与残余 3（定义行不在域内）已由 [ADR 0127](0127-domains-of-markdown-pointers.md)
结清**：定义行进域并照内联链接判定；带 `#` 碎片的指针改为**拒绝**（不是静默跳过）；
无定义的引用式使用仍不判，但改按「它是不是链接」定性（不是链接 ⇒ 只数不判）。

残余 1（围栏豁免没有真实样本）、4、5、6 原文继续有效——本轮没有产生任何围栏样本。
