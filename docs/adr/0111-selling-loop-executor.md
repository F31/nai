# ADR 0111：B07 的执行体——把「讲品循环」从一次判定变成会跑的东西

- 状态：已接受（W136，2026-10-17）
- 基线：`docs/直播数字人 + 智能体系统技术方案 V3.11.md`
- 相关：ADR 0105（W127）、ADR 0110（W132）、§53、§5.7、§5.3、§48.5、§57.3、INV-33

## 背景

`tests/registry.yaml` 的 `B07` 自 W68 起就是 `pending`，notes 自己写明原因：交的是**判定面**，
而「讲品循环跑起来了吗」不可判。本轮开工前现测，这句话仍然准确：

| 环 | 现测结果 |
| --- | --- |
| ① 判定面 | `evaluate_pitch(&PitchPlan, &PitchPolicy)`，四条 row 全判，19 项测试 |
| ② 执行体 | `nai-runtime` 对 `selling` / `PitchRunner` **0 命中** |
| ③ 调用方 | `Composition` 无相关方法 |
| ④ 真实产生者 | 段落内容与话术、TTS 时长、播放采样、§5.7 重校验——都不在仓库内 |

判定面的**形状**本身说明了缺什么：它判的是一整份 plan 的快照（`entrances` 是整条时间线），
而一个在跑的循环是**一次进一段**的，每一步要回答的是「现在能进这一段吗」。快照判定答不了这个
问题——它没有「上一次进入是什么时候」这个状态。

## 决定

1. **规则只定义一处**。新增 `PitchHistory`（最后一次进入 + 每段最后一次进入 + 计数）与
   `evaluate_transition(history, next, policy)`；`evaluate_pitch` 的 row 3 改为**逐条重放**它。
   于是批次判定与在跑循环对同一条时间线**不可能**给出不同答案。若在 runtime 里另写一份冷却算术，
   两处会各自漂移，而「哪个答案是真的」将不可判。

2. **冷却的读数是「该段自己的上次进入」**。这是本轮顺带修掉的一条**弱判据**：
   W68 的实现是 `entrances.windows(2)` + `pair[1].segment == pair[0].segment`，
   于是 `selling@0 → spec@600 → selling@900`（冷却 1000ms）**被判为合规**——它一对相邻同段都没有。
   规格写的是「同一段落的**重复进入**」。判别性样本因此取「中间插了别的段」这一形状：
   旧实现放行、新实现拒绝；边界另一侧（`gap == cooldown`）必须仍放行，否则「不早于」被读成了「晚于」。

3. **执行体 fail closed**。`enter` 在拒绝时**不记录、不移动游标**。这不是防御性编码，而是
   「拒绝」这件事在类型上的含义：一个被拒的进入若仍推进状态，调用方忽略返回值就能跑到规则前面。

4. **§5.7 的重校验是输入，不是自证**。`ResumeRecheck` 覆盖「产品、价格、活动、素材、授权」五面，
   每面三态 `Fresh / Stale / Unavailable`。`Unavailable` 是**拒绝**。理由不是保守，而是**准确性**：
   五面的真实产生者是守门与知识层，仓库内没有；在装配根里写「假设它是新的」，等于把一个
   **没测过的事实**写成一次**授权**。为了让这种状态**可表示**，专门提供 `ResumeRecheck::unavailable()`——
   否则调用方只能在「撒谎」与「不调用」之间二选一，而前者更可能发生。

5. **拒绝分四族四码**：plan 不合规 `INVALID_ARGUMENT`、转移被拒 `CONFLICT`、
   重校验过期 `EVIDENCE_EXPIRED`、重校验不可测 `CAPABILITY_NOT_READY`。
   合并成同一个码会让调用方无法分派——「太早了」可以等，「测不了」等不来。

6. **归位不是一次新的进入**。插问后回到检查点所指段落，是继续被中断的那次访问，不是段落切换，
   因此**不进冷却判定**、不增长时间线。它要过的是 §5.7 的重校验，那是另一条规则。

7. **`apps/engine` 本轮不接**，如实登记 0 命中。engine 的 `Script` 只有 `ManualEvent` 的
   comment/gift，没有讲品概念；接它要先设计脚本层的讲品编排格式，那是另一个形状的设计，
   与「把执行体建起来并接上调用方」不是同一件事（W123/W128 对 R10 也是这个处置）。

## 后果

- B07 `pending → implemented`，**不升 `tested`**：`apps/engine` 0 命中，且三类真实产生者不在仓库内。
- 「讲品循环现在可运行」这句话仍然**不可说**。可以说的是：编排一进一段地推进、被拒即停、
  检查点与归位有判定、调用方在装配根上。**段落说到什么水平、播出来多长**，本轮没有任何主张。
- 冷却读数变强后，任何「相邻同段才算重复」的旧假设都会变红——这是判据增强的**预期**效果，
  修前提而不是关判据。
