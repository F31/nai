# ADR 0182：句边界 FAQ 插问与原稿归位

日期：2026-10-26。状态：已采纳，工程交付与Windows定向实测完成；真实本地Qwen合成验收Blocked。

V48-07采用单个受保护插问范围。操作员先从当前问题池检索并核对已发布FAQ原文，再显式批准本机回答。绑定原自动范围、FAQ任务及其父问题、源快照、epoch、模型/音色、实际输出及费用范围；同一范围最多16个已使用插问ID及FAQ任务，不重放已选问题。

普通插问等待当前句可信提交后暂停，记住未播sentence_cursor。回答具有独立预演/TTS身份，复用实际公共批准/执行链路，回答完成不增加原稿submitted_sentences；只有root验证实际提交完成才恢复原游标。仅支持120字以内的已发布FAQ，公共守门v4仍只允许已确认物理规格原文，不能把操作员批准视为任意语义通过。

插问期限15秒，不放宽业务网络15秒及控制4秒；TTS子Operation消费剩余期限。最多当前/下一句原稿及单个插问描述，实际PCM缓存仍最多两项。来源变化、父问题取消、P0/nonce/epoch、模型变化和真实媒体权限逐层复检。失败/取消停止自动范围，未派发保持暂停；未知提交保持Interrupted，人工处理后才可继续。重启不恢复旧范围。

状态读取只呈现受保护元数据，不授予音频或事实授权。同一请求的来源证明仍只在不可变Store借用及同一Operation内生效。Windows GUI、原生进程和真实API分别记录，164ACC不升级。后续是真人独立麦克风接管，再做连续OBS及长稳矩阵。
