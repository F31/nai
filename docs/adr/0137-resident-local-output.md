# ADR 0137：会话常驻本机输出窗口

状态：Accepted（2026-10-21）。基线 V3.11，承接 ADR 0134。

为OBS保持同一采集对象，engine在一个会话内持有一个受监督keeper。首次明确本机播放创建窗口，句间黑色静音待机，逐句创建/释放音频stream。私有继承管道用LocalOutputCommand传描述符路径、装箱grant、撤权与停机；媒体字节仍在单独文件。输入队列4、主控命令2、状态2，单句20秒/64MiB，常驻30分钟，均有界。

每句重新校验审批/哈希/事实/epoch/短租约。撤权命令仅作拒绝，不授予下一句播放；750ms未得到静音待机确认则回收子进程。EOF/失租独立拒绝，旧renewal在待机时不能启动音频。不自动重播或自动调用API。所有早退先撤回调授权，再释放音频流。

本裁决扩展工程本机输出，不授予硬件PlaybackAck、持续讲品或麦克风接管认证。中性形象待机、长播/音频会话稳定性和OBS实际录制仍需后续证据。真实设备测试须在可访问Windows音频服务的环境运行，受限沙箱的回调停滞不能记通过。
