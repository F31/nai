# ADR 0129：原生桌面壳独立构建

- 状态：接受
- 日期：2026-10-19
- 依据：V3.11 §10.1、§29、§1259；ADR 0046 D3/D5

## 决策

将 src-tauri 从「只有声明」推进为真实 Tauri 2 可执行程序，采用独立 Cargo workspace 和独立锁文件。
ADR 0046 D3 的便携门控边界继续成立：根 workspace 显式排除原生壳，portable/full 不需要 GTK/WebKit/WebView2。
本决定替代「不引入真实依赖」这一阶段性选择，不修改内核依赖方向。

原生壳内嵌已有 Vite 生产前端，复用既有 CSP/权限声明。构建准备只复制目标机真实 engine/keeper 二进制，
不制造占位 sidecar，不启动后台进程。前端在原生宿主中禁用 HTTP 测试连接，并明确引擎 IPC 未接线。
受保护 IPC、进程监督和安装器仍是后续实现，不能将窗口加载称为安装后首句演练完成。

## 成本与验证

独立依赖闭包包括 Tauri 2.12.4、tauri-build 2.7.3 及平台传递依赖；增加构建缓存和平台工具链维护成本，
没有新增常驻服务。本轮点名原生 build/clippy 和真实 WebView 导航冒烟；根 full 仍负责既有便携与前端检查。
根 SBOM 的范围仍为根 workspace，发布壳前必须另补该独立闭包的供应链产物与签名链。

Linux 加载证据不替代 Windows 安装、设备、签名、公证或人工 UI 验收；A12/O01 不因本轮自动升级。
