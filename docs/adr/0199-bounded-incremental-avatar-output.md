# ADR0199：首块准入的有界增量音画

日期2026-11-08。Accepted，限已封存PCM的原生短流执行层，不是在线TTS/跨任务长流、安装版或持续实时通过。

协议6在签名预热证据中声明真实block_frames/motion_frames，Root核对frame_num及预热块数公式。一个实际块作为预填，上限两块；Root像素预算包括调度队列、3帧传输、当前/生产临时/屏幕缓冲，共不超过256MiB，元数据及worker自身资源另有边界，不冒充整个进程RSS。

第一块完整验证后开启设备音轨，后续由既有Root ingress独立校验身份、摘要与代次并增量交付。取消共享原子Operation，反压不阻塞P0；像素只按新鲜设备时钟选择，欠帧/过期/生成失败撤音轨并安全画面。成功终态须同时有完整生成和设备播放完成。

统一原生预演为增量路径，删除Batch.adopt和整段Prepared容器。源封存仍保持同上下文、逐源摘要、精确拼接与144000样本上限；未来帧不再全部分配，256MiB改为在途Root像素预算。取消时撤销尚未播出的所有依赖帧，不将已播前缀当作完整成功。

真实3.84秒短流：首块1948ms、首声3206ms、生成完成5511ms，96帧和92160样本完整播放；队列峰值65/上限80。生成仍慢于音频，首声提前不授持续实时。设备启动/门控在首块后仍约1.26秒，下一步需量化并行设备准备与供给余量，不能简单消掉缓冲等待而掩盖/放大欠帧。
