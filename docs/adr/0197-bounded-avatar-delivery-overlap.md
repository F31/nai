# ADR0197：有界CPU交付与单GPU计算重叠

日期2026-11-08。状态Accepted，仅工程预演能力；生产采用仍须端到端性能验证。不更改ADR0193/0195单视觉引擎、单TTS和一槽方向。

保持模型/特征/随机数/CPU前缀转换在原线程顺序执行。单CPU交付线程独占OwnerFrames，将上一块交付与下一块计算重叠；下一块CPU物化前等待上一块释放，最多一块在途，无排队扩容、无第二GPU实例。失败取消父任务，退出先join后关闭映射，GPU内核本身不可抢占。

私有协议4增加overlap_ms。它是compute与delivery单调区间交集，不是整个delivery时间。Root验证不超过任一参与阶段，累计阶段减去交集受任务墙钟限制，拒绝旧协议及不一致签名计量。

本轮真实热态重叠609ms，96帧回执及取消恢复通过，但3.84秒音画需6578ms；上一轮6375ms，两次不同进程/时间的测量不能建立因果加速结论。当前没有端到端收益证据，不提升实时状态或生产默认。下一步聚焦GPU去噪/解码等生成阶段，不继续把CPU传输作为主瓶颈。
