# ADR 0194：首轮采用已部署 Qwen3-TTS 1.7B

日期：2026-11-04。状态：Accepted；修订 ADR 0193 中 TTS 默认型号，其余单引擎和 M0 约束不变。

用户确认优先使用现有可工作的 Qwen3-TTS 1.7B 推进 FlashHead + Qwen + OBS 目标机验证，0.6B 留作按需优化，不再以 0.6B 下载完成作为首轮前提。新数据根及本地适配器默认使用当前服务声明的 `qwen3-tts-1.7b-customvoice`；已有用户配置不自动修改。型号和端点可配置，不能以请求 model 字段代替服务实际模型的核验。

已部署 1.7B 的服务报告约 3.89 GiB 显存，非流式语音有首句等待；与 FlashHead 同时运行的显存、时延、帧率与长稳未实测。模型切换须根据实际数据决定，不能预先断言联合运行通过。首轮仍须执行 M0；FlashHead Lite、VAE、wav2vec2 的来源和许可应分别核对。
