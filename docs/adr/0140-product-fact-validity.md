# ADR 0140：商品文档有效期贯通与证据期限收紧

状态：Accepted（2026-10-21）。依据V3.11 §5.4/§5.7/§53，承接商品工作台/热发布及人工辅助节目。

商品草稿和operator知识文档新增可选的成对valid_from_utc_ms/valid_until_utc_ms，闭开区间[from,until)，from必须小于until。配置用0至253402300799999的安全整数（至9999年，低于JS精度上限）；UI显示本机时区，持久化UTC毫秒。缺失不等于永久有效或机器Fresh，旧草稿不自动补时间。

复用ImportedDocument既有valid_from_ms/valid_until_ms、快照时间过滤、candidate_documents_valid与approval_valid，不改SQLite schema，不增加新的事实存储owner。有效期属于文档修订身份；发布与热发布保持时间，并以既有epoch/快照切换废止旧审批。

候选expires_at_utc_ms和生成deadline取请求TTL与所有引用证据最早失效时间的最小值；合成deadline再以候选期限收紧。请求中同时轮询UTC有效性及独立单调deadline，到期取消，已派发请求保留用量不自动重试。播放继续从存储取审批证明，媒体租约不超过候选/审批期限。事实失效归EvidenceExpired，不作为供应商故障。

人工辅助节目现在要求所有商品事实窗口已声明且当前有效，这是有意收紧的准入：旧草稿须补充/发布时间后使用节目。普通手工问答仍兼容未声明时间的旧事实，须既有知识/守门/人工审批；不得把这种兼容路径称为自动讲品许可。

时间校验不判断事实内容真实性，不补齐商品/价格/活动/素材/授权五面自动校验，也不把自由文本转为结构化价格/活动值。自动有限节目、金额预算、硬件完成进度、真人麦克风和OBS另行接线。系统UTC时钟是当前时间来源，没有外部授时认证；原安装和真实用户数据本轮不变。
