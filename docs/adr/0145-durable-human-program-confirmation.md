# ADR 0145：节目人工复核持久化边界

状态：Accepted（2026-10-22）。沿用V3.11 §5.7/§53与ADR0141/0144，完整PlaybackAck定义不变。

人工听完确认不再只推进内存计数。确认前要求精确本机submitted候选、播放时独立预期设备帧数，以及与成功结果绑定的≤16KiB报告SHA256；复读并验证IAudioClock实际尾部、单stream、窗口提交诊断。审批/事实/有效期与会话epoch/快照/节目期限再检查，不能只信submitted字符串或缓存批准位。

既有critical `cue`日志承载具名节目状态转换，payload固定event=`program_human_confirmation`，遵循生成的OpenAPI ProgramConfirmation契约。无需新kind、表迁移或第二个存储owner。记录含操作者、段落、候选与报告/媒体摘要、设备帧和窗口提交诊断，未包含完整草稿或凭据。critical写入成功才推进；写后撤权/冲突保留记录但暂停，无自动下一段/重试。

读取当前工作区最近256条决策中最新匹配记录并返回哈希链引用。它是近期只读历史，不是全部历史检索；重启仍absent，不从人工记录重建runner、审批、候选、预算或已完成句，不作为场次记忆。UI以默认折叠详情展示，不增加人工填写步骤。

机器音画完成、可恢复的正式节目检查点与自动插问归位仍未完成。真实Windows设备测试使用明确本地协议夹具，确认命令由测试调用，不冒充人耳/OBS验收。
