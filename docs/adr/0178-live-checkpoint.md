# ADR0178：讲品单元队列与可信提交检查点

日期：2026-10-26；状态：采纳。

以既有发布节目单元构成最多32项有界队列；LiveContext持久记录发布源身份、控制人、独立session/epoch、当前及下一单元、提交及人工跳过计数。对象ID与session ID相同，通过既有对象版本CAS控制；不新增数据库表或旧协议兼容层。

只有root内部record_public_execution在验证语音任务、父预演、当前单元、批准对象、源身份及epoch后，才能在同一审计事务中推进提交检查点。重复完成幂等，错误来源/旧epoch/审计失败拒绝推进。提交完成不是硬件播放完成ACK。JSON解析失败仍拒绝，不能因对象类型不明而放行。

暂停在当前单元提交边界生效，继续不自行生成或播放。重启撤销旧epoch，恢复必须显式执行；未知在途单元保留中断，只能明确跳过并单列计数，不能冒充已提交。源失效禁止新播出，但允许结束清理。

首页和发布页共用队列入口，复用既有逐段准备和批准。此切片不提供自动连续播出、长文分句、预取或真人麦克风接管；现场会话与备播导航仍需后续解耦。164项ACC不因局部测试升级。
