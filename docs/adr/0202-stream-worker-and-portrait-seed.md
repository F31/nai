# ADR 0202：增量worker生命周期与头像初始化随机源

日期：2026-11-09。状态：Accepted（新worker原生诊断通过，Rust主控/设备尚未装配）。

增量执行协议升至2，拒绝旧版本1；真实Ready、共享帧引用/Release、输入EOS与渲染Complete/Cancelled分开。单常驻模型中顺序新任务保留不同epoch/task，控制不被raw/GPU阻塞。取消时若原始包未完整消费，则通道被污染，必须终止并重新建立，不允许把残留字节当下一任务的起点。

跨进程对照暴露头像参考latent的随机源缺口：上游LTX encode使用posterior.sample()，原代码仅在任务开始时固定全局RNG，发生在头像缓存生成之后。现在在get_base_data之前也按配置seed绑定全局RNG；不换模型、分辨率、步数或预处理比例。重新建立参考后，两个独立进程的96帧摘要完全一致，失败记录保留。

这是一处可复现性修复，不把旧随机初始化片段自动视为新基线人工验收；人工画质、持续实时与发布仍待验。Python父进程诊断不替代Rust主控或实际设备播放。34ACC/M0不升级。
