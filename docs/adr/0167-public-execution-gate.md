# ADR0167：独立执行租约与逐帧提交游标

日期：2026-10-25。状态：采纳，V48-05核心增量，尚未生产装配。

新增PublicExecutionLease，与健康心跳的消息和用途分开。root仅通过PublicMediaPermit当前权威复检生成租约，TTL限制为原permit剩余期限且不超过500ms。消费者绑定完整批准hash、实际准备描述/首尾帧回执、输出/会话/epoch及新的准备UUID；本地挑战超过250ms、重放、错误身份、停止或到期使该流永久撤权。相同clip重新准备必须生成新UUID。执行key仅允许私有原生上下文，不返回Web、不持久化；生产key配置/桥接本轮尚未实现。

消费者挑战与callback必须使用同一消费者单调时钟原点；root的剩余期限独立计算，不把root绝对tick当消费者时刻，也不按消息到达重签。共享原子围栏无DB、网络或队列锁，callback观察到过期/时间倒退即撤权，gate owner销毁亦撤权。

共享CPAL回调改为每帧检查停止/截止条件，使用有界源样本提交游标完成24kHz与实际设备采样率映射，静音不推进、尾部不越界。提交不是硬件播放完成，已排入设备的缓冲不能由该游标证明已撤回。嘴型可使用该游标，实际公共渲染接线尚未实现。

当前常驻公共窗口仍使用deadline恒0的静音准备，既未接入新执行gate，也没有root生产许可签发/续租入口。本轮不能声称公共语音或动态嘴型已实现，164ACC保持pending。
