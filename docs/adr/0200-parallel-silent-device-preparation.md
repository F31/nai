# ADR0200：并行静音准备与有限源准入余量

日期2026-11-08。Accepted，限已封存PCM的原生短流执行层；不改变协议6、图像算法、控制/模型期限或持续实时状态。

音频设备从任务开始独立静音准备，与GPU首块生成并行。现有音频协议零样本Running只表示续租和设备可用，不表示正在播报；源PCM仍由独立ready门控制。图像未准入时必须保持安全画面，played_sample不得非零。准入依赖同epoch/设备代次和当前新鲜证据，不使用墙钟推进样本。

为避免拿掉串行设备等待后暴露供给不足，用本次首帧到达耗时估计块周期，对有限剩余块的超音频预算累计加200ms保护，且不早于首块完整就绪。只有完整生成已验证时可跳过未来余量。估计仅延迟门开启，不是实时保证，原有欠帧退出及256MiB/两块上限保持。

设备初始化的3秒上限不变，但等待使用保留进度的同一异步future，每10ms复检父取消，不因反复timeout重新读取帧。取消先撤权/安全画面，再退出设备进程。

实测设备1207ms准备、首块2062ms、准入2280ms、首声2404ms；比上一轮单次3206ms早802ms。完整96帧/92160样本通过；此非随机大样本性能认证。生成仍5250ms/3.84秒，未达持续实时，不能用首声优化升级M0。
