# ADR 0038：真实 Provider 接入的边界——端点是配置、凭据不入库、可用性是账户状态

- 日期：2026-10-10
- 状态：Accepted
- 基线：V3.7 §30.1（测试分层；「不得用播放固定 MP4 冒充已完成的音频驱动模型」）、§16 S07（日志、诊断包、崩溃转储、仓库扫描均无明文密钥）、§1469（声明式契约）、§5.9（黄金集八类）、§12.5（整链路分位数）、§655（B01 验收）、§1329（O01 验收）、D01（不引入 GPU/SDK 作为普通 CI 前置依赖）
- 变更：`openspec/changes/w36-live-provider-evidence/`
- 判据：`tests/registry.yaml` S07 与 B01/O01 的登记口径

## 背景

B01、O01、A02、B03 此前一律登记为「真实模型未接」。判定骨架都已落地（W30/W31 的黄金集门槛与载荷载体、W19 的第二家替换、W29 的度量与复盘），但**没有任何一次真实调用发生过**。

真实凭据到位的当下，缺口从「机制不存在」切换成「接入会污染仓库或把事实读错」。四条实测事实构成本 ADR 的输入：

| # | 事实 | 含义 |
|---|---|---|
| F1 | 端点 `/v1/models` 返回的真实模型清单**不含**配置里写的那个模型名 | 配置里的模型名可能不存在于端点 |
| F2 | 同一端点、同一凭据：模型甲 2xx，模型乙 403 且报文给出**剩余余量为负** | 可用性是**账户状态**，不是端点的性质 |
| F3 | 语音端点以显式错误码拒绝不合书写形式的音色标识；按端点要求书写后返回音频 | 契约差异只能靠实测发现 |
| F4 | 同一台机器对文本端点报证书吊销检查失败，对语音端点不报 | **主机**环境差异，不是端点事实 |
| F5 | SSE 流以 `data: [DONE]` 这一**非 JSON** 帧终止 | 帧形状是契约的一部分，不能靠猜 |

## 决策

### D1 端点是配置，不是协议

新增一家 OpenAI 兼容端点只填 `ProviderProfile`，**不新增 `Protocol` 枚举分支、不新增适配器**。`Protocol::OpenAiCompatible` 已同时 `serves` 文本与语音，同一端点的两个能力共享一条凭据与一个 `endpoint`。实测已证：两个不同的真实网关（文本、语音）各自只差一份 profile，`Protocol` 与适配器集合零改动。

`provider_ref` 必须与既有端点不同，否则用量账本在替换后无法区分两家。

### D2 凭据只经进程环境，扫描域是「git 会发布的内容」

三条边界逐一否决后取交集：

| 方案 | 后果 | 结论 |
|---|---|---|
| 扫磁盘 | 被忽略的本地凭据文件必然自命中 ⇒ 本机无法持有凭据 ⇒ 检查被绕过 | **否决** |
| 只取 `--cached` | 新增文件在 `git add` 之前不在域内 ⇒ 凭据被发现时错误几乎已铸成 | **否决**（初版即此，实测发现后改） |
| 取 `git diff --cached` | 只拦当次暂存，历史与未暂存皆不覆盖 | **否决**（范围太窄） |
| `--cached --others --exclude-standard` | 拦在暂存之前；被忽略路径（`.env`、`node_modules/`、`target/`）仍不在域内 | **采纳** |

被忽略性由 `.gitignore` 决定，因此「本机凭据放哪里安全」与「扫描拦什么」共用同一份规则，不存在第二套需要同步的约定。该边界由两条测试分别钉住两个方向：被忽略的 `.env` **不在**域内，运行期新建、尚未暂存的探针文件**在**域内。

### D3 阈值用「前缀 ＋ 各前缀最小长度」表

仓库里已有一处同前缀的测试哨兵（`crates/nai-kernel/tests/monitoring.rs` 的哨兵，前缀后 18 字符）。实测：最小长度取 32 后全部待发布文件零命中，而真实凭据（前缀后 48 字符）会命中。

**不采纳**无前缀的通用长度规则：实测会命中 `token: "cloud link unreachable"` 这类全库数十处的**合法词汇**（`Finding` 的 token 字段）。**不采纳**在源码里写真实样例：扫描器源码与被跟踪的测试夹具都不得含可命中的字面量，夹具在运行期拼装——并由一条测试断言「扫描器源码不自命中」。

### D4 缺凭据 = `CAPABILITY_NOT_READY`，非零退出，**不写任何文件**

**否决**「有就用真实、没有就回退桩」：那会让冒烟在缺凭据时依然变绿，正是 §30.1 点名的「用固定素材冒充」。空值与未设同等对待——复制 `.env.example` 留空不得产生「半能用」的运行。

### D5 模型可用性是账户状态，逐模型记录

同一端点上逐模型发起一次最小调用，逐条记录 HTTP 状态与网关错误码，配额类报文原样提取剩余余量。**否决**「取一个样本代表端点」：F2 说明同一个 key 在同一个 host 上既能通也能被配额拒。

### D6 证据只含事实，**连前缀都不含**

证据字段固定为：`host`、`path`、`method`、`protocol`、`auth_scheme`（**只记方案名**）、`model`、`status`、`gateway_error_code`、`usage_fields`、`bytes`、`media_type`。**否决**记录任何请求头原值或请求行原文。凭据从不出现在文件名、日志或证据里。

### D7 音频证据是真实字节，字节数与 media type 来自响应

字节数取自响应体长度、media type 取自响应头；本地不得推断或补默认值。空体或错误报文一律判为**未产出证据**。

### D8 端点契约差异以实测为准

F3 与 F5 的教训。**否决**在冒烟里对失败输入静默重试或归一化后只记成功——那样证据不再具备纠错能力。4xx 必须连同错误码如实记录，且不得被读作「端点不可用」。

### D9 主机差异是环境事实，不是端点事实

F4。证书吊销检查失败记为**主机**注记；**否决**据此宣称端点不可用，**否决**静默吞掉。传输失败与端点拒绝在记录里是两种形状：前者 `status` 为空并带 `transport_error`，后者带状态码。

### D10 安全层的 30 秒上限对冒烟同样有效

`Operation::new` 拒绝超过 30 秒的操作（安全层不变量）。冒烟**不得**给自己更长的期限：请求超时与操作期限在示例中取同一常量，而不是让传输层悄悄截断调用。

### D11 冒烟不是验收

连通成功只新增连通性事实。B01 仍缺题集与完整评估，O01 仍缺约 10 分钟首句演练与约 30 分钟真实输出验证。**否决**以冒烟结果改动这两项的登记状态。

### D12 不改 `provider-core` 的契约，不新增证据目录约定

`Protocol`、`ProviderProfile`、`LlmClient`、`SpeechClient` 全部不变；18 包与依赖方向不变；零新增外部依赖。§30.1 已为 RAG/媒体/升级/UI/性能指定目录，**未为真实 Provider 证据指定目录**；证据落 `docs/reports/evidence/`，与既有报告同处 `docs/reports` 之下，不臆造新的顶层约定。

## 否决方案

| 方案 | 否决理由 |
|---|---|
| 把真实调用做成 `provider-core` 的集成测试 | 会把网络与凭据变成普通 CI 前置条件，与 D01 同源被否 |
| 只写一个 Node 脚本，不跑本栈 | 只证明**端点**可用，不证明**我们的绑定与适配器**对得上；补了 Rust 示例后两者互补 |
| 复用既有 `openai_smoke` 示例 | 它硬编码 `api.openai.com`，且注释明说**跳过生成路径**（token 成本），对新网关与文本链路都给不出答案 |
| 在证据里保存完整请求以「便于复现」 | 请求头携带凭据；复现只需要端点、模型与写入形式 |
| 用环境变量白名单或允许清单豁免自命中 | 放宽阈值或允许清单会让检查失去意义；D3 的阈值表已能同时避开哨兵与命中真凭据 |

## 后果

- **S07 的「CI 密钥扫描待建」被补上**：`cargo xtask check --secrets` 可执行、零误报、由测试钉住两个方向。
- **两个真实端点已接入**：文本与语音各一次真实调用**经本栈**（`ProviderProfile → ProviderClient → 适配器 → 预算网关`）成功，`Protocol::OpenAiCompatible` 与适配器集合零改动，`docs/reports/evidence/` 有机器可读记录。
- **B01/O01 状态不变**：真实模型可用是必要前提而非达标。B01 仍缺 100 题集内容与完整评估，O01 仍缺演练与真实输出验证。
- **账户状态成为显式事实**：同一端点上不同档位的模型可用性不同，且随余额变化；这类事实进证据而不进能力声明。
- **未闭环的部分要说清**：本变更只验证了「配置的端点能不能被本栈正确驱动」，未验证检索质量、未跑黄金集、未做真实声道与设备播放。
