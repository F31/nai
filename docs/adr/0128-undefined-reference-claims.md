# ADR 0128：「不是指针」≠「不需要有人认领」—— 未定义引用式使用的具名台账

- 状态：已接受
- 日期：2026-10-19
- 轮次：W154
- 相关：[ADR 0127](0127-domains-of-markdown-pointers.md)（决策 2 判「无定义的引用式使用不是指针」，
  本条补上它留下的后半条：认领）、[ADR 0125](0125-doc-link-reachability.md)（三分处置：订正 / 降级 / 拒绝）

## 背景

ADR 0127 决策 2 把引用式使用拆成两半：label 有本文件定义 ⇒ 它是链接，落点照判；没有定义 ⇒
CommonMark 把它降级成**字面文本**，读者看到的就是原文写下的字 ⇒ **不是指针**，判它「指向哪里」
等于判排版。前半条有 8 条注入背书；后半条只做了一件事：**计数**（`undefinedReferences`）。

那一计数上留了两个洞：

1. **只有数，没有名单。** 要回答「是哪 6 条」，判据答不出——写这条规则的人得另写探针，手工 grep
   第一次只找到 4 处（另 2 处落在输出截断里）。**计数 ≠ 清单**（MEMORY §6）。
2. **没有上限。** 用例只钉「非负整数」。一处把 `[安装](install.md)` 写成 `[安装文档][install]` 的
   笔误，会让计数从 6 变 7，而**一切照旧为绿**。ADR 0127 立项的理由是「判据对它们完全无感」，
   这个洞把同一件事原样留在了这条支路上。

W153 还留了一句话：「6 处的标签都活在同一份文档的资料清单里」。本轮逐份核对，这句话**成立**：

| 文档 | 资料清单 | 正文引用 | 结论 |
| --- | --- | --- | --- |
| `digital-host-agent-design-V3.2.md` | **2** 条（`- [S2] …` / `- [S3] …`） | 5 个编号（S1–S4、S16） | 清单**不全**，S1/S4/S16 无条目 |
| `抖音直播…方案-V2.3.md` | **16** 条（`- **[S1] …**`） | 16 个编号 | 一一对应 |
| `digital-host-agent-design-V3.5-OpenCode.md` | **15** 条（`- [S1 标题](url)`） | 13 个编号 | 清单另多出 S12/S15 未被引用 |

但**第一次量它的结果是 0**：扫描器要求方括号里**只有** `[Sn]`，而 V3.5 把标签与标题一起写在
方括号里（markdown 链接），一条都不命中。差一点把「该文件没有资料清单」写进结论。
**报告 0 同样是入参信号**——这是本仓第二次（第一次是 ADR 0127 背景里那个 0/6 之辨）。

## 决策

### 1. 「不是指针」与「不需要有人认领」是两件事

判据仍然**不判**它指向哪里（ADR 0127 决策 2 不变），但每一处未定义的引用式使用 MUST 在
`tests/undefined-references.yaml` 里被**具名认领**，否则失败。

理由不是「多一道检查更安全」，而是：**一处笔误与一处引注在这里字形完全相同**，判据无法分辨，
而「无法分辨」的正确处置不是放过，是**要求有人表态**。放过等于把分辨责任推给一个不存在的人。

### 2. 认领状态是封闭两态，各付一条可被机械否证的声称，方向相反

- `citation`：本文档的资料清单里**有**给该标签作证的条目 ⇒ 判据去找，找不到就是声称倒了。
- `missing_bibliography`：本文档**一条清单都没有**（那处引注无出处可核），必填 `closure`
  写「取到什么算闭合」⇒ 一旦补出清单，这条登记**自行过期**。

**方向相反是刻意的。** 单向的「登记过就不红」会让台账退化成豁免清单（MEMORY §7：台账不是豁免，
要具名、相称、自清理）。反向声称把「随手登记一条」也变成可被推翻的事：写 `citation` 要拿得出
来源条目，写 `missing_bibliography` 会被后来补的清单打红。

### 3. 台账的键是 `(path, label)` + 出现次数，不是行号

行号随上文增删漂移 ⇒ 台账会变成「改一句话就要改一个数字」的负担，那种台账没人维护。
「同一标签在这份文件里出现几次」才是这条声称的**内容**。

### 4. 双向核对，且形状先核、核不过不登记

- 方向一：语料里有、台账里没有 ⇒ 未认领 ⇒ 红（这正是洞二的补丁）。
- 方向二：台账里有、语料里没有或条数变了 ⇒ 过期 ⇒ 红。
- 形状（`state` 域外 / 缺必填 / `count` 非正整数 / 无 path / 无 label）**先核，核不过的条目不参与
  覆盖**。顺序不能反：先登记再报错，会让一条 `state: typo` 把那条用法从「未认领」里抹掉——
  一条形状错误顺手换来一次免责。

### 5. 返回清单，不只返回数

`undefinedReferenceList`（逐一具名，带认领状态），`undefinedReferences` 由它派生。
**一处定义**：两个数字分开维护迟早对不上，而对不上的那一次没人知道该信哪个。

### 6. 规格拆分，不缩句

主规格那条 Requirement 正文已 **446** 字符，`--strict` 的 500 字符上限只查主规格正文（MODIFIED
正文豁免），超长只在**归档后**才暴露。⇒ 把「只数不判」那一句改成指路，另**新增**一条 Requirement
承载认领规则（正文 **428** 字符）。MUST NOT 为了压进 500 而把规则写成缩句。

## 后果

- 判据的这条支路从「一个数」变成「一份名单 + 一张会被推翻的台账」。新增的未定义用法、立不住的
  引注声称、过期的登记，三者都会喊。
- 用例 **16 → 22**；**9 条注入**逐条「只有它错时才红」，注入后逐字节还原（基线 `c72aea90…`（判据）
  / `a948f4f4…`（用例））。I9 的注入点在**用例侧**——「真实语料传了台账」这件事本身也要被验证，
  否则删掉那一行，判据会以空台账对待语料，6 处全变未认领而无人知道是删错了还是真漏了。
- **零份文档被改**：6 处仍是引注，读者看到的就是原文；给它们补定义会把整份文档的引注变成链接。
- `missing_bibliography` 今天 **0 条**真实样本 ⇒ 这一支的全部证据是合成样本 + 注入。与 ADR 0127
  里「定义行与锚点 0 条真实样本」同一种空白，**如实登记，不当作已覆盖**。

## 残余（具名，本轮不做）

1. **`V3.2` 的资料清单本身不全**：正文引用 5 个编号，清单只有 2 条 ⇒ `S1` / `S4` / `S16` 三处引注
   **无出处**。它们写成 shortcut `[S1]`，在域外（ADR 0127 决策 4），判据看不见 ⇒ 既不红也不被登记。
   这是「引注无出处」这一族的**真实实例**，但不是被判据抓到的那一个。补清单需要真实来源，编不出来。
2. **shortcut 引注仍在域外**：`[S1]` 与数组下标、任务复选框（全仓 2733 条 `- [x]`）字形相同。
   把它纳入域就得先能分辨这三者，本轮没有这个判据。
3. **`missing_bibliography` 零真实样本**：三份有引注的文档都有清单。这一态存在的理由是「没有这个
   取值，第一处真正的无出处引注就只有判红一条路，而修它需要仓外的真实来源」——**先有取值，再有实例**。
4. **在没有清单的文档里，笔误与引注不可辨**：`missing_bibliography` 会把该文档里任何未定义引用式
   使用都收进来。这是「无出处」本身的代价：那份文档的引注本来就无从核验，判据 MUST NOT 假装能。
5. **量「有没有清单」会假 0**：本轮第一次量 V3.5 得 0 条。任何「按方括号内容精确匹配」的量法都会
   漏掉 `- [S1 标题](url)` 这种写法 ⇒ 量法 MUST 按**前导标签**量，且看到 0 时先怀疑量法。
