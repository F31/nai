# ADR0161：受限规格原文公共守门准备复核

日期：2026-10-24。状态：采纳，V48-05工程增量。

公共guard先提供确定性受限政策nai-public-exact-spec-v1，不用LLM或模糊相似度代替守门。来源仍要求owner_confirmed、当前有效、明确引用且满足节目必需事实。首版只允许正十进制的物理规格白名单，以及有限普通商品名称/款式组成的原文句式；自由改写、金额与促销承诺、未知禁用语法明确阻止。产品禁用规则只支持明确前缀后的字面短语，不作通用语义或法律合规认证。

root观察实际PCM和内置形象后，Store再次核验本句/TTS任务/角色/会话epoch/快照来源，再由纯内核运行政策。审查对象用Protobuf绑定工作区、会话、preview、task、快照、事实、正文hash及实际音画资源；独立完整对象SHA256用于一致性核验，不是签名、公共批准或执行许可。目标为固定的本机公共窗口计划sink，不声称已经取得某个keeper实例或直播平台权限。

结果最长30秒且不得超过事实及本句有效期。取消、P0、事实撤权、资源不匹配或当前来源变更拒绝，旧结果不能通过检查请求复活；界面显示过期提示，不自动重新调用API或续期。真正消费仍须重建含实际输出实例的bundle，重新守门并经持久批准与短媒体租约，不能把准备复核提交为播放许可。
