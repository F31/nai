# ADR0162：实际公共输出实例与root单次挑战

日期：2026-10-24。状态：采纳，V48-05工程增量。

每次公共keeper spawn由可信原生父进程生成新的随机UUID，通过私有继承环境交付，实际状态逐次回传并由固定child owner核对。Web页面不能指定输出身份。

原生宿主先向引擎取得单次挑战，再poll真实keeper并提交内部观察。引擎用自己发行挑战时的单调时间计入排队、资源核验和来源复检，最长250ms，取用即消费；不使用跨进程UTC或旧状态抵达时间重签期限。只保留一个待用挑战。停止nonce及取消/P0仍在前后复检，紧急路径不等待业务mutex。

普通网页call剥离请求内的观察，私有挑战不进入网页命令白名单。只有Tauri原生root可以组合受核验的OutputOwner与BusinessOwner；窗口终止/失联时清除观察并报告未绑定，不以待机身份授予业务播放。

守门政策升级nai-public-exact-spec-v2，审查对象绑定实际输出UUID，删除计划目标常量路径；v1复核不导入或复活。实际实例仍只支持静态待机，公共批准、业务PCM/帧、嘴型和OBS继续未完成，ACC不升级。
