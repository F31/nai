# ADR 0187：有限软件声明与插问响应时窗

日期：2026-10-27；状态：采纳。

用户选择nai白皮书作为V48-09真实产品资料。既有公共守门只接纳物理规格，不能借用物理规格模板介绍软件。新增有限的软件声明族：事实label为“本机功能”、conditions为“本机工作台”、owner_confirmed且无单位/币种；功能值只接纳代码中明确列举的六项，本次实际验证手动提词、节目编排。只允许精确模板，不开放任意软件承诺，既有来源、撤销、期限、风险与批准复检保持生效。

公共政策身份与两种新原因从foundation.proto生成，消费者共用枚举身份；旧身份拒绝。播放开始前要求剩余期限覆盖完整PCM时长加500ms，不延长期限；续租不重复要求完整原片长度。

两次真实试验暴露：生成后临近期限才开始播放、以及插问选定到回答结束共用15秒。新选定问题采用固定30秒响应窗，仍取原问题、事实、FAQ、批次和自动任务期限的最小值，不续期旧记录。网络调用仍15秒，设置TTS测试45秒，存储控制4秒不变。

替代方案：关闭守门、延长网络等待、续期旧批准均拒绝。真实用户/平台完成不能由本机样本提交推导。工程试验与失败、未知费用分别留存，164ACC保持pending。
