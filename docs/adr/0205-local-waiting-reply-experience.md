# ADR0205：完全本机的新回答允许有界等待

日期：2026-11-17。状态：Accepted（用户明确选择“坚持完全本机，接受新回答等待数秒”）。

保留当前已接受画质、单TTS与单FlashHead实例、Rust控制及独立Python worker。个人本机新回答不再以3秒首声作为准入硬门；记录实际等待及人工体验。未约定新的数值阈值，不擅自将45秒取消上限设为体验合格值。历史3秒失败和原机器预算保留为原目标证据；已备播放首声、句间、样本完整性与静音/取消门均不放宽。

当前实测新回答约6.5秒且不含LLM，只是起点，不承诺所有输入该时长。缓存不能补偿持续新生成吞吐不足，问题处理必须有界、串行且有取消；不因用户接受等待而声称可连续实时生成。自动AI问答及语义句归位依规格实现，不把现有显式Start/PlayPrepared探针当作生产智能体。

当前选择不授权租用算力、上传肖像、降画质或新增第二个模型实例。ADR0204关于个人本机新回答三秒硬门由本决策限定，其余预算/基线冻结继续有效。34ACC/M0不自动改变。
