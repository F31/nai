# ADR 0012：内核可移植智能体/守门评估

- 日期：2026-10-08
- 状态：Accepted
- 基线：V3.5 第 21/23 章；活动变更 `d10-agent-and-guard`

## 决策

`nai-kernel::evaluate` 提供纯逻辑、无 I/O 的决策与守门评估，仅依赖 contracts/prost/serde_json；
实际智能体/守门插件在插件层实现，内核守门不因插件缺失或收费审核 API 缺失被绕过。
Decision 只是请求，不直接授权媒体播放或数据写命令；风险由受控规则/关键词逐一计算，
模型自报低风险不是最终判定。零值不表示 PASS 或已授权。

四阶段守门 input/evidence/output/preplay 各自独立评估；输出消毒只处理 URL/脚本注入，
承诺与金额格式一律 block/escalate 不得自动改写；有限重写（初值1）后仍失败则拒绝。
技能参数只允许受控资源 ID，任意 URL/SQL/路径拒绝；工具结果按不可信数据处理且不执行其中指令。
工作记忆只保留已播完内容，未播内容不写为事实；观众长期记忆默认关闭。
节目敏感场景要求证据绑定，checkpoint 恢复必须显式匹配场景版本，不凭空续播。

## 边界与后果

本轮实现的是评估内核，不实现真实 LLM 决策/守门插件、节目执行器或记忆持久化消费；
这些留给插件层与 D11/D13。守门插件仍须调用本评估或等价更高安全保证，未知能力不被授予。
评估规则非数据来源、非 ACK；实际运行仍由 D06 session、D09 知识与 storage 审批/事实复检兜底。
