# ADR 0196：同上下文的有界音频批次

日期：2026-11-08。状态：Accepted，限当前有界预准备工程路径；不改变ADR0193单视觉引擎或ADR0195单TTS/一槽预取方向，不授M0或生产开播Ready。

## 决策

已经准备完毕且由Root归入同一执行上下文的相邻PCM，最多两段，可用单个Render连续生成。保留每段来源序号、SHA256和精确样本范围，worker复检合并摘要。全局25fps网格只在整体末尾补块；不在短句边界重置运动/音频历史或伪造独立首帧，不插入静音。

上下文用不可序列化的对象身份、epoch、参考形象摘要与父Operation绑定。相同标签或相同epoch不等于同一Context。批次是不可拆分的取消单元：插问、接管、事实/许可失效在生产装配中必须使依赖它的批次整体失效，不从含未来源特征的生成结果中恢复旧前缀。当前只验证执行上下文和取消；事实/许可数据库复检及真实问题路由尚未装配，不能据该类型声称已经实现。

输入必须是完成验证的供应商输出或操作员显式手动快照；Context.source只封存字节身份，不代替供应商EOS/来源授权。当前诊断使用手工技术PCM，未接在线TTS预取。

只有已选定并提交到同一输出单元的源才能合并，不能因此自动提交尚可替换的预取句。插问的句边界切换时机由上层调度决定；P0则立即取消整个批次。当前未实现生产插问路由，也不提供批次内部分恢复。

音频仍最多144000样本，像素最多256MiB，不建立无界累计队列。Root只在完整生成/校验后进入当前预演播放器。移除逐段生成后重绑定的实现，不保留双执行路线；显示去重单独保留。

## 后果

两段1.92秒的固定输入，由四块160候选帧降为三块120候选帧，保留帧仍96；运动上下文随块数一同减少。这不保证与旧分段结果逐像素相同，也不证明稳态实时或主观质量通过。正式常驻输出、在线滚动批次和一槽预取/插问优先仍单独实施，不以本轮预准备掩盖延迟。
