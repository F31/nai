# ADR 0183：独立真人麦克风音轨与显式恢复

日期：2026-10-26，2026-10-27补验。状态：采纳；工程链路/设备及后续OBS分轨、600秒媒体稳态通过，见ADR0184与收尾报告；全天连续讲品未验收。

工作台负责原生麦克风采集并交给显式选择的耳机／虚拟音频输出，OBS独立采集该进程应用音轨。不引入ASR、网络上传或录音；真人原声不冒充TTS候选。新增按需 `nai-human-mic-worker`，复用CPAL适配器，控制面只有有界Protobuf，PCM留在原生进程。

输入和输出来自当前进程实际设备快照；操作员必须选择安全输出并确认。默认不采集，不自动替换消失的设备。单次会话最多4小时，仍须500ms短租约；每次续期消费250ms内的单次挑战，轮询状态不激活设备。父进程失联、设备故障、窗口关闭或P0停止文件变化后停止，不自动恢复。回调使用固定容量原子SPSC环，最多200ms数据，消费后清零，允许±0.2%时钟差修正。

独立OBS音轨标识窗口仅显示电平，在单独线程刷新。停止先把媒体期限置零、撤销门控，再回报软件静音，之后释放WASAPI设备。设备释放可能超过250ms，不能放在软件静音回执之前；软件回执不表示扬声器、耳机或OBS已完成静音。关闭状态下设备检查／释放等待最多4秒，不放宽活跃续租或媒体期限。

接管先清数字人媒体，撤销旧epoch、批量批准及自动范围，记录恢复点；被打断的原稿句须确认后仅跳过这一句，被打断的FAQ不推进原稿。恢复须先停止真人音轨并明确确认位置；重新批准文本和剩余自动范围，不复活旧TTS、旧许可或已占用额度。数字人静音与包含真人的工作台全部静音分开；P0不等待模型或业务数据库锁。

增加一个按需媒体进程及小窗口，有明确设备/隐私/关闭成本，不新增常驻服务。六程序运行组合须一起更新。原生设备、实际听感、连续OBS和长稳分别记录；局部验证不升级164项ACC。
