# ADR0177：业务模型源上下文与网络子任务取消

日期：2026-10-26；状态：采纳。

业务LLM生成和已发布语音准备共用ADR0176的AgentTaskContext，与问题池按工作区、发布快照及事实引用集合生成相同源身份。工件持久保存task_context，FoundationResult及语音计划返回生成契约中的共同上下文；派发、完成、采用及音频授权沿原有角色/模型/会话/期限守门并复检源身份。

Schema允许保留缺字段的历史工件用于解析和账目查看，业务执行gate拒绝缺共同上下文或身份不匹配的候选，不自动补字段、恢复批准或迁移租约。模型设置的连接测试没有业务资料前置，仍使用固定测试内容、不建立新费用预留。

Operation.new保持1–4000ms；显式model_task/model_child最大45000ms，业务网络仍受原15000ms上限约束。父模型Operation由引擎持有，Adapter直接消费子Operation；发送前、等待中及结果交付时检查祖先取消和最短期限。网络传输使用剩余期限，不能在子调用重置整段预算。取消子不影响父/兄弟，控制与媒体P0路径不变。

已派发费用与候选是否可用分开：LLM报告可信usage时结算known，否则派发后unknown；TTS当前缺可信供应商用量回执，派发后保持unknown。取消/资料更新后迟到结果不能恢复文本或PCM缓存，不能据此宣称退费。保留线程未退出时的单槽位占用，避免卡住解析器造成无界后台线程；WORKER_STALLED保持有限安全错误码，不再误分类为普通Provider失败。

本轮不建立LLM→TTS自动付费流水线，也不让模型答案绕过公共内容守门。人工采用及重新发布会产生新源身份，不能沿用旧任务权威。完整LiveContext、工具配额/语义RAG、连续讲品检查点和插问接管仍属后续任务。
