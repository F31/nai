# ADR 0192：Windows 正式公共画面后端选择内置几何 2D

日期：2026-11-01。状态：采纳。

任务 1.4 要求依据实测选择符合 Windows 正式运行约束的原生后端或服务适配，并记录成本。本 ADR 选定当前正式公共画面后端为已交付的 `BuiltinAvatar` / `nai-media-core` 内置几何 2D（ADR 0160）。MuseTalk 1.5 保持隔离研究。没有批准把 Python 写进 Windows 正式运行包，也没有批准外部渲染服务适配。

## 决策

Windows 正式运行包的公共窗口继续使用内置 MIT 几何 2D：512×288 RGB888 闭嘴/开嘴资源、包 hash 覆盖格式版本与像素、许可文本独立 hash。公共执行已经在同一条受控 WASAPI 流上按已播放源样本选这些帧。该选择是“现在可以随正式包发布的公共画面”，不是写实生产，也不关闭 1.3.1 的合法真人视频样片。

## 依据

隔离研究按官方 `decode_latents` 串行路径三次计入 512×288，墙钟是 47.66、47.97、48.75 毫秒/帧，相对 32 毫秒线未达到。见 `docs/reports/2026-11-01-musetalk-serial-512-repeat.md`。同一研究在 4 秒硬件时钟上呈现比例 0.18；进程 RSS 采样峰值 6175.6 MiB，PyTorch 分配峰值 2386.4 MiB。见 `docs/reports/2026-11-01-musetalk-device-clock.md`。32 毫秒线不放宽。

仓库规则要求 Python 只用于离线制作、导出和隔离研究，正式 Windows 运行包不得依赖 Python 推理。当前没有原生 ONNX MuseTalk 实现，也没有通过许可、身份、取消、回执和受控停止核验的外部服务适配。因此 MuseTalk 不能作为 1.4 的正式后端。

内置几何 2D 已经在公共 keeper 生产路径上装配，不引入 Python，不扩大正式包依赖。

## 后果

公共窗口可以继续按设备时钟出内置 2D 和字幕。MuseTalk 研究脚本、权重和 Python 环境留在 `E:\projects\nai\target-windows` 隔离树。后续若出现达到 32 毫秒线的原生实现，或完成独立 ADR 的受控服务适配，再另作 1.4 修订。本 ADR 不授予播放许可、平台开播、口型评分或 164 ACC 升级。
