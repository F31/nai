# ADR 0190：V5.2 主组合与验收映射的分阶段采纳

2026-10-29。状态：Accepted（主组合决策）；仓库执行基线迁移未完成。

用户确认保留现有 React 界面，并要求固定 V5.2 主组合。当前目标为 Windows 单机、RTX 5090 Laptop、Tauri 2＋React＋TypeScript、Rust 内核、API LLM、既有外部本地 Qwen-TTS、一套已授权真人素材＋写实口型候选、独立公共输出 keeper 和一款实际直播软件；OBS 与直播伴侣可分别验证，但不默认同时加载。模型生产策略以 NativeOnnx 为目标，研究 Python 与外部 Qwen 服务分别标识，不能冒充生产原生实现。未使用能力不自动启动。

该决策修正 V5.2 §42.2 的 Vue 项，保留现有实现和数据。设备、资源、模型身份和可用性以实测为准，不将本文当实时配置或批准。V5.2 中输出租约 600ms/200ms 是初值，不自动覆盖既有 500ms 及其他各作用域租约，须先核对状态机、故障证据并通过独立 ADR 修改。

新旧验收映射见 [V5.2 主组合与验收映射](../v52-primary-composition.md)。映射为追踪关系，不等价、不可从旧证据自动转为通过。实际执行源仍是 `tests/registry.yaml` 的 V4.8 164 项；C52/CGPU 新项尚未写入该源，也未生成或执行。完成 schema、注册表和消费者迁移、保留历史及验证之后才可切换执行基线。既有 164 项状态不变。此 ADR 不授予播放许可、模型 Ready、平台权限或发布认证。
