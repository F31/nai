# ADR 0169：公共字幕与分层呈现证据

日期：2026-10-25。已采纳。工程实现已定向验证；真实业务语音与OBS音画验收尚未通过。

字幕只能取root保留的批准原文，经私有准备消息交给固定keeper，并独立复算既有caption hash。固定Windows系统字体通过fontdue 0.9.4有界栅格化；字体不随包分发。缺字、篡改、控制字符和超过三行均拒绝，不截断或替换。字体解析在既有独立keeper的准备worker内完成，不进入音频回调，不新增常驻服务。

整句字幕只在有效执行提交首样本后显示，停止、P0、租约到期、失联和完成清除。保留250ms挑战和500ms执行租约；不按字数虚构逐字时间轴。窗口呈现状态仅在实际buffer提交成功后更新，绑定准备ID、帧/源样本、字幕hash及合成像素hash。窗口提交、设备样本提交、物理输出和OBS录制是不同证据。

本轮单次真实TTS授权在派发前落盘记账，未知结果禁止自动重试。实际返回SYNTHESIS_FAILED，费用unknown，不能以静音夹具、字体图片或待机录制替代真实音画验收。OBS使用工作区内独立portable配置，只捕获公共窗口及应用音频，桌面与麦克风禁用，不推流。V48-05继续InProgress，164ACC保持pending。
