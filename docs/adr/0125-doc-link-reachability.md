# ADR 0125：文档内部指针的可达性——判据管「能不能走到」，处置分「订正」与「降级」

- 状态：已接受
- 日期：2026-10-18
- 轮次：W151
- 相关：[ADR 0123](0123-archived-proposal-structure.md)（归档记录的结构判据）、
  [ADR 0124](0124-spec-merge-reconciliation.md)（归档增量与主规格的对账）、
  W75（域 = `.git/index` 的同一条边界）

## 背景

`docs/` 下 328 份已跟踪 markdown 里有 831 条链接，794 条是**相对路径**。这些指针是记录的骨架：
报告指向 ADR、ADR 指向基线、报告指向归档变更。它们的共同特征是——**断了不会有人喊**。

实测（W151）：794 条相对链接里有 **36 处**走不到（32 断链 + 4 通配），跨 **25** 份文件，
全部是**已发布**记录。而现有门控对它**零信号**：`openspec validate --all --strict` 判主规格形状，
`--archived` 判归档记录能不能解析，registry 与各条契约判据读的是别的面——仓内**没有任何判据
解析 markdown 链接**（唯一一处是 ADR 0125 引入的这一条）。

断链的形状也说明它不是一次性事故：

| 类型 | 处数 | 成因 |
| --- | --- | --- |
| 缺 `../` | 15 | 报告住在 `docs/reports/`，链接按 `docs/` 写（`adr/…`、基线文件名） |
| 多一层 `docs/` | 4 | 同一份报告里混用「从仓库根看」与「从本文件看」 |
| 目录深度错 | 2 | `../changes/archive/…`，实际在 `openspec/changes/archive/…` |
| 兄弟文档写成子目录 | 2 | `kernel.md`（真身在 `docs/kernel.md`） |
| 日期 / 文件名笔误 | 3 | 报告真名是 `2026-10-09-…`；ADR 0001 的真名是另一串 |
| 通配当链接 | 4 | `0051-*.md`——写了编号却没写文件名 |
| 指向**从未存在**的文件 | 8 | `0027-trace-id-single-definition.md`（6）、`0015-decision-log-criticality.md`（2） |

最后一类是真正需要裁定的：它们不是「路径写错」，而是**指的东西从来没存在过**。前面几类只要
把 URL 改对；这一类若也「改一个上去」，就会把一个断链换成一条**看起来能点、内容不对**的指针。

## 决策

1. **判据只判「能不能走到」，不判「指得对不对」。** 后者是语义，机械判不了。判据的正向命题是：
   每条相对链接解析出的路径 MUST 在 `.git/index` 里。域与 W75 同源（未跟踪文件域外），
   这条边界与 `pending-registration` **不互相替代**。
2. **目录算存在。** 一条指向 `…/archive/<变更>/` 的链接是读者能点的，只要该前缀下有已跟踪文件。
   六份早期报告的归档链接正是这种形状。把它判成断链，等于要求本来正确的记录改写法——
   判据错，不是记录错。
3. **通配直接失败，且措辞不同。** `0051-*.md` 与 `0015-…md`（不存在）是两种缺陷：前者「没说清」，
   后者「说错了」。合并成一句「解析不到」会让 4 条本可机械修好的记录看起来与 8 条不可复原的
   记录同类。**判定必须分类**，这是本条与「不可解析 ⇒ 失败并分类」同一条纪律。
4. **外部链接、协议相对、纯锚点在域外**，理由分别是「可达性不归本仓库管」「同上」
   「slug 规则随渲染器变，今天 0 条样本」。引用式链接定义行（今天 0 条）同样在域外。
   域边界**逐条写进报告**，MUST NOT 让「域外」在读者那里退化成「已覆盖」。
5. **不可解析 ⇒ 分类失败。** 越出仓库根的 `../`、非法百分号转义都归入「cannot be resolved」，
   MUST NOT 静默跳过——那会让断链以「解析不了」的名义逃逸。
6. **处置按「意图是否可复原」二分，而不是按「哪一类文件」。**
   - **可复原**（编号/同目录唯一确定）：**就地订正 URL**。这是对**指针**的订正，不是对记录的改写：
     差分只含 URL 字符串，一个字的决策正文都不动。
   - **不可复原**（指向从未存在的文件）：**降级为纯文本 + 该记录末尾追加勘误段**。MUST NOT 猜
     一个编号补上去。勘误段写明「为什么它不存在」与「真实落点（若可确定）」。
7. **勘误段可以重复，指针不能重复。** 六份 ADR 各带一份同源的勘误：读者可能从任意一份进来，
   指针只在各自文件里生效——「一处定义」管的是**事实**，不是**副本**。

## 后果

- 门控多一步纯静态 Node 测试（读 `.git/index` 与 markdown 文本，不编译、不需要 protoc）；
  站点登记 `xtask-doc-links`，`tier: portable`（它跑在 `engineering_checks` 里）。
- **首跑 36 条红**：这条判据不是「先制造红再修」——红是它立项时就存在的现状，修完才绿。
- 修 36 处：28 处就地订正 URL（纯 ASCII 字符串替换，逐条断言命中次数），8 处降级 + 6 段勘误。
- **决策正文零改动**：6 份 ADR 只在末尾追加勘误段；报告只改 URL；`development-plan` 改 2 处日期笔误。
- **注入验证**（逐次 `sha256sum -c` 还原，基线 `81e17f52…a898`）：关掉目录豁免 ⇒ 2 红；
  放行通配 ⇒ **只红 1 条**（真实语料已无通配 ⇒ 判别性样本）；少看一份文档 ⇒ 只红 1 条；
  外部链接入域 ⇒ 3 红；去掉零链接守卫 ⇒ 只红 1 条；越界不判 ⇒ 2 红。

## 残余（具名，本轮不做）

1. **锚点（`#fragment`）未判**：今天 0 条带锚点的链接，slug 规则随渲染器变（GitHub 的
   `github-slugger`、VS Code 预览、`markdown-it` 各不同）⇒ 没有真值可校准，先不做。
   一旦出现第一条带锚点的链接，这条就得重新裁。
2. **引用式链接定义行（`[x]: url`）未判**：今天 0 条，解析器也未实现。域边界已写在报告 §五，
   它是一处**已知盲区**，不是「已覆盖」。
3. **`docs/` 之外的 markdown 未判**：`openspec/` 的变更文档、根目录 `*.md`（AGENTS 等）都不在域内。
   它们不进入「记录链」的主力，但**不是没有链接**；扩域要先量。
4. **链接的可达性 ≠ 链接的内容正确**：「能点开」与「点开是那件事」是两回事，后者仍是语义。
   本条判据只关掉前者；后者只能靠人读，MUST NOT 记作「已判」。
5. **外部链接的可达性未判**：37 条 http(s) 链接一条都没测过。判它要么引入网络依赖（把外网
   可用性写进本地门控），要么引入一份缓存快照（第二处定义）⇒ 都不做。

## 勘误（2026-10-19，W153）

**残余 1（锚点未判）与残余 2（引用式定义行未判）已由 [ADR 0127](0127-domains-of-markdown-pointers.md)
结清**，决策 4 里「纯锚点与引用式定义行在域外」这一口径随之失效：

- **定义行 `[label]: url` 进域**：URL 走与内联链接同一套可达性判定（通配 / 不可解析 / 索引里没有）。
- **带 `#` 碎片的指针由「域外」改为「拒绝」**：碎片怎么生成由渲染器定，判据无从校准；
  「跳过」等于把看不了的算进绿里。带文件名的仍然照判文件部分。
- **无定义的引用式使用仍不判**，但理由换了：CommonMark 把它降级成**字面文本**，它**不是链接**——
  原来写的是「0 条样本所以先不做」，那是**没有样本**，不是**没有指针**。它现在被计进
  `undefinedReferences`，边界数得出来。

决策 1–3、5、6 与残余 3–5 原文继续有效。本 ADR 原文不改写：撰写时这两类确实是 0 条样本，
那是点时刻的事实。
