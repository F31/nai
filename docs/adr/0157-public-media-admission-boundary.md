# ADR 0157：公共媒体bundle与权威准入端口

日期：2026-10-24；状态：采纳；V48-05进行中。

公共AV bundle使用Protobuf元数据绑定音轨、视觉包、许可和字幕摘要，不承载原始媒体或任意路径。规范化审批hash排除自身approved_sha256，其余字段全部绑定，音频/视觉缺轴拒绝；与standby健康消息和private_native_audio授权不同。

PublicMediaAuthority是装配根提供的权威状态端口，读取当前会话/输出、事实、审批/guard及实际资源证据；没有生产实现时拒绝。准入内核不依赖数据库/平台SDK，不从客户端声明自证权限。本轮不提供生产权威端口，也不接通keeper媒体消费；测试夹具只在tests中。

许可最长500ms，准入及每次消费前续检先检查原子StopFence，再读权威状态，读后再次检查停止与实际时钟，避免慢读取跨过期限。过期/失配后原许可永久失效；普通健康心跳不恢复。未来root必须完成真实来源与资源验证，再装配到独立媒体数据面，不能把当前core单测当播放或OBS认证。

整句私有TTS的单价未知可按用户明确上限全额预留，批准hash绑定已观察模型版本/音色/文本/预留与价格已知状态，不改变授权scope。费用仍unknown，不假结算为免费。无新服务或依赖。
