# ADR0166：常驻公共窗口的静音预装载

日期：2026-10-25。状态：采纳，V48-05工程增量。

root复核持久内容批准、当前事实/音频/许可/守门和真实输出实例后，把PCM导出为本数据根中的随机临时文件。私有交付回执只经认证root IPC进入原生宿主，再经已有认证控制管道交给固定当前keeper；控制管道无PCM/像素。进入网页前剥离路径，网页解码器额外拒绝私有能力。Windows导出采用新建文件、DELETE_ON_CLOSE和共享删除，进程强杀也由OS回收；不覆盖或扫描删除用户文件。

窗口以只读句柄和固定根/文件名规则读取，拒绝链接/重解析点、越界路径、错误实例或hash。一个固定worker、容量1命令/结果队列承担数据核验和SDK初始化，保持窗口/P0线程可运行。4秒准备期限、完成后最多5秒静音持有；主动清理、停止、失联或到期撤权。驱动初始化本身不可由标准库抢占；未返回时不创建第二worker，窗口退出由进程生命周期回收。

CPAL适配实现从试听worker提取为adapters/audio-cpal（adapter层），两个媒体进程共享，不相互依赖。复用既有cpal 0.16.0，无新增第三方依赖或常驻进程；既有公共窗口增加一个有界设备线程，最多持有单句480000样本。业务root不依赖音频SDK适配器。

预装载callback的执行deadline固定0且不对外暴露，提交样本保持0，不存在播放入口。device_ready仅表示SDK静音初始化，不授PublicMediaPermit、live_ready、播放或硬件完成。公共画面仍为静态待机。

为保持原250ms新鲜度约束，哈希改为有界块更新，并在root缓存不可变内置资源的构造结果；每次仍重新核验实际像素/许可hash，不缓存批准或Ready。canonical字节及hash不变。长期设备测试使用生产长驻模式，短夹具64请求上限保留。

下一步独立完成短租约执行、当前窗口音画同步、批准/事实续检、实际完成与OBS。V48-05及164ACC不升级。
