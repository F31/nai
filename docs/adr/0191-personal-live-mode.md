# ADR 0191：个人直播模式的交互与授权策略

2026-10-30。状态：Proposed，待按活动 OpenSpec 实现和验证；不改变当前运行时。

用户明确要求简化个人本机工作台，减少逐句审批、预算和内部产品/场次/发布操作。个人模式默认不设置预算上限，不要求逐次金额和逐句人工批准；回答由 AI 生成并可由数字人播出，可由用户点击触发，也可在用户显式开启且满足当前场次及渠道条件时自动执行。费用未知保持 unknown，历史有限/禁止预算不自动改写。

这调整现行批准及单次预算要求对个人模式的适用范围，须在实现前明确个人策略、可信身份、来源和媒体授权契约及旧规格变更，不能单纯隐藏 UI 或伪造人工批准。现有团队/受控模式保留；平台权限、内容来源、版本、epoch、许可、P0 和失联撤权仍然生效。具体变更见 `openspec/changes/v52-personal-live-workbench/`。

新增策略涉及持久数据/迁移和执行守门，须先改 schema、生成、备份/journal、故障与原生测试；既有数据库、Key、账本和注册表历史不得删除。V5.2 尚非当前验收注册表基线，此 ADR 不表示新模式已经实现或验收通过。
