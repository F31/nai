# ADR0198：编译worker的维护就绪与控制输出隔离

日期2026-11-08，Accepted，限当前Rust原生预演/执行层；不授持续实时或安装发行组合认证。用户已确认块级编译短片整体可接受，反馈及视频摘要绑定保留。

采用单一块级模型编译、原SDPA显式图外执行、LTX内部encode/decode编译；不在worker中保留整网/eager回退。编译算法装配从诊断维护状态中提取为独立组件。每任务重置全局和私有RNG，与人工接受的配置一致，不在批次内部重置运动。

维护Operation最多240秒并继承父取消/期限；控制仍4秒、业务model_task仍45秒。配置明确maintenance_timeout_ms和warmup_samples，缺字段拒绝，不迁移旧config。worker用至少两块内部静音预热，帧只在本进程释放，不送入公共输出；签名协议5 Ready必须携带实际编译图/kernel和预热回执，Root独立复检后才允许业务。

Rust owner超时或取消时结束子进程，不等待GPU主动抢占。首次实际Ready可超过45秒，不能因此放宽业务期限。当前冷维护使用已安装MSVC/Windows SDK环境；只继承明确工具链变量及CUDA路径，Key/代理/任意用户环境不转交。免开发工具的发行打包尚未覆盖。

原生编译器会绕过Python对象级stdout重定向。worker复制不可继承的专用控制fd，并同时将CRT fd1和Windows标准输出句柄改指日志；签名事件只写专用fd。该隔离经真实原生及子进程写入测试验证，不将日志混入Protobuf帧。

Ready只表示编译和内部预热可用，不是许可、TTS、设备或OBS通过。既有媒体身份/设备时钟/安全帧和取消复检保持；映射ACL、持续实时及长稳仍需独立证据，不因短片人工接受或96帧播放升级34ACC/M0。
