# ADR0176：资料问答任务上下文、取消树与持久问题池

日期：2026-10-26；状态：采纳。

V48-06 本增量建立共用的 AgentTaskContext：工作区、不可变发布快照及哈希、事实引用集合哈希、带域分离的上下文哈希。上下文由可信后端计算；角色版本在父工件单独保存并复检。该结构目前用于资料问答父子任务，不宣称已实现带 session/epoch/讲品检查点的完整 LiveContext。

Operation.child 继承祖先取消标志及最短 deadline，最多8层；子任务取消不影响父任务和兄弟。持久取消另由单事务关闭问题父对象与未采用的 FAQ 子候选并写审计，提交后才确认；审计失败回滚并提示未确认。两种机制分别覆盖进程内调用树与重启后的候选权限，不给私有问题取消添加公共 P0 语义。

问题池按操作员和上下文隔离，采用120秒滚动窗口、最多32条（包含已结案）、重复计数最多99且不续期。复用现有版本对象和两张按时间桶定位的有界索引工件；读取最多两桶、64个历史ID，窗口内至多32个。没有新增数据库表、后台服务或无界审计扫描；旧工件作为历史保留，工作区彻底清理仍走既有明确确认流程。

处理问题只调用已发布 FAQ 的本机检索。子候选绑定父ID、子ID及上下文哈希，采用前重新检查父状态、角色、期限、快照和事实引用。采用只改话术草稿；提交复检读取原绑定版本，允许本事务自己的草稿更新，不放宽采用前的最新版本检查。取消保留此前已经采用的草稿。页面不能提交或伪造 parent_task；通用对象读取不暴露内部索引。

UI沿用同一问题输入，提供入池、处理、查看和取消；自动读取、人工刷新，切换上下文隐藏旧结果，取消未确认时清空候选。没有自动模型生成、观众接入或公共播出。LLM/TTS 全链路任务树、完整 Harness、LiveContext 及连续讲品归位需后续装配。
