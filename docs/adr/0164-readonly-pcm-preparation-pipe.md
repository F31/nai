# ADR0164：只读PCM管道与独立准备回执

日期：2026-10-24。状态：采纳，V48-05工程增量。

媒体不进入既有健康租约控制管道。root通过独立stdin匿名管道把有界原始PCM交给固定keeper程序的无窗口准备消费者，描述为单独有界Protobuf环境元数据，stdout只返回准备回执。子进程没有匿名文件写句柄，Windows实际验证stdin拒绝写入。消费者环境清空，不继承root控制凭据；仅保留系统目录及本次描述/随机消费UUID。

回执绑定完整描述hash和独立消费实例，并报告实际PCM、首尾帧核验。这个实例不冒充现有待机窗口；无批准、执行租约、音轨提交或设备完成。root后台工作沿用2项容量/4秒期限，取消或到期停止并等待子进程，回收管道线程之后才释放在途计数。

选择可移植有复制pipe而非unsafe Windows句柄降权或未认证共享内存。不是零拷贝或通用handle broker，不代表现有窗口已接通音画。持续业务输出、公共批准装配及OBS仍需后续实现；164ACC保持pending。
