# ADR 0136：知识快照的显式撤权热切换

日期：2026-10-21。状态：采纳。基线V3.11、registry发布线与统一内核不变。

会话知识此前采用一次绑定；普通发布不应让运行会话追随“最新知识”。商品直播又需要运行中纠正事实，因此增加显式受控切换，而不把冻结绑定改成动态查询latest。能力绑定快照、插件配置与Provider配置的维护窗口语义不变。

应用装配根执行prepare/activate：先P0静音、推进epoch并持久化撤权，使旧生成/审批/媒体失效，再准备独立scope的新知识。宿主CAS保存非机密场景并持久导出；引擎确认完整knowledge内容匹配prepared版本且代次未变，才更新存储绑定及运行态知识引用。普通bind/retrieve仍读冻结ID；变更的是明确撤权边界后的绑定，不修改旧快照或复用旧审批。

宿主不持有P0需要的整段发布锁，运行Store仍只有engine一个owner。阶段任务有界，受现有控制鉴权和命令账本管理；仅可引用宿主数据根受控暂存目录，不接受任意路径。无新服务、Python或模型运行时依赖。

准备或保存失败保持暂停；已保存而激活未确认时保守停止引擎并提示重连，保留新事实，不自动回滚旧配置。成功路径保持同一引擎进程，不恢复自动模式。当前为整会话短暂停播，不承诺逐文档无感更新或硬件静音认证。

依据、实测与局限见 [热发布报告](../reports/2026-10-21-r1-knowledge-hot-publish.md)。ADR0135的“运行中拒绝改配置”继续适用于Provider路由/凭据，不扩大为禁止编辑商品草稿。
