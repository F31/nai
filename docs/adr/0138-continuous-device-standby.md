# ADR 0138：常驻音频会话、许可待机图与v2分帧文件

状态：Accepted（2026-10-21）。承接ADR0134/0137，依据V3.11 §8.4、INV-21。

keeper会话只open/play一次WASAPI stream，句间填零而非关闭；每句独立MediaGate、短租约、审批/事实/哈希与样本计数。音频队列单槽，Packet持有DeviceChunk及该句计数/错误信号；撤权包丢弃，正常撤权不毒化下一句。设备/时钟错误拒绝后续音频；段内失败只撤当前句。回调不访问网络、数据库、模型或普通业务锁，不用设备提交冒充硬件完成。

静态闭嘴图由avatar-2d已准入素材单独生成，复检许可、取消与期限，不接受讲品文字/语音，不借旧候选截图待机；首个完整preplay校验后装入keeper。撤权/帧失败保留合法中性图，父进程EOF撤掉语音后可保留中性图至本地关闭或30分钟上限。此图不授予说话、自动讲品、动作或事实播报权限。动态形象/许可撤销控制面尚未接入；本会话使用固定准入素材，变更需显式停机重新准入。

LocalPlaybackMedia v2传每帧SHA256、独立待机SHA256。全描述符摘要由私有grant绑定；keeper逐帧seek/read/hash，不把整句RGBA读入内存。v1保留64MiB闭包路径，v2单帧16MiB、每句20秒/512MiB、最多2400帧、描述符256KiB；producer流式写和计算摘要，不读回整句。v2展示准入依赖对应逐帧摘要，frames_sha256全文件摘要保留为producer离线诊断，不能把只检查文件长度说成完整校验。

这是有复制的受控本机文件后端，不是正式共享内存/零拷贝，不完成长播/OBS/硬件PlaybackAck认证。强杀遗留文件的自动清理、输出预热UI与待机微动作仍待做；单作业磁盘上限不等于跨多次强杀的累计配额。
