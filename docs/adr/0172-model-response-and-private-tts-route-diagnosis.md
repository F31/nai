# ADR 0172：模型正文与受限TTS路线诊断

2026-10-25，已采纳。文本测试复用既有受校验正文，新增明确响应区域。TTS使用现有任务UUID作为X-Trace-Id，绑定在root内部Request，仅对SiliconFlow官方域名或明确本地测试发送；页面只展示编号，不接受自定义头或路线。

两次真实对照由用户明确授权。debug专用Owner启动方法只在子进程设置诊断路线；正常Owner启动显式清除该覆盖，release不开放诊断方法，业务预演不受诊断环境影响。内部SDK允许可信root选择direct，不添加页面协议或全局代理修改。

独立诊断程序通过原认证IPC/NativeVault链使用保存配置，不取出Key；单独演练工作区，固定模型版本/音色/短句，全局授权与每路派发凭证create_new、sync_all，结果未知仍不重发。没有新依赖或跨语言字段/表迁移。

实际直连与系统代理模式均等待响应超时。此结果只能证明此次切换HTTP代理未解决问题；不排除共享网络/TUN/客户端协议或供应商端处理，不能直接认定供应商故障。后续需供应商按请求编号核查。真实TTS/音画保持未验收。详见[报告](../reports/2026-10-25-v48-05-model-response-and-tts-route-diagnosis.md)。
