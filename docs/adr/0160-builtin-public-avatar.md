# ADR0160：内置公共2D资源与许可观察

日期：2026-10-24。状态：采纳，V48-05工程增量。

使用media-core内独立V4.8资源API生成默认几何形象，root与keeper复用该算法；不依赖旧cue协议或插件实例。两张512×288 RGB888贴图承载闭嘴/开嘴资源，包hash覆盖格式版本、尺寸/帧率及实际像素。分配有界，逐行/逐块检查取消和期限，重新观察必须重算实际资源hash。

新作品随附assets/public-avatar/LICENSE.txt中的独立MIT许可，嵌入二进制并计算完整许可文本hash。仓库根LICENSE为Apache文本而Cargo标识为MIT的既有不一致不作为本资源授权依据，本轮不修改其他代码或第三方资源许可，也不声称已完成全仓许可审计。

引擎公共候选检查可以将真实visual轴置为passed；独立keeper以同一已核验资源显示静态待机形象，并传递视觉元数据。控制面不传PCM或像素。形象存在与健康租约不授业务媒体消费、公共guard或批准，live_ready/audio_active保持false。开嘴资源本轮不由语音驱动，不作口型/设备帧率/OBS认证。

下一步仍为公共守门和业务音画数据通道，之后才可验证完整批准与播放闭环；自定义资源导入及其独立许可管理未实现。
