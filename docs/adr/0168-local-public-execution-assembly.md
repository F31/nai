# ADR 0168：本机公共单句执行装配

日期：2026-10-25。决策已采纳；本轮Windows单句执行实测与开发版更新完成，不授产品验收通过。

内容批准与实际执行继续分开。执行key和每次准备UUID只在root/原生父进程/固定keeper之间私有传递；页面只明确请求本句Start/Stop，不参与挑战和续租。实际设备初始化后刷新消费者挑战，root复核持久权威与真实准备回执，再签发至多500ms独立执行租约。健康续租不能延长执行。

CPAL适配器提供callback授权闭包，实际窗口用原子执行围栏；私有试听保持原有期限语义。音频和嘴型共享源样本提交游标，像素用进程内最新快照而非控制消息。原生轮询只有在明确Start成功后才持续复核续租；停止/撤销/P0/失败均不会自动恢复旧流。完成只记提交，不虚构硬件播放ACK。

不新增常驻依赖，不改存储Schema，不使用本地LLM/TTS。原批准草稿上限30秒但不延长来源或guard期限。真实声画延迟、OBS录制和扬声器完成保留待实测。详见本轮报告和OpenSpec变更v48-05-public-playback。

开发运行验证后的补充：30Hz绘制不节流控制响应；nai-media-core和sha2的dev包级优化保留全部校验与原期限。原生定时续租独立于页面；状态快照500ms失效，普通用户命令预占并仅在派发前有界等锁，P0不等待。测试与认证范围仍是单公共窗口；硬件完成和OBS不由静音夹具授予。
