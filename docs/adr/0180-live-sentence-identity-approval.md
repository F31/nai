# ADR0180：句级源身份、提交检查点与批量文本批准

日期：2026-10-26；状态：采纳。

新建V48-07队列采用句级身份。计划哈希使用域分隔nai-live-text-plan-v1及生成的Protobuf编码，绑定发布源、run/epoch、有序全文和界限；排除可变revision/current_start及批准视图。创建前执行128句/32KiB总界限，失败不留下会话。旧单元队列保留历史并标Unavailable，只允许明确结束重建，不自动迁移或获得新执行权。

PreviewLiveSentence只允许当前与下一句。通常Preview用于新队列时也选择当前句；私有预演工件持久绑定全局句索引、单元内索引及计划哈希。既有TTS的父预演SHA和音画候选来源继承该身份；读取、派发及root公共回执复检，后句准备不允许越序输出。每个可信完整提交推进一条句检查点，仅单元最后一句完成时推进单元；重复回执不多计。中断未知时明确跳过剩余当前单元，句数及单元数分别记录跳过，不冒充提交。

公共政策升级为nai-public-exact-spec-v3-sentences：先验证整段话术恰为支持的物理规格事实表达，再仅允许同一确定分句器得到的完整句。禁止任意摘取、改写或通过安全句隐藏整段风险/禁用短语；金额、风险和未知规则仍拒绝。语音/画面资源和消费前复检保留。

批量文本批准持久于受保护队列对象；管理员明确核对全部原文及使用权后，CAS绑定计划哈希与session/epoch，最多有效五分钟。记录签发时间以拒绝时钟回退，并保存最多32个已用批准ID，替换后也不能复活撤销ID。撤销可清理失效来源的文本范围。该批准不复制实际单句音画批准，不授予费用预留、媒体permit或直播平台权限；本切片仍需逐句合成、批准实际音画及播出。

后续自动衔接必须装配root的有界预取，将范围批准与实际模型/音色、费用及输出目标授权合并复检，子任务取消继承既有取消树；文本撤销须阻止后续消费。随后才接插问归位、真人独立麦克风与整场OBS验收。不用本切片局部测试升级164项ACC。
