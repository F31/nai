# ADR 0156：公共待机keeper与健康租约

日期：2026-10-24；状态：采纳；V48-05进行中。

新线按需启动独立nai-public-output-keeper，复用锁定minifb创建Windows常驻公共待机窗口，不将旧线output-keeper或私有试听直接改名当新线完成。新进程只处理固定健康消息，不接收业务文字/图像/PCM，因此无需冒用私有审批。

健康租约不是媒体授权。复用LeaseGate挑战锚定算法，但协议命名和控制入口独立；优先停止标记也独立。终态不能恢复，必须显式重开，公开状态始终live_ready=false/audio_active=false。窗口刷新计数只证明静态待机呈现。

本轮新增1个按需媒体进程，无云/数据库/模型/音频服务依赖；关闭窗口或宿主正常退出回收。独立进程stdin读线程和有界队列隔离半包阻塞；静态待机不包含私有内容或外部资产。真正公共音画bundle、2D资产/时钟、硬件音轨及OBS故障认证仍是V48-05后续，不以待机窗口代替。
