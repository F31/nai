# ADR0163：匿名PCM准备工件与源样本嘴型时轴

日期：2026-10-24。状态：采纳，V48-05工程增量。

复用实际TTS缓存，在最多2项、每项4秒的后台工作中建立匿名PCM文件。取消后worker仍占在途容量直到退出，防止反复释放造成无限线程。工件与原缓存共享截止时间，不续签权限；匿名文件依最后句柄释放。控制面只传描述和hash，无媒体字节或路径。

media-core复用内置许可资源，按24kHz样本位置每800样本生成一帧实际嘴型像素，整数RMS与攻击/释放平滑，不使用墙钟或网络到达时间驱动。跳帧不积压像素，尾帧准确覆盖样本；错误/取消/倒退终止该渲染流。准备描述绑定渲染器版本及首帧hash，公共bundle和可信权威状态绑定完整描述hash。

匿名文件写入后实际读回与首帧渲染比对才发布准备状态。准备状态与批准、设备提交/完成回执分离；原合成计费不因准备失败被撤销。当前消费者在root内，跨进程只读句柄broker、公共批准生产装配、keeper音画和OBS仍未完成，164ACC不升级。
