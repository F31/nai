# ADR 0181：原生两句预取与自动公共输出

日期：2026-10-26。状态：已采纳，工程交付与原生定向实测完成；整卡及长稳验收仍进行中。

V48-07采用单一可信原生Owner编排，不让网页计时器承担直播调度。整场文本批准之外，操作员显式授权模型配置、音色、累计调用上限、实际本机输出和形象许可；授权不超过文本批准期限。每句继续经过真实音频、当前来源、政策、内容bundle和独立媒体租约检查。最多当前与下一句，已提交缓存释放后才能补入后续句。

范围/派发记录保存在受保护live_run中，单次调用无自动重试，未知费用不回退。重启、源/模型变化、撤销或停止不恢复旧自动授权。暂停当前句边界，人工停止先清输出后做数据库清理。内部准备/批准命令禁止页面调用。

普通请求等待只维持输出健康心跳；媒体授权仍须全新挑战和root复检。自动请求的持久检查点在静音预装载阶段提交，随后才领取播放挑战；失败保留不确定状态。固定正文的纯Schema校验只缓存最多64个SHA256摘要，不缓存任何当前授权或事实时效。

备播与发布Schema分别有64摘要上限。来源证明只能在同一Operation及不可变Store借用内复用，绑定bundle和最早事实/范围/文本/TTS到期；每次复检UTC、取消、撤权集合/P0，重新读取批准账本和实际输出，返回前再检查期限。不会跨请求缓存当前源身份。轻量状态读取不重复续媒体；暂停读取轻量版本后作CAS。

本增量不提供插问归位、真人独立麦克风、设备级无缝切换或平台推流。Windows实际提交不等于硬件播放完成；164项ACC不因局部证据升级。
