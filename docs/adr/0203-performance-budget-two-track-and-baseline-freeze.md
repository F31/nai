# ADR 0203：性能预算、双轨流程与基线冻结

日期：2026-11-11。状态：Accepted（预算文档生效；首个决策输入的矩阵实验见同日报告）。

2026-11-11用户明确修订的首声3秒/首PCM优化目标见[ADR0204](0204-personal-live-experience-budget.md)；该项优先，模型冻结和安全边界继续有效。

## 背景

V5.6.1 基线（ADR 0193）执行一周内约 30 个归档切片，34 项 ACC 全部 pending 未移动。
实测显示形象生成存在组件级吞吐赤字：稳态计算/音频 1.42–1.78（RTX 5090、768px、4 步），
而近期五类微优化（条件复用 1.1–1.4%、GEMM autotune 约 2%、FP8 算子/整图无净收益、
图重放 3–5%、FP8+图组合 13.3%）合计无法闭合缺口。缺口是模型级参数选择问题，
不是工程调优问题；同时优化工作先于 M0 端到端闭环，且流程开销（OpenSpec+ADR+registry）
已超过小切片本身的价值。

## 决定

1. 采纳 `docs/performance-budget.md` 为唯一性能预算与工作筛选依据：北极星为 M0 五项；
   优化轮必须先写 Amdahl 上限，上限小于缺口不做；<5% 差异按环境噪声处理。
2. 结构性杠杆按固定顺序推进：去噪步数 4→2、渲染分辨率 768→512（上游默认即 512）、
   编译/量化一次做透并限时。首个决策输入为 2×2 步数×分辨率矩阵（同 PCM、同种子、
   同编译边界），其质量门为黄金帧像素指标加人工审看。
3. 决策门：结构性杠杆全部完成后稳态 RTF 仍 >0.9，则直播路径改用 2D/audio2blendshape，
   FlashHead 转为离线预渲染片段（V5.6.1 已授权的预录片段路线），不继续同精度微调。
   时间盒：自本 ADR 起两周（至 2026-11-25）。
4. 基线冻结：V5.6.1 冻结至 2026-12-09。期间不改基线文档、不重写 registry、不更换
   TTS/形象模型选型；唯一的允许变更是测量门槛强制触发的决策门结果（按第 3 条）。
5. 流程双轨：移动 ACC 的切片走完整 OpenSpec；profiling/探针/候选测量为实验轨，
   只产出 docs/reports/ 报告，不建 ADR、不动 registry、不升级 ACC。

## 影响

- 不再接受「画质参数不可动」作为优化前提；分辨率与步数是需要质量门护送的变量，
  质量门不放宽（口型/身份/衣物人工审看 + 像素指标记录）。
- 诚实纪律不变：实验轨同样如实记录失败与噪声，不以缓存/放宽期限冒充实时。
- 旧编号与历史 registry 规则不变；本 ADR 不移动 34ACC 中任何一项。
