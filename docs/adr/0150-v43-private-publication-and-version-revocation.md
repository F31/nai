# ADR 0150：私有纯内容发布与事实版本撤销

日期：2026-10-22。状态：采纳；V43-RF03发布子任务，不代表整卡或M1完成。

## 决策

1. 沿用新线唯一writer和不可变对象版本。报告、快照和撤销记录使用源JSON Schema定义的保留信封；generic/草稿入口不能创建或擦除这些类型，不允许从删除入口移除历史发布产物。无需新表或旧结构兼容层；为拒绝不理解撤销语义的消费者，新发布组合使用格式2新根与SQLite user_version=2，格式1原数据不打开、不自动迁移。后续规模化索引须另作显式Schema/迁移设计。
2. 快照引用节目、产品、主持与系列的精确UUID/revision/hash，不复制媒体或凭据。首个发布用途仅private/content_only，不能直接作为DeliveryUnit发送。当前保守要求全部产品事实已人工确认且当前有效；主持风格不能扩大事实权限。
3. 发布先生成30秒影响报告，绑定请求主体/角色revision、闭包、水位、字段diff、显式cue→事实依赖和未知项。水位涵盖工作区对象头、会话、交付、角色、全局停止代次及有界排序的撤销scope集合，排除报告自身。Admin提交精确报告hash和显式未知项确认后仍需复核，提交前再次检查报告期限与事实有效性。此API确认不证明真实用户已经在UI审阅。
4. 快照、依赖清单、本地已应用outbox、审计和幂等结果在同一SQLite事务提交。失败不产生半成功快照。普通草稿修改不会替换或撤销仍有效的历史快照；本轮不自动将前版标Superseded。
5. 紧急撤销以指定快照定位错误的产品对象版本，对该工作区中所有引用相同产品UUID/revision的快照收紧许可。独立`v:workspace:object:revision`拒绝意图先于审计持久化，审计回滚或进程重启不能恢复。修订后的新产品版本不被这个旧版本scope误伤。读取及发布重放均按当前许可/有效期求状态，不回读旧成功缓存。
6. 正文仍8KiB，扫描最多256对象（含历史墓碑/报告）、64会话、256交付、64角色；为报告及快照预留容量，超过返回ResourceExhausted，不截断影响分母。撤销scope沿用256上限，版本拒绝意图不静默淘汰。没有新增常驻依赖、进程、端口或云组件。

## 已知边界

自由文本未转换为完整AST，语义正确性仍需人工核对；目前所有活跃会话作为可能受影响列出，因为尚无snapshot-session映射。不是完整素材/缓存图，也不声称精确媒体停播。跨对象版本、hash、类型和事实条件已实测；旧版被撤销而不可访问时报告扩大未知范围，不谎报无影响。

发布状态只说明私有内容快照可用或Blocked，既非设备完成，也非真实用户已读/已采用。当前无备播UI接线和预演发送器；后续消费者必须再次验证版本scope与目标许可。安装、旧资产、Key与许可不改变。
