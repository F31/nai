# ADR0204：个人直播以就绪后3秒首声与连续体验验收

日期：2026-11-11。状态：Accepted（用户明确采纳）。

用户认为800ms TTS硬门槛不符合当前个人本地场景，授权以3秒首次响应结合缓存预取继续。修订ADR0203的对应预算：就绪后从提交到实际设备首样本≤3000ms；包含该次实际LLM生成、TTS与视频准备。冷启动准备单独计时，不预先播放假语音；已备文本的结果不授LLM链路通过。800ms首PCM保留为优化目标，不再独立阻断连续体验工作。

连续讲解保持单TTS常驻、短语义句和一个未来句预取。句间实际设备gap目标≤300ms，持续生成须跟上播放；固定缓冲只能吸收抖动，不能消除吞吐赤字。报告逐句时间线、累计停顿和是否耗尽，短程与30分钟阶段分开。

模型/基线冻结、视频RTF余量、画质门、P0/停止/epoch、业务网络45秒及有界队列不改。预算改变不授任何ACC通过。机器预算为tests/v561/experience-budget.json，文档索引docs/performance-budget.md。优先交付可体验的连续链路，停止为追单项800ms而反复做不足以闭合体验缺口的微调。
