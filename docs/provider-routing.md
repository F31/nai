# LLM / TTS 配置与主备路由

原生桌面界面提供独立的“LLM / TTS 主备与智能路由”面板。浏览器工程控制页不能直接写本机配置。新设置在停止并重新启动引擎后生效。

## 操作

1. 打开右上角“设置”，进入“LLM 文本服务”或“TTS 语音服务”。界面自动载入已有数据库配置；无需读取按钮或先选择技术文件。尚无路由时准备 Agnes/CosyVoice 推荐公开参数，不代表账号已可用。
2. 模型列表直接显示主模型、备用模型及Key状态；点击“编辑”配置该项。常用模型下拉自动填接口，使用其他代理/模型选“自定义服务 / 模型”；TTS提供CosyVoice音色下拉，未知音色以自定义保留。配置ID自动生成只读，超时/token/币种/价格版本在高级区。
3. 每组可添加最多4个备用；点击“设为主模型”直接置首，备用之间可调整顺序。移动携带完整模型/音色/凭据绑定，新模型不复制其他模型Key。所有条目币种须一致，不自动换汇；价格版本用于追溯，不代表导入官方价格。
4. 在“主备与智能路由”选择策略、失败阈值和冷却，再点击“保存LLM / TTS配置”。两组配置和加密Key事务保存到数据根`provider-settings.sqlite3`；`operator-scenes/provider-scene.json`只是使用前从数据库重建的无密钥导出，源包不改。模型或Key未保存时阻止启动、预检与单项测试；读取失败时禁止空表单保存，可显式重试。
5. 各模型填写自己的Key后保存，点击右上角“连接”。首次空引擎库自动初始化，已有库不自动重建；场景/运行配置路径、身份及旧共享Key默认在“连接与工作区”的高级设置中折叠。Key以AES-256-GCM密文入库，主密钥受Windows凭据管理器保护；不进JSON/日志/命令行，保存后输入清空，重启无需重输。空Key保留旧值，填写新值并保存即可更换。
6. 引擎运行时点击“停止引擎并修改配置”；已有会话撤权，旧候选不续用。协议/地址变化会清除该行待保存Key，旧保存Key显示为不再适用，并在保存时清除旧绑定；改模型/音色/顺序保留Key。模型列表每行提供“删除”，至少保留一个模型，删除后显式保存才生效；高级区可单独删除已保存Key。LLM支持OpenAI兼容/Anthropic，TTS支持OpenAI兼容/ElevenLabs/SiliconFlow；真实账户模型/音色可用性需自行测试。

## 策略

**健康主优先**：跳过未配置凭据、熔断或正在试探的节点，按列表选择。默认一次供应商失败后冷却30秒；可配1–5次阈值、1–300秒冷却。冷却后允许一个请求试探，成功清除故障并恢复主优先。

**实测低延迟优先**：在本次运行中已有成功调用的可用节点间比较75%旧值+25%新值的延迟均值；没有观测值时按顺序，冷却节点优先获得一次恢复试探。不并发竞速、不为探测延迟额外付费、不把未知延迟当0。健康状态只在当前进程内维护。

每次请求选择后固定供应商、模型、音色和预算身份。取消、换代或未取得派发权的预算失败不增加供应商故障。已派发后失败的请求不会自动换家重发，避免重复计费；**后续新的显式请求**才走备用。失败的同一候选/预览不会偷偷再次合成，需重新生成、审批新候选。

## 验证边界

预检可以检查所有主备的配置/凭据是否可构造；可选网络探针仅实际测试当前LLM。TTS和备用未逐个联网时，connectivity明确保持not_ready，不给整组认证通过。实际路由由调用结果驱动，不把配置存在当在线健康。

本地HTTP协议服务验证了独立LLM/TTS模型、音色、不同Key、两类主故障后的后续转备、无重复派发及真实持久化预算；Windows壳实际完成配置副本→多Key注入→真实engine→预检→停止后修改。真实付费账号、商业音色授权及生产延迟仍须使用实际配置单独验收。

## 用户提供的Agnes / SiliconFlow配置与逐条测试

首次未配置时已准备公开参数；已有配置可逐项从模型下拉选择 Agnes 或硅基流动，填写对应Key并保存，不再批量覆盖另一组。地址、模型与音色保留用户指定值，SiliconFlow基础路径补齐/v1。预算币种/价格版本是本地管理参数，不代表已知官方账单。

保存后可在每个条目点击“测试此供应商（可能消耗API额度，不播放）”，使用此条已保存Key；新输入需先保存，测试不回显Key。结果仅该项有效，不刷新运行期熔断状态，也不把单项通过替代整机预检或其它备用认证。网络调用≤30秒，总进程≤35秒；失败不自动重试。单项测试采用独立一次请求预算，不计入正式会话累计账本，累计测试费用应按供应商账户限额控制。LLM探针输出不超过配置与128 token的较小值；TTS仅合成“连接测试”，不发声。显示稳定错误码、耗时、实际PCM计数；金额未知不显示为0。
