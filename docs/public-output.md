# 新线公共待机输出

在新备播工作台左侧选择“公共输出”，点击“打开公共待机窗口”。仅此时启动独立nai-public-output-keeper，窗口标题为“nai · 公共输出”，固定显示NAI/STANDBY。

“停止并保持待机”终止本次控制租约，窗口保留；旧心跳不会恢复，需明确关闭后再打开。关闭公共窗口回收进程。已打开时，右上角停止入口也可操作，不依赖业务表单是否正在保存。窗口Esc同样停止健康链路并保留待机。

当前不接入语音、字幕或数字人渲染，不把私有内容复制到公共窗口；页面显示的刷新次数仅是待机刷新诊断。可以在OBS窗口捕获中查找同名窗口，实际捕获/录制仍需人工验收，不代表已完成直播链路。

独立开发版入口为scripts/start-preparation-workbench.ps1，keeper二进制与桌面壳需配套构建；无LLM/TTS Key或付费调用要求。新协议只含健康消息，未来公共媒体必须经过独立授权门控，不能复用健康心跳授播放。详见[本轮报告](reports/2026-10-24-v48-05-public-standby.md)与[ADR0156](adr/0156-public-standby-keeper.md)。
