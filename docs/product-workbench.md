# 商品事实与讲品准备

桌面工作台提供“商品与知识”入口，支持运行中草稿编辑和知识热发布；持续讲品、播放队列、插问自动归位及真人麦克风仍待接线。

2026-10-21：直播台已接引擎单轮四段节目。商品提纲按卖点、规格、适用场景、售后说明编辑，每段最多512字；非四段旧提纲必须显式清空转换后保存发布，超长内容不会截断。连接后读取引擎进度，启动本轮本身不调用API；逐段明确生成、核对审批、本机播放本段精确候选，实际听完再提交引擎确认。状态不确定先刷新，不重发命令。暂停/插问先静音，旧轮不能归位，后续需开启新轮。详见 [本轮报告](reports/2026-10-21-r1-engine-program-workbench.md)。

## 使用顺序

2026-10-22开发增量：节目听完确认会复检精确候选的本机播放报告和有效审批/事实，再将人工复核写入审计数据库；持久失败不前进。节目面板可展开查看审计引用，重启可查看近期记录，但活跃节目不恢复、不自动播报。人工记录不等于机器音画完成或已完成句。实际安装状态见当轮交付报告。

1. 保存连接与 LLM/TTS 配置；已有加密 Key 无需重填。
2. 进入“商品与知识”，读取并编辑草稿，无需停止引擎。“停止引擎（维护）”保留给维护操作；“断开”仍仅断开界面。
3. 填写商品名称、事实来源/正文和讲解提纲。每条事实可设置生效、失效时间：界面显示本机时区，数据库保存UTC毫秒。两项必须成对，失效必须晚于生效；到达失效时刻即不可用。新增事实默认仅本地；仅对业务允许的事实明确勾选“允许发送云API”。
4. “保存草稿”写入数据库，不改变已发布知识；可在重启后读回。
5. 引擎运行时，点击“热发布知识（暂停播报并撤销旧审批）”。引擎先静音并持久化撤权、准备新快照；宿主保存配置并导出后才激活，成功后当前进程立即使用新知识。更新本身不调用LLM/TTS；已经派发的旧模型请求可能仍产生费用，其迟到结果不会播放。
6. 引擎停止时仍可离线发布，下次连接使用新快照。热发布成功无需重连，但必须重新生成和审批；不会恢复自动模式或旧审批。已发布且未修改的提纲可填入提问框；播放仍由现有短句流程完成。

提纲是生成请求的准备内容，不是已审批的话术，也不是已执行的节目队列。普通闲聊与无知识依据的承诺不会因此被放开。

## 状态与边界

- 一份当前商品草稿：名称最多128字，事实1–32条、每条正文最多4096字，提纲1–16段、每段最多1024字；每条事实支持成对有效期。暂不支持文件解析、多商品目录与形象选择。
- 旧草稿未声明时间时保持“未知”，不会自动补永久有效。普通手工问答仍遵循现有知识门控；讲品提纲的载入、生成和归位要求所有商品事实当前有效，未知/未生效/过期时拒绝并提示来源。请补充有效期并显式发布。清除有效期会恢复未知，不能绕过节目校验；保存草稿不等于更新已发布事实。
- 已声明时间会进入知识快照：检索排除未生效或过期事实；候选与生成/合成deadline不超过最早证据期限，期满后即使原审批尚在也拒绝新合成/播放，在途任务取消且不自动重试。已派发API可能仍计费；时间有效不代表业务内容真实性已由系统认证，也不替代五面完整重校验。
- 配置位于现有 `provider-settings.sqlite3`；v1→v2先由SQLite生成一致备份并刷盘，再以事务和user_version升级。加密凭据表不参与商品编辑。程序降级不能直接读v2，应走维护升级/恢复流程，不覆盖新数据。
- 草稿与Provider场景共同参与版本检查；旧表单遇到别处保存返回 `PRODUCT_REVISION_CONFLICT`。不得绕过冲突重试覆盖。
- 发布使用新scope、snapshot与document ID，热发布拒绝覆盖当前快照或复用旧文档命名空间。新scope准备后保存失败，不切换绑定，数字人保持暂停；请修正后显式重新发布。暂存目录自动清理。
- 激活要求已导出的持久场景与准备的知识内容完全一致，并复检会话epoch和版本。若持久配置已保存而激活未确认，宿主保守停止引擎以保护输出，提示重新连接加载新知识；新配置不会静默回滚。正常热发布保持同一进程。
- engine热切换和重连均先静音、持久化撤权并废止旧审批，再切换知识绑定；普通 `bind_session_knowledge` 仍保持冻结。新绑定仅接受活动快照和匹配的已撤权代次。P0控制不等待宿主的整段发布锁；真人音轨尚未在nai接线，不宣称已完成真人音轨验收。
- 原生命令 `product_workbench` 仅接收现有 `StorageRequest` Protobuf，返回 `StorageResult`；value是 `schemas/config/product-draft.schema.json` 配置字节。无新增JSON媒体消息、云请求或常驻服务。
- 热发布复用受保护控制通道访问 `POST /sessions/{id}/knowledge`，需要 `knowledge.publish` 权限、session/epoch/版本/seq、prepare或activate及受控暂存引用；不接受任意文件路径或URL。异步作业结果在 `/events` 中列出。
- 当前不修改已安装版本，不代表OBS录制、持续数字人输出、真人音轨或平台开播已经验收。
