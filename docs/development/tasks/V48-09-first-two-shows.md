## 顺序与出口

1. 选定真实工作区/产品，核对少量规格、限制和FAQ；记录已有准备方式的人工工时，未知则保留未知。
2. 保存并核对第一场的产品、节目与发布快照，私有预演确认对象/声音/形象及P0；常规模型调用遵守已配置预算和固定期限。
3. 首轮目标约30分钟发现流程问题；真实问题在入池时关联场次。插问、接管、恢复按所选组合操作，记录失败，不擅自推流/录麦。
4. 结束第一场，选择一条有实际依据的问题整理为重点，核对回答事实和三方差异，创建独立下场草稿。
5. 打开新产品/节目，重新复核发布，建立全新第二场；第二场实际使用改进的FAQ。保留/修改/拒绝均可，拒绝不算程序失败但不记为已采用。
6. 核对版本链和实际回执，分开报告本机提交、人工听感与平台观察。记录两场准备/等待/排障和复盘用时，缺基线不计算节省。
