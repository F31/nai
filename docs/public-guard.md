# 公共规格守门首版

2026-10-24升级：当前政策ID为nai-public-exact-spec-v2，绑定原生宿主核验的实际公共窗口UUID。请先打开公共待机窗口，再合成本句并检查；无窗口、终止、挑战超期或重放不能复用旧对象。下述规格原文范围保持不变，仍不授业务播放。

“检查公共播出准备”现在会在实际资源观察后复核规格原文。不调用模型API，不自动改写内容，不发声；守门通过也不是公共批准。

支持的规格为容量（毫升/升/mL/L）、净含量（毫升）、重量或净重（克/千克）、长度/宽度/高度（厘米）和直径（毫米）。必须是当前有效且已人工核对的正十进制值，按话术引用顺序逐项播报，每句格式为“款式+规格名+为+原值+单位。”。本句最多引用8项，沿用256字符/1024字节语音上限。

款式限空、标准款、大号/中号/小号、大容量款、基础款、经典款、白色/黑色/蓝色/红色/绿色款。可选“这是一款商品名，”前缀，商品名限便携水杯、水杯、保温杯、收纳盒、背包、量杯、玻璃杯、不锈钢水杯、储物箱、旅行箱、桌子、椅子、水壶、保温壶、杯子。其他组合不自动放行。

例如“这是一款便携水杯，标准款容量为500毫升。”可进入受限政策复核；“这款水杯适合出行，标准款容量为500毫升。”因自由改写被阻止。此限制不表示改写一定错误，而是尚未纳入确定性政策。

禁用规则只接受“禁止：/禁止:/不得宣称/不得承诺/不得提及/不得声称”加一个明确字面短语。条件、例外、无法处理的语法和命中的短语会阻止；高风险、金额促销词也会阻止。不提供任意语义、医疗/金融承诺或法律合规判断。

页面显示通过、已阻止、未就绪以及原因；30秒内的复核也须在真正消费时重查。过期后手动重新检查，不续期旧批准。当前业务公共输出仍未接通，不能仅凭guard通过开始播出。详见ADR0161与本轮报告。
