# 768 VAE 卷积内存布局探测

用户认可的 768 原图构图，实际 LTX VAE 将重复参考图编码为 `[128,5,24,24]` 潜变量；同一潜变量用于两种独立解码。未运行数字人主模型、语音播放或 OBS。PyTorch 2.7.1+cu128、RTX 5090 Laptop、bf16、无编译；每种布局先预热，再执行 3 次同步计时。

| 布局 | 三次耗时（秒） |
| --- | --- |
| 原始连续布局 | 0.4806、0.4007、0.4394 |
| Conv3d 权重与潜变量 channels-last-3d | 0.5879、0.5281、0.5743 |

候选在这一轮未显示加速。两个 `[1,3,33,768,768]` 输出均为有限值，最大绝对差 0.0078125、平均绝对差约 0.00000531；不能据此断言位一致或视觉效果已验收。两种布局顺序固定，样本数少、GPU 功耗未控制，不能归因细节或计算稳定加速比；更不能外推到已编译的 VAE/完整模型。

新增独立 `scripts/flashhead_vae_layout_probe.py`，把检查限定在 2–6 次、256–1024 的 32 倍数尺寸，输出以独占创建 JSONL 记录成功或失败。实际探测日志 `target-windows/flashhead-acceptance/vae-layout-768-20261106.jsonl`。未修改正式 VAE 权重、模型默认、用户数据或 Qwen 环境；候选不接入工作台。下一步仍需寻找更有效的、保留四步画质的计算路径，并以真实联合音画衡量，不以此推断 768 实时已通过。
