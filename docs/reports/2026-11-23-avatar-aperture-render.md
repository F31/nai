# 显式开口控制渲染探针

用四张独立留出帧各渲染0.65×、1×、1.45×三档，固定现有唇部地标和144像素局部底片，通过局部逆映射控制纵向形变。12张输出区域外像素差为零，1×对照与输入逐像素相同。OpenSpec严格校验及CPU运行通过。

对照图可见，原片已有口腔内容时可以调整开合。接近闭嘴的帧主要拉伸原有嘴唇，无法合成自然的张口及牙齿。这限制了单纯几何变形能覆盖的语音范围。下一步用连续留出段验证音频曲线驱动，在源口型无法覆盖目标时统计不足帧，并评估使用同人物、同姿态的真实口型素材。短探针未验收口型同步、全帧回贴、真实音画或实时输出。
