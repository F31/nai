# 单房间活动任务装配

## 实现

在 app 层新增 `nai-workbench-engine::v561_tasks`，不接入历史 foundation 可执行入口。Tasks 只保存一个活动任务，讲解/回答/真人按 kernel 优先级替换，替换先失效旧所有权并取消旧 Operation；期限无效或优先级不足的请求不破坏当前任务。模型 I/O 在槽外消费 Task.operation 子任务。

完成回执用不可伪造的进程内 Arc 身份绑定活动任务，拒绝跨装配实例、重复及旧回执。完成/失败收尾和过期任务只释放对应槽，不自动恢复讲解；恢复由显式 begin 创建新代次。该完成接口是任务收尾，不能当作模型事实正确、媒体播完或硬件停止回执。

kernel 新增可持有的弱引用 OutputLease，绑定签发实例和代次，显式 release；丢弃克隆不自动释放。独立 StopHandle 仅持弱引用，可不等待任务槽直接原子 stop，当前实例终止后不可重开；Tasks 析构撤销全部在途任务。没有新增常驻线程或等待队列。

## 实测

- 新装配5项测试通过：优先级/迟到完成/显式恢复；无效输入及跨实例；独立线程停止和析构取消；超时收尾；接管取消真实回环 HTTP 的 Qwen Adapter 等待且不重试。
- kernel 所有权7项回归及原LLM/TTS取消2项回归通过。
- app lib 定向 clippy（-D warnings）通过，OpenSpec严格校验通过。构建缓存始终在 E 盘；工具链硬链接失败时复制提示保留。
- CodeGraph transport closed，本轮回到源码、rg 与定向测试确定依赖影响。
- 没有调用真实模型或付费 API，没有开启麦克风、OBS 或更改用户数据。
