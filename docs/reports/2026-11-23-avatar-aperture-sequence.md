# 连续底片音频开口控制

对原音频连续留出帧3728–3827应用开口探针预测。100帧／25fps，左侧原始局部画面，右侧开口驱动，音轨取对应原语音。渲染限制为已测试的0.65–1.45倍，源开口比低于0.03且目标要求放大时保留底片。阈值为本轮实验选择，并非人体通用常数。

36帧超出倍率范围，20帧因近闭口放大而保留底片，其中18帧重叠，合计38帧无法按当前规则直接使用目标倍率。统计包括预测误差带来的目标偏差，不能把38帧全部归为几何能力不足。输出4秒视频，ffmpeg完整解码通过。未做人工听感或新语音验收。下一项验证从训练段挑选同人物、近姿态的真实口型是否能覆盖缺口。

录像和逐帧证据位于target-windows/avatar-region-research/aperture-sequence-20261123。OpenSpec严格校验通过，生产及验收状态不变。
