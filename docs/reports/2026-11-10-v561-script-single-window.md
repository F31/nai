# 跨句输出连续性第一切片：一段讲解共用一个窗口

## 实现

窗口由脚本协调器创建并持有，每句音画输出借用同一Window，不再逐句创建/销毁。等待下句源时每次最多10ms接收等待并处理窗口事件；关闭/Escape取消整段，旧源不可继续消费。单句诊断入口仍创建自身窗口，不保留兼容格式或新后台服务。每句结束清安全画面，整段完成/停止/失败后释放窗口。

新增source_wait_ms、gap_from_previous_device_end_ms及实际OS窗口身份报告。时间均使用脚本同一单调时钟；窗口复用不是设备复用或提前生成下一句视频。P0/媒体租约、200ms时钟及45秒整段期限保持。
