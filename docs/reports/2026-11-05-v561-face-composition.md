# 人脸构图与口型质量诊断

用户反馈既有 384×384 半身构图的嘴部变形明显。录像抽帧可见较小脸部区域在说话时存在口部拉伸；可能原因包含输入中脸部所占像素、模型本身、音频及运动建模，当前未做受控消融，不能认定唯一原因。

以已授权肖像自动检测单脸，并使用比例 2.8 的独立人脸构图、512×512 FlashHead Lite 和同一段 Qwen 语音生成 6.72 秒离线对照。用户观看反馈「明显改善，可以继续」。片段 `target-windows/flashhead-acceptance/jjf-facecrop512-mouth-review.mp4`，实际解码 168 帧、25 fps、512×512、24 kHz 单声道音轨；这是离线质量样片，不是实时性能证据。

新增 `scripts/flashhead_portrait.py` 和诊断开关 `--face-crop`，可配置人脸留白比例、检测阈值及构图尺寸；保留原图，检测到零张或多张符合阈值的人脸时明确拒绝，不使用上游静默回退。裁剪参数写入诊断事件，临时构图位于 E 盘报告目录并在模型读取后清理。几何/无脸/多人/无效参数定向测试 3 项通过；真实授权肖像处理结果与用户认可的构图逐像素一致，空白图在模型加载前明确拒绝。

使用原始授权肖像、自动构图、512×512、已有语音和窗口设备链路进行 1.92 秒验证：48 帧送达并提交，未记录安全画面。两块短样本不能证明实时或长稳，素材构图也没有修复模型在所有音素、角度或人物上的变形。构图开关目前仅接隔离诊断，尚未接正式工作台；原 V5.6.1 十分钟失败、共享内存权限及 OBS 长时验收状态不变。
