# 形象准入与预览缓存接线（2026-10-28）

## 本轮

原生选择后的内部准入将已生成 PNG 移交给工作区、素材包摘要和许可摘要共同索引的私有预览槽；返回结构仅为身份元数据，不带 PNG 或本机路径。选择取消不创建包。实际样例包通过安全读取、渲染和缓存后可按相同身份读取，其他工作区不可读取。此代码路径尚未向网页注册，输入中的工作区标识未成为可信身份，也没有实际二进制协议端点。

Windows 定向 `avatar` 模块 13 项通过，包括导入到预览、损坏和越界拒绝、junction 并发替换、缓存替换/清除及数据边界。一个构建目录的测试可执行文件仍被 Windows 锁定，使用 E 盘另一已有目录复测通过；不能据此判断锁定是由之前关闭的应用导致。
