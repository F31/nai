# WASAPI 设备与公共语音采样率映射补验

扩展既有独立静音 Windows 设备测试：在同一 WASAPI 48 kHz 设备流中同时核对设备帧和 24 kHz 源样本映射到 25 FPS 视频帧的一致性，停止后再次核对位置。真实设备实测通过：384000 Hz 时钟、24007 设备帧、48 次观测、12 次视频帧变化；不输出语音、不生成播放回执。此测试只使用零起点连续静音流，并未覆盖真实业务音频队列间隙、重采样边界、暂停恢复、设备失联和公用输出租约。

生产同流 WASAPI 适配器尚未实现；CPAL 和独立 WASAPI 仍是不同流，不能据此接入硬件时钟。下一步需实现同一流上的受控写入和设备位置采集，按 cue 起点处理前置静音及排队位置，验证撤权后先停止输出，再进行真实音画/OBS。
