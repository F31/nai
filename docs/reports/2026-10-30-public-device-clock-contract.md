# 公共输出设备时钟契约增量

workbench protobuf 新增可选设备时钟观测，包含输出实例、准备对象、会话/epoch、流代次、设备频率和位置、采样率及已播放样本。缺失代表不可用；提交样本数保持原义，观测不构成播放完成或输出授权。Rust/TS/C++ 由项目生成器生成并通过 schema --check（281 条消息无漂移）。宿主在同流设备适配实现前拒绝带该字段的状态，避免把未验证的观测作为有效播放进度。

公共输出 Windows cargo check 成功，宿主库 8 项测试通过；最初带过滤词测试实际运行 0 项，随后改为运行全部宿主库测试。首次沙箱内 protoc 启动报告 Windows DLL 重定位错误，受控环境复跑生成和无漂移检查通过。

本轮仅完成契约及暂时拒绝，不提供真实设备位置，尚未实现验证流代次、设备断联、播放帧映射和 OBS；OpenSpec 任务保持未完成。下一步为同一受控 WASAPI 设备流的时钟适配、验证和接线。
