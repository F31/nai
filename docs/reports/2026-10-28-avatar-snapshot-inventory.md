# 形象备份快照清单一致性（2026-10-28）

在隔离备份原型中，将有界 SQLite 快照和形象包引用枚举接为一步，枚举以快照连接为准。定向测试确认源库在快照后变化不会改变快照清单，缺失引用文件和取消会失败；形象备份相关 3 项测试通过。

原有构建目录测试程序被占用，使用 E 盘 `target-windows/avatar-backup-snapshot` 完成验证。该代码仍为内部原型，没有修改用户数据库或运行版。素材复制与独立核验、数据库摘要绑定、持久清单、迁移日志和崩溃恢复尚未整合；可信许可、公共渲染和撤权停播仍未完成，不能视作播出授权。OpenSpec 保持进行中，164 ACC 不变。
