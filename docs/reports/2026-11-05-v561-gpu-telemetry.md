# FlashHead GPU 遥测修复

此前直接终止 `nvidia-smi -l -f` 后遥测文件为空，不可用。新增 `scripts/flashhead-gpu-telemetry.py`：逐次有超时地执行 nvidia-smi，每条 JSONL 行立即刷新，记录 Unix 毫秒与单调时长；功耗上限等不可用数据为 null，采样失败单独记录，零有效样本返回失败，部分失败不冒充全成功。采样时长及间隔有界；独立脚本不控制生产输出。模型诊断事件增加 Unix 时间戳以便对齐。

验证：3 秒真实采样 3 条、0 错误，功耗上限 [N/A] 正确为 null；指定不存在程序时产生 sample_error、0 样本、failed 和非零退出。15.36 秒语音跨度的模型诊断与采样对照中，遥测 25 条、0 错误，11 条位于模型 ready 至 complete 的生成阶段；首样本晚于 ready 0.391 秒、末样本早于 complete 0.440 秒，生成阶段样本最大间隔 1.027 秒。其间采样功率 22.71–136.55 W、温度 54–62°C、GPU 利用率 0–98%、整机显存 10375–10377 MiB；功率上限 unavailable。1 Hz 抽样不能证明精确峰值。

模型 ready 9.500 秒、完成 20.328 秒；16 块平均音频特征 0.0347 秒、视觉生成 0.6349 秒、前向总计 0.6696 秒。它与上轮约 1.014 秒/块存在波动；样本、运行条件和阶段覆盖不同，不能断言速度变化由功率、温度或后端选择引起。此前 55 秒遥测试验有 55 个有效样本，但只覆盖生成阶段前约 13 秒，记录为部分覆盖。

原始文件 `target-windows/flashhead-acceptance/model-aligned-20261105.jsonl` 和 `gpu-aligned-20261105.jsonl`。本次使用已授权肖像和既有语音，不播放、不推流，不发新 TTS 请求。诊断不传输画面、不提供音频时钟，不是 OBS 或 10 分钟 M0 验收；系统页面文件配置后的重启仍未确认。
