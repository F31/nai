# 个人直播策略领域增量

实现：`nai-live::personal_policy` 使用项目现有 JSON Schema 校验器消费个人偏好契约，限制输入不超过 4096 字节，解析互动模式、回答触发方式和知识范围。公屏抽样由调用者提供 0–99 的独立均匀随机值，主题独讲不选取公屏；返回值仅表示偏好，不授予平台连接、事件消费或公共输出权限。模块不访问存储、设备或模型；未设定默认值，也未改动现有预算与审批数据。

定向验证：Windows `cargo test -p nai-live personal_policy --offline` 两项通过；个人策略契约 Node 测试一项通过；`cargo xtask check-deps` 通过 31 个 workspace 包。构建和缓存使用 E 盘 `target-windows/live-auto-build`。未进行真实公屏、模型或设备调用。

基线核查：上一轮中断的宽范围 schema 测试中，定向复现了能力目录测试的一项失败：该测试仍断言旧的 `show.plan` 能力目录，与当前 V4.8 目录不一致。其他失败尚未逐项定位，不能认为整个测试套件通过，也不能将所有失败归因于该项。本轮直接调用系统 pnpm 的 OpenSpec 校验因 Node/pnpm 版本不匹配未执行；未变更 OpenSpec 文件。

未完成：策略持久化和迁移、作用域和默认值、个人模式与旧规格裁决、自动回答的权威复检、事件去重和有界队列、智能体与 UI 连接均未交付；注册表状态不变。
