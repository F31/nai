# 隔离 OBS 接收端撤权实验

本机媒体夹具初始隐藏静音。OBS Lua看门狗接收包含本次运行nonce和递增序号的文件续租，失去续租则静音和隐藏，过期锁存至本次录制结束。100毫秒定时器的5次回调是实验判据，未验证调度抖动和绝对停止期限。

发送端保持运行16秒。续租主动中断，之后在发送端仍活跃时发送一次递增迟到续租。OBS只记录一次启用和一次撤权。视频7.854秒起切黑至封口，音轨6.778秒起持续静音至结尾，515帧完整解码。帧和音频时点来自实际录像，音轨静音起点可能包括源内容间隔。迟到续租后仍保持黑静音。

证据位于target-windows/v561-loopback-lease-20261123。文件续租和Lua当前仅用于隔离实验，并未验证真实nai生产端、OBS线程停顿、采集链路时延或恶意本地写入。下一步把续租绑定到实际生产帧和任务代次，单独验证进程失联及显式停止。
