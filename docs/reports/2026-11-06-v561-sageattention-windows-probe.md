# Windows 768 注意力算子隔离探测

目标是在不改变用户认可的 768 原图构图和四步采样前提下寻找实时余量。Windows 原有 PyTorch 2.7.1+cu128、Python 3.10、RTX 5090 Laptop；当前 PyTorch 报告自身 Flash 注意力不可用。

仅在 E 盘隔离目录下载并解包 Windows 社区 SageAttention 2.1.1 wheel；其发布名称标注 torch 2.7.0，与现有 2.7.1 不完全匹配。发布方元数据给出 SHA-256 `3886c0e2c4d428d35fbd665ad28a3e76674443d74f54cafae4a1de699becc6cf`，下载文件匹配；这仅验证文件与发布元数据一致，不能证明供应链安全、正式 ABI 兼容或适合发布。未替换原 PyTorch、Qwen、系统包或正式运行路径。

真实 GPU 小算子对照在 bf16、头维 128、长度 128 下执行，输出有限，与当前 PyTorch SDPA 比较最大绝对误差 0.03516、平均绝对误差 0.00400；量化结果不要求位一致，单个随机样本不能证明模型口型/身份质量。

真实 768/四步模型：独立 Sage 路径首轮编译包装模式后 6 块平均 1.437 秒（1.348–1.561），不编译模式后 6 块平均 1.475 秒（1.455–1.525）；各块对应 0.96 秒语音。默认后端此前另一轮编译音画平均约 1.278 秒。测试非交错且未严格控制功率/其他负载，不计算可靠加速比；本轮未发现实时收益，未采用候选、未做用户画质验收。日志 `windows-768-sage211-20261106.jsonl`、`windows-768-sage211-eager-20261106.jsonl`。

上游模型代码在 Sage 成功导入时优先使用它；补充的隔离诊断 `attention_import` 和 `--require-sage-attention` 可拒绝未导入的静默回退，实测显示导入成功并完成 24 帧。但导入标记不证明每个注意力调用都使用该算子；首轮编译测试没有标记，也不应把它单独当作完全路径证明。量化误差、权重画质、二进制与平台兼容性及长稳未验，不把 Sage 加入默认环境。

进一步工作应在控制功率/时钟和同一负载下研究上游 Windows 官方可构建算子、模型计算和 VAE 解码优化；保持用户认可的四步画质，不因短片缓存表现通过 M0。官方项目及社区构建信息：[SageAttention 上游](https://github.com/thu-ml/SageAttention)、[Windows 构建发布](https://github.com/woct0rdho/SageAttention/releases/tag/v2.1.1-windows)。
