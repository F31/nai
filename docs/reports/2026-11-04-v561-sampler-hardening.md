# V5.6.1 M0 采样修正

本机实际为 Windows 11、RTX 5090 Laptop GPU（驱动 610.62，24463 MiB 显存），物理内存约 32 GiB。此前“等待目标机”的记录已纠正。当前 `127.0.0.1:8000` 拒绝连接，OBS 未运行；FlashHead Lite 权重完整性、worker、Qwen 0.6B 和完整音画链路尚未验证，M0 仍未执行。

M0 采样脚本此前会向已有目录追加样本，且汇总时访问错误层级使 GPU/内存统计始终为空。现拒绝非空输出目录，使用单调计时记录实际运行时长，同时记录墙钟时长、每个样本相对时间和最大墙钟采样间隔，并修复汇总层级。输出时长与间隔只是原始证据，不自动给出通过结论；异常终止时不保证写出 summary。

`tests/v561/baseline-boundary.ps1` 验证旧证据保留并拒绝重用；10 秒本机短测采集 3 条，汇总 GPU 温度及内存非空，最大采样间隔约 5.9 秒，脚本开销使实际采样时长约 13.3 秒。此次未启动模型、直播或 OBS，短测不是 M0 验收；正式连续性判定需要核查采样间隔，当前采样频率不足以证明短时故障不存在。
