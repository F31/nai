# 2026-11-08 有界增量形象输入层

## 实现

新增v561_avatar_input：块几何由调用方的已验证Ready传入（当前40帧，对应38400个24kHz样本），一个待装配块，满块同步回调形成背压，epoch/task/start_sample连续。流尚未完成的满块明确eos_verified=false，仅供临时计算；尾块只在现有CosyVoice适配器验证实例/请求/数量/摘要完成回执后交付。任意供应商、回执、回调或取消错误均取消同一父Operation，不重试，不产生播放许可。返回Summary才证明整个输入完成，不能把最后一个满块的到达当作完成。

新增原生诊断v561_avatar_input_probe，仅消费真实HTTP块并记录时刻，不运行GPU、不播放或保存PCM。现有worker协议6和正式播放路径未改；内部结构不是跨进程契约，不手改生成代码。

## 验证

3项定向测试通过：不同分片完全一致的源字节/偏移/身份与EOS尾块；错误计数和取消不放尾块；消费者首次失败停止后续交付、总量超限原子拒绝及奇数字节拒绝。诊断构建/clippy通过，只有既有E盘增量硬链接复制回退警告。

## 技术判断与后续

当前backend一次读取完整PCM、整段librosa 24k→16k重采样，并在每次render重置motion。直接对各块重复调用render不成立，会破坏运动连续性和滤波边界。下一项须先修改正式schema并生成：Begin/有界原始PCM块引用/序号与摘要/EOS/取消；Python维护有状态重采样和单任务motion/history，Rust保持源时钟与有界背压，再将本输入层连接GPU。小于完整推理块的首PCM尚不能驱动当前40帧推理，不能把2586ms说成首视频或首声时间。

整句EOS前的生成仅可视为可撤销的临时计算；是否允许已验证传输格式但尚无最终应用EOS的源实际外放，必须在后续规格中明确失败即时停播语义，不能由本输入层隐式授予。缓存仍只接受完整成功源。

本轮没有接入worker/GUI或更新安装版，不授公共音画、OBS/长稳通过；34ACC保持pending，M0仍No-Go。
