# 重放旧租约后句子时钟停住

## 结果

同一条静音实验流在句子进行中重放已经用过的租约。重放被拒绝，随后也不能再取挑战。失效前的读数是已播放 435、提交 1440、设备位置 23864、频率 384000、流代次 1。

流退出时已播放 676、提交 1440、设备位置 27720，流代次仍是 1。提交没有增加，676 不超过当时的 cue 上限 1440。已播放从 435 增到 676，是退出前已经提交的缓冲区还在播完，不是取消之后又提交了新样本。设备位置从 23864 走到 27720，发生在流退出之前。

退出后再等 50 毫秒，已播放仍是 676，提交仍是 1440，设备位置仍是 27720。接纳规则接受这条观测。

被忽略的 `cancelled_lease_stops_the_sentence_clock` 本次显式运行通过，用时 1.29 秒。`openspec validate v49-realistic-avatar --strict` 返回 “Change 'v49-realistic-avatar' is valid”。1.3.10 和 1.3.11 都没有勾选。

## 没有改变的路径

公共 CPAL 播放仍只使用提交游标，不读 `IAudioClock`，状态里继续不填设备时钟。没有装配公共输出，没有拔设备，没有把 cue 的设备帧区间写进协议。没有真实公共音画或 OBS。没有跑 MuseTalk，没有重绑定位缓存。这次用的是重放旧租约，不是暂停，也不是句中那段时钟仍在走的静音。
