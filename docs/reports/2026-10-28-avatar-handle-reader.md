# 形象素材目录句柄读取（2026-10-28）

## 已实现

桌面壳的内部读取原型新增 `cap-std` 和 `cap-fs-ext` 4.0.3（及其锁定传递依赖）。Windows 以禁止删除共享的目录句柄打开选中根目录并拒绝根 reparse point；每个子目录通过 no-follow 相对句柄打开，最终文件也 no-follow、核验普通文件并有界读取。桌面代码不引入 unsafe，依赖自身包含平台特定 unsafe；没有引入常驻进程。

## 验证

- Windows 定向 `avatar::tests` 9 项通过，包括静态目录 junction 指向外部拒绝、并发将子目录替换为指向外部的 junction（1000 次读取，验证发生实际替换）不能读到外部数据、路径和大小约束，以及原有包完整性测试。
- `v48-avatar-management` OpenSpec 严格校验通过。原测试可执行文件被 Windows 锁定，最终回归在 E 盘 `target-windows/avatar-baseline-check` 独立目录完成。
- 非 Windows 根目录打开仍是原型，不声称具备同等防竞争保障；当前验收只覆盖 Windows 和上述具体场景，不等于完整文件系统安全认证。

## 未闭环

函数尚未连接原生目录选择和独立素材传输；现有页面的原型上传不能作为生产导入。必须补齐可信许可来源和撤权复检、事务性选择与公共输出绑定，再实施真实窗口与 OBS 验收；未开放新入口或更新运行版。形象管理 OpenSpec 保持活动，164 项 ACC 未改变。本轮未调用模型，也未修改用户数据或 Key。
