# V5.6.1 真实短句音画本机诊断

原 Rust 接收器只校验帧并释放共享槽。现将接收器抽为可注入消费者的模块：完成只读映射和哈希核验后交付拥有独立像素副本的帧，消费者接收成功后才确认共享槽。新增单独 Windows 诊断程序，使用有界帧队列及 16 kHz/24 kHz 时间线换算，由同一 WASAPI 流的设备播放观察选择帧，并提交 minifb 窗口；音频为同一段语音的 24 kHz 单声道 PCM。播放线程的许可回调由诊断进程持有，结束或失败关闭。

使用授权 `docs/jjf.jpg`、FlashHead Lite、本机先前 Qwen 实际语音的前 1.92 秒，真实模型生成 48 帧并全部经 Rust 读取、确认；修正计数后再次运行显示 `received=48 shown=48 input_closed=true`，其中 shown 计数发生在窗口提交成功之后，WASAPI 观察到的播放样本抵达音频末尾。输出 `target-windows/flashhead-acceptance/rust-av-verified-20261105.jsonl`；该日志记录模型与传输，不记录 OBS 或主观听感。用户此前授权本地模型和设备联测，无付费 API、无推流。

验证还包括 6 项帧调度测试及跨进程共享槽复用/接收器退出 2 项测试；最初合成帧音画预检也收到并提交 48 帧。短样本中首块模型计算约 2.44 秒、次块约 1.13 秒，对应 0.96 秒音频块；无法推断长时间实时能力，也不能由提交计数推断物理显示、听感或音画偏差。

局限：此程序是隔离诊断而非新工作台的正式入口；模型输入使用预先合成的语音，不是实时 LLM/TTS 连续讲解。共享映射仍缺生产级 ACL、进程身份认证及受控句柄交付；尚未执行 OBS 录制、用户主观音画验收、长时间稳定性或 M0。诊断程序及其独立 C++ 映射助手未作为可发布程序安装。
