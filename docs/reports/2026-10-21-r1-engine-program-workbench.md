# 桌面引擎节目接线

日期：2026-10-21。承接 ADR 0141 / r1-engine-finite-program；规格 r1-engine-program-workbench。本轮不修改契约、引擎或存储迁移，不改变验收注册表状态。

## 交付

- 商品准备提供卖点、规格、适用场景、售后说明四个固定提纲字段，每段最多512字。旧1–16段配置继续可读，但非四段需显式点击清空转换，再保存发布；不自动截断、改库或发布。
- 桌面真实调用已生成类型对应的 ProgramCommand/ProgramView。严格解析响应，绑定节目、快照、epoch、生成请求和候选哈希；确认不本地递增计数。
- 启动本轮不调用 API；显式下一段只提交一次命令，最多160次250ms只读轮询。ACK丢失、超时或读回失败后禁用节目变更，提示刷新，绝不重发生成或确认。
- 本段候选经既有审批工作台批准后，可明确播放本段；按钮仅关联精确哈希。设备提交仅解锁人工听完确认，进度仍取引擎读回，离线预览/其他候选不推进。
- 连接/重连只读已有节目，不自动启动、生成或重播。暂停/结束走既有P0静音；未确认不能声称结束。插问前重读引擎节目，活跃节目必须先取得静音结果再发送问题。
- 移除生产界面的五面勾选归位；旧轮失败/暂停/结束后不能恢复，须静音换代，再显式启动新轮。发布、换代、断开使旧前端关联失效，迟到回调不推进。

## 使用顺序

1. 在“商品与知识”读取草稿，维护事实有效期与云端许可；把旧提纲明确转换为四段，填写后保存并发布。
2. 连接引擎，查看或刷新节目进度；点击“启动已发布四段节目”，再明确生成第一段。
3. 在下方核对本段精确哈希的候选并审批，点击“本机播放本段已批准候选”。实际听完后提交引擎确认，再明确生成下一段。
4. 需要插问时先静音结束旧轮，或由发送入口实时检查并请求静音。旧轮不归位；后续要讲品需明确开启新轮。

## 边界

当前仍是单轮人工辅助，不是持续自动讲品或插问后自动归位。引擎进度仅内存，硬件完成ACK、可恢复检查点、五面机器校验、真人麦克风接管与OBS录制验收仍未完成。本轮没有全仓测试、新设备/安装验收或真实付费 Provider 测试。安装版尚未替换，新功能属于源码与构建交付。
