# Qwen 缓存边界修复

在接线前审查发现：Qwen 缓存键未包含服务地址，使用竖线拼接还会发生字段边界歧义；命中缓存时也未检查操作取消或期限，可能返回已撤销操作的旧音频。

改为包含地址、模型、声线、语言和精确文本的结构化键，避免字段分隔符碰撞；缓存命中前后检查操作和祖先取消/期限，合成成功后写缓存前再检查。失败时不返回音频，且不因缓存命中启动网络。该检查不能替代播放前的 epoch/权限复检，服务端同地址更换权重时仍需调用侧显式管理模型版本或刷新缓存；当前尚未完成生产工作台接线。

Windows 定向测试：Qwen 单元测试 6 项和本地适配集成 1 项通过，覆盖不同端点、分隔符歧义、父操作取消和超期缓存命中；未调用真实供应商。

同时将 V5.6.1 验收表与 OpenSpec 上下文中残留的 0.6B 改为用户确认的 1.7B，34 项验收状态保持 pending。此前 2.2–2.9 被笼统标为完成，但试听、预取与播放接线、完整取消和指标尚未闭环，现恢复未完成，已有局部实测保留。M0、逐帧共享内存、音频主时钟和 OBS 仍未完成。
