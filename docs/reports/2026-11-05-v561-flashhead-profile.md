# FlashHead 分阶段性能诊断

`flashhead-bounded-diagnostic.py` 增加音频特征、视觉生成、有限性检查分阶段计时；显式 GPU 同步有测量开销。阶段使用高精度 `perf_counter`，期限仍只在块之间检查。增加仅供诊断的 `--attention-backend cudnn`，限定视觉模型 SDPA 使用 cuDNN，不改变生产默认；后端不可用时失败，不静默回退。

30 秒默认后端试验：32 块，每块对应 0.96 秒；全部块平均音频特征 0.0523 秒、视觉生成 0.9565 秒、检查 0.0044 秒；去掉首块后分别 0.0303、0.9405、0.0005 秒。该轮使用旧 `monotonic` 阶段计时，Windows Python 3.10 存在时钟量化，作为近似观察。主要耗时在视觉模型，不能据此确定唯一算子瓶颈。

随后使用 `perf_counter`、相同肖像/语音/模型及各 11 块分别运行默认和强制 cuDNN：默认全块平均音频 0.0642 秒、视觉 0.6647 秒、前向合计 0.7289 秒，首块 1.3010 秒、去掉首块均值 0.6717 秒；cuDNN 对应 0.0358、0.7253、0.7611 秒，首块 1.9492 秒、去掉首块均值 0.6423 秒。两轮仅顺序运行一次、块数少，运行状态可能变化；默认后端实际选择未捕获，不能判定统计显著的收益，更不能视为实时直播成绩。与上一轮约 1 秒/块之间存在明显波动，原因未确定。

额外合成张量算子测试，形状 [1,12,1280,128]、bfloat16，在 RTX 5090 上 cuDNN 正常执行约 0.125 ms、数学后端约 1.940 ms、最大绝对差 0.000977；FlashAttention 后端显示未编译。该结果只针对合成张量，不能外推整个模型或用户形象质量。GPU 一秒采样实验的 nvidia-smi 输出文件为空，采样失败，不报告温度、功率或整机显存峰值，也不能推断波动原因。

验证：默认与 cuDNN 实际诊断均完成、每轮输出 11 个有限块；前一轮 32 块完成；OpenSpec 严格校验通过。无播放、推流、OBS 或新 TTS 调用。下一步应建立可靠 GPU 遥测与多轮同条件对照，并优先验证有界帧交付和音频时钟；M0 尚未通过，不改变实际运行默认。
