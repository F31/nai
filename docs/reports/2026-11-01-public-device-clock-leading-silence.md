# 句子开始前的静音不推进该句

## 结果

实验栅栏放开之前，同一条静音流的设备时钟已经在走。等到这段前置位置按 24 kHz 折合约 8000 个源样本后，再等 50 毫秒。读数是设备位置 151872、频率 384000、流代次 1，已播放 0，提交 0。按同一比例，151872 约合 9492 个源样本。接纳规则接受这条已播放为 0 的观测，并不把设备位置换成已播放样本。

栅栏放开后该句才开始。第一次读到已播放样本时是 275，提交 1440，设备位置 174896，流代次仍是 1。275 小于前置静音折合的 9492，所以启动前那一段没有被算进这句。

被忽略的 `leading_silence_does_not_advance_the_sentence` 本次显式运行通过，用时 1.89 秒。`openspec validate v49-realistic-avatar --strict` 通过。1.3.10 和 1.3.11 都没有勾选。句间静音没有测。

## 没有改变的路径

公共 CPAL 播放仍只使用提交游标，不读 `IAudioClock`，状态里继续不填设备时钟。没有装配公共输出，没有拔设备，没有真实公共音画或 OBS。没有跑 MuseTalk，没有重绑定位缓存。
