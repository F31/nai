# 形象备份引用清单原型（2026-10-28）

新增隔离只读清单函数，扫描有界对象版本并提取形象草稿素材与许可摘要；候选权利表完整存在时，同时扫描绑定和撤权记录。按素材摘要去重，对同一素材摘要对应冲突许可、无效摘要、缺失或损坏对象、半套表和超过容量拒绝。

Windows 隔离 SQLite 定向测试通过，覆盖多个形象版本、撤权记录去重、许可摘要冲突和缺失源对象。测试程序在一个 E 盘构建目录被 Windows 锁定，切换至另一已有 E 盘目录后通过。

该函数尚未接入生产 Store 或真实数据库快照，也未与桌面侧形象包复制、可验证清单、备份目录隔离和恢复 journal 接通。全量对象版本中若历史文件已被清理，当前选择安全拒绝而不是跳过；其适用性需在正式迁移前核查。未访问用户数据、更新运行版或调用模型，OpenSpec 任务和 ACC 状态不变。
