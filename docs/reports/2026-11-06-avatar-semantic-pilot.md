# 语义区域数据试点

固定 FeatherTalk train.py 接口核查发现训练除视觉网络外还使用 VGG19 感知损失权重。旧 MouthRoiDataset 依赖特定 .lms 坐标，不能直接接入新的嘴部语义区域。人物训练、音频特征和损失依赖仍须统一核查，未启动训练。

从已验证连续片段生成 100 个 144×144 无损 PNG 目标块和 100 个融合遮罩；逐项包含原帧编号、时间、原图区域、尺寸及版本，明确 upstream_dataset_compatible=false。全部 200 个 PNG 实际解码验证通过，源帧编号与几何记录匹配。产物 target-windows/avatar-region-research/dataset-girl/semantic-pilot。遮罩为回贴 alpha，不是自动认定适合训练的嘴部损失或输入遮罩。

仅完成独立数据接口试点，不是人物权重、新语音样片或实时能力。下一步必须实现使用该语义接口的数据加载与在线复用，验证音频窗口对齐和训练输入遮罩，然后准备全片与独立留出片段。不得以100帧训练后回放同帧声称泛化通过。模型许可闭包和144区域画质仍未验证。
