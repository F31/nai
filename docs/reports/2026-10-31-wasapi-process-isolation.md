# WASAPI 实验进程隔离演练

新增 Windows 隔离进程测试：子进程打开默认输出设备的静音同流实验后端，实际设备时钟推进后，子进程主线程模拟永久阻塞；父进程在 2 秒期限内强制结束子进程并等待退出，随后新客户端成功打开设备并在 500ms 内正常退出。1 项父进程演练通过；被忽略的子测试仅由父进程调用。此前无设备的纯卡住进程演练也通过。使用项目 E 盘 TEMP 与独立构建目录。OpenSpec strict 通过。

该测试证明本机一次强制结束后能重新打开共享音频设备，不证明声学静音、音轨已播放完毕或拔出设备时的表现；卡住的是子进程主线程，不是 COM 调用，也未验证内核/驱动卡死。没有实现生产子进程宿主、媒体权限绑定或父进程失联租约，原实验 Probe 的 Drop 仍可能阻塞；不能用于工作台公共输出、OBS 或真实业务语音。

下一步基于现有受控子进程和生成契约装配真实音频宿主，验证进程失联时租约停止、设备断连与可信回执，随后才做受控语音验收。
