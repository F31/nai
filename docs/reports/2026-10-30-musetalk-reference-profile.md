# 真人样片体验及分阶段性能

用户观看此前的 4 秒样片后反馈：声音正常，口型可以接受。该反馈针对单个样片，不代表长时间稳定或所有素材可用。

为确定优化方向，在同一 RTX 5090 Laptop、本地已授权视频与已有 Qwen 音频上，复核 11 项模型文件摘要后重跑一次隔离 Python 研究链路，未调用 TTS 或外部服务，未上传或推流。输出 120 帧、30 fps、960×540 的 4 秒样片，FFmpeg 全文件音视频解码通过。计时从研究程序 main 开始，不包含 Python 导入、素材准备、模型下载与上轮 TTS 合成。

| 阶段 | 本次耗时 |
| --- | ---: |
| 人脸检测及关键点模型加载 | 3.344 秒 |
| 120 帧人脸定位 | 26.109 秒 |
| Whisper 加载及整段语音特征 | 7.828 秒 |
| VAE、UNet 和分割模型加载 | 4.921 秒 |
| 120 帧推理、融合与静音视频编码 | 38.829 秒 |
| 音频封装与输出检查 | 0.234 秒 |
| 整体 main 耗时 | 81.313 秒 |

阶段边界同步 GPU 后计时；渲染阶段混合 VAE 编码、UNet、VAE 解码、面部分割融合及视频编码，尚未拆成单算子耗时。该阶段整体约 3.1 帧/秒，不能等同于独立模型 FPS 或实时性能。PyTorch 本进程 CUDA 峰值 allocated 4843.2 MiB、reserved 4866.0 MiB；Python 本进程 RSS 以 200 ms 采样，峰值约 5801.6 MiB，不含子进程、驱动、其他程序及全机 GPU 峰值，不能用作设备总量。实际 metrics 在 `target-windows/realistic-avatar-research/video-inspection/musetalk-sample-1793359776040830500/metrics.json`。

本次是一次离线测量、非稳定分布或长稳结论；未测语音首包、实时音画偏差、OBS 直播、故障接管、平台或生产 NativeOnnx，验收注册表不变。下一轮先将真人底版的定位、裁剪和可复用素材作为有界预处理缓存，渲染阶段细分计时并验证缓存命中/变更失效；再研究批量推理与按需融合对画质及首音延迟的影响。性能改动必须保持用户可接受的口型及停止/撤权边界。
