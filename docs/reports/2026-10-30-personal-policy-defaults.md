# 个人直播偏好默认值与备份前置核查

领域偏好缺省值已实现：仅主题讲解、用户触发 AI 回答、仅依据资料，公屏抽样比例预设 100%；主题独讲不会选取公屏，保存或读取偏好不代表启动直播或授予权限。输入先经类型解析再经现有 JSON Schema 验证，拒绝重复字段，避免 JSON 对象字段覆盖造成解释歧义。

Windows 定向测试：个人策略 4 项通过；现有模型迁移备份原语相关 11 项通过，覆盖取消快照、不完整备份隔离、损坏拒绝和隔离恢复等；OpenSpec 严格校验通过。构建缓存位于 E 盘 `target-windows/live-auto-build`；编译时增量硬链接不可用并退回复制。未访问用户数据库、模型或设备。

迁移尚未完成：现有备份原语不是 schema 版本升级及 journal 激活恢复；未实现个人偏好的存储、版本迁移、实际任务取消及 UI/智能体接线。现有预算、审批和验收注册表不变，不能将本轮结果称为个人直播模式交付。
