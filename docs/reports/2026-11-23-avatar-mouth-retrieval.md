# 同人物真实口型素材覆盖对照

从音频探针训练段检索同人物局部素材，用开口误差≤0.015、嘴宽相差≤10%、嘴角连线角度相差≤5°作为本轮二维筛选条件。与连续留出片段之间保留原音频窗口隔离。100帧中38帧需要补充口型，38帧均存在候选。

以原始局部与直接替换局部对照，中心区域最大相邻帧RGB差为0.04956，原片0.04163（归一化0–1）。两个最大值可能发生在不同帧。当前仅用二维姿态代理，未对齐或融合入全帧，也未验证新语音或真实口型同步。4秒视频完整解码。下一步比较逐帧最近匹配与带连续性代价的候选路径，再做融合验证。
