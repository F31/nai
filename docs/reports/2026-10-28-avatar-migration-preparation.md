# 形象迁移备份准备与清理界面验证（2026-10-28）

## 本轮实现与验证

提取现有模型迁移中的 SQLite 一致快照为独立内部函数，保留有界步进、取消检查和 SQLite `quick_check`；原备份还继续执行文件清单、哈希和恢复验证。备份相关定向 4 项通过，包括取消时不复制；这只是数据库快照，未覆盖形象素材文件，也不是新的生产迁移。

增加 Windows 测试专用模块解析器，定位已有生成契约，避免修改 WSL 创建的工作区链接；工作区清理界面逻辑测试 6 项通过，新增形象权利记录阻止删除的用例。上轮报出的 UI 测试环境失败已通过此测试方式解决；真实渲染及原生 UI 尚未验证。同名伪造形象表与不完整表拒绝清理的 SQLite 定向测试通过。
