## 关键实现

- 远端协议 `schemas/openapi/remote-knowledge.yaml` 独立生成 Rust DTO、TS types、内嵌 JSON Schema
  与端点常量，无手改产物；`RemoteGateway` 复检 `RemotePolicy` 过期/允许操作/KB/上传/留存/删除。
- `rerank_evidence` 只重排已合法证据 ID，子预算耗尽保留 base 为 partial；整体取消/超时停止。
- `Store::remote_delete_targets` 提供本地 tombstone 后的 kb-scoped 远端删除目标；远端失败不回滚本地失效。
- 迁移 0004、备份 JSON Schema v4、真实服务端 manifest、v3 升级不激活旧 metadata-only 记录。
- 发布事务注入错误、facts/权限/竞争发布 CAS、源 revision 变化、缺失词法/向量均回滚保持原版本。
