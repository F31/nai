# CosyVoice首块token与参考对齐采证

## 得到的确定事实

当前参考音频3.48秒、24kHz mono float32，编码为87个Flow参考token。模型hop25、Flow lookahead3、token_mel_ratio2、静态Flow chunk25token（50mel帧）。部署算法首次生成token门槛25+13参考补齐+3前瞻=41，两次实测decoder_input_tokens均41，token_offset0、finalize=false。不是HTTP分包或网络读取大小决定此门槛。

## 代码与检查

扩展既有cosyvoice_first_pcm观测器：只读token/参考shape及模型hop/前瞻，记录首个token2wav的实际计数/开始时刻和第25/所需token到达时间。内部仅保留前256个token时间点，不记录token值、文本、音频内容；日志只输出首块摘要。元数据解析失败不改变原音频或异常，超限显式标记截断。11项既有及新增CPU检查通过，含真实gate取消/忙拒、回调、原异常、既有入口唯一性保护、计数公式与不记录内容。

本轮为实验轨，无新生产配置或外部HTTP端点；没有更改模型参数、参考输入、hop、Flow、缓存及精度。新对齐算法只有完整OpenSpec规划，尚未实现。
