# V5.6.1 帧调度核心

新增独立调度器：容量和过期阈值由调用方配置；校验帧结构、epoch、pool、序号、槽位代次、尺寸和可选摘要；接收拥有独立副本的帧，根据设备观察的播放样本选择最近已到达时间点的帧，在阈值内保持上一帧；队列满拒收，不覆盖未消费帧。停止、暂停、过期、时钟倒退及设备代次或采样率不匹配时拒绝或回退安全帧。

Windows 相关定向测试 5 项通过，覆盖帧选择、容量、暂停、过期、时钟倒退、摘要、旧 epoch、槽代次和采样率。此前旧代码中存在 WASAPI 设备时钟实现，但仍依赖旧输出装配；此轮未把其与新调度器接线。

后续修正：真实 FlashHead 帧的源时间线为 16 kHz，而 WASAPI 后端源时钟为 24 kHz。调度器现通过整数交叉乘法对齐不同采样率，迟到上限以播放时钟采样为单位，避免舍入漂移；同一设备流的时钟采样率改变仍拒绝。更新后 6 项调度测试及 3 项设备时钟测试通过，其中包括 16 kHz → 24 kHz 的边界和过期测试。

尚未完成：可信进程和共享槽句柄交付、Rust 实际读取与释放、真实音频设备时钟适配、输出窗口、真实模型端到端性能、OBS 和 M0 验收。调度器调用者须独立验证发送方身份、共享槽所有权、设备时钟来源及观察新鲜度；本轮测试不代表真实播放成功。
