# OBS 本机实时发送夹具

使用已有授权音画，FFmpeg按实时速度发MPEG-TS，隔离OBS仅绑定指定本机UDP端点。首轮OBS未在短发送窗口内识别流，录像全黑静音，保留证据。第二轮OBS先开始录制，再发送固定关键帧间隔的16秒音画，结束后继续录制约5秒。

第二轮录像22.13秒，663帧完整解码。录制时间轴16.510秒起尾部持续静音，16.554–18.321秒为末帧冻结，18.321秒起为黑画面。约1.767秒为录像中的冻结区间，不等同于经同步时钟测得的断连响应。可用作传输参考，不能作为立即撤权或OBS播出合格证据。未接实际nai生产端、未验证预览最小化。下一步为接收端加入独立许可和帧超时清空，并测真实生产端骤停。

证据目录target-windows/v561-loopback-obs-20261123，成功录像在retry/recordings。
