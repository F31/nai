## 一、先量上一条残余，它不是一条能立的判据

ADR 0124 残余第 1 条是「归档 `tasks.md` 的段结构未判」。照例先量：

| 事实 | 值 | 它意味着什么 |
| --- | --- | --- |
| 归档 `tasks.md` | **147 / 147** 齐备 | 存在性这一半是零信号 |
| 有 `## ` 段的 | **108**（**39 份没有段**） | 「必须有段」今天红 39 次 |
| 段标题种数 | **375**，其中 **311 种只出现一次** | 段名是自由文本，闭世界不成立 |
| 段内 0 条任务的段 | **52**（如 `Workflow follow-up`） | 「每段至少一条」今天红 52 次 |
| 复选框数 | min **4** / median 17 / max 48 | 「至少一条任务」全过，而它几乎等于「非空」 |
| `*` 与 `-` 写法 | 全部 `-` | 没有第二种形态可判 |
| 代码围栏 | **0** 份 | 标题不会被围栏藏住 |

结论：**「结构」在这份语料里没有统一形状**。39 份平铺是合法历史，不是缺陷；375 种段名是人的
自由书写。剩下能写的判据只有「非空 + 全部勾选」，而后者已由 `openspec validate --archived`
覆盖 —— 再写一遍就是同一件事的第二处定义。⇒ **不立项**，残余继续留在 ADR 0124 里。

## 三、36 处的分类，以及它为什么不是一次性事故

| 类型 | 处数 | 成因 | 处置 |
| --- | --- | --- | --- |
| 缺 `../` | 15 | 报告住在 `docs/reports/`，链接按 `docs/` 写 | 就地补 `../` |

| 日期笔误 | 2 | 报告真名是 `2026-10-09-…`，写成了 `10-10` | 就地订正（同目录唯一候选） |

| 指向从未存在的文件 | **8** | `0027-trace-id-single-definition.md`（6）、`0015-decision-log-criticality.md`（2） | **降级 + 勘误**（见四） |

七种里有六种是路径写法问题——**同一个人在不同的轮次里重复犯同一类错**，这本身就说明
它需要一条判据，而不是一次大扫除。

## 四、处置：订正与降级是两类，不是一个「修链接」

`0027-trace-id-single-definition.md` 与 `0015-decision-log-criticality.md` 有一个共同点：
**文件从未存在过**。它们不是路径写错，是指涉落空。处置因此二分：

- **可复原 ⇒ 就地订正**。`0015-decision-log-criticality.md` 的实指可确定：ADR 0019 决策 5
  （`docs/adr/0019-composition-root-boundary.md:25` 逐字：「决策日志分级：critical
  （cancellation/duty_lease 等）失败即错误；telemetry 允许缓冲」）⇒ 改为 ADR 0019。
- **不可复原 ⇒ 降级为纯文本 + 勘误段**。`git log --follow docs/adr/0027-deployment-lifecycle-boundary.md`
  显示 ADR 0027 自创建起就是「部署生命周期的边界」，与 trace 无关；原文写的 `0027` 与任何
  trace 相关的 ADR 都不对应 ⇒ **MUST NOT 猜一个编号补上去**。6 份 ADR 各自把该指针降级，
  并在末尾追加 `## 勘误（W151，指针）`，写明「编号不可复原」与真实落点（ADR 0081 决策 6
  对 ADR 0064「一处定义、两处使用」的应用）。

猜错的代价不对称：断链读者知道「这里坏了」，假指针读者不知道。所以宁可留一个明确的缺口，
不换一个看着像答案的错误。

## 五、判据形状与诚实边界

四条规则（细节见 ADR 0125）：相对链接的落点 MUST 在 `.git/index` 里；**目录算存在**；
**通配直接失败且措辞不同**；外部 / 协议相对 / 纯锚点在域外。另加三条守卫：文档集为空、
索引为空、在域内链接为 0 —— 各自具名失败，「零错误」不许由「一条都没看」产生。

**四处零样本，如实登记**：

1. **锚点（`#fragment`）不在域内**：今天 0 条带锚点的链接。slug 规则随渲染器变
   （GitHub / VS Code 预览 / `markdown-it` 各不同），没有真值可校准。
2. **引用式链接定义行不在域内**：今天 0 条 `[x]: url`，解析器也没实现。
3. **`docs/` 之外的 markdown 不在域内**：`openspec/` 的变更文档与根目录 `*.md` 都有链接，
   扩域要先量。
4. **「能点开」≠「点开是那件事」**：内容正确性仍是语义，本判据不判，MUST NOT 记作「已判」。
