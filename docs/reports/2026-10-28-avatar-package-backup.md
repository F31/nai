# 隔离形象包备份原语（2026-10-28）

新增内部复制原语：以目录句柄读取已安装包，对素材总大小与包摘要复检，在调用方提供的隔离目录重新执行正常准入并重建中性预览；返回的元数据不含素材字节。源许可文件篡改后复制拒绝，已生成的隔离副本仍可独立预览。Windows 形象相关定向测试 15 项通过，包括该复制、静态与并发 junction 拒绝及既有预览检查。

该原语不枚举数据库引用的完整形象集，不验证源和目标一定不同，没有备份清单、数据库快照装配或迁移 journal，不能当作生产备份或恢复实现；调用方还必须管理路径所有权、引用闭包和权利校验。当前未接入用户界面或运行版，没有访问用户资料、调用模型或升级验收状态。
