# 局部口型开口监督探针

用已有标注计算上下唇中心距离与嘴宽的比例。CPU岭回归从真实音频特征预测该比例。前段3696帧训练，训练和连续留出段之间隔离音频窗口，905帧同时比较正确音频与后移25帧的音频。

正确音频MAE 0.02097，相关系数0.435。错位MAE 0.02553，相关系数-0.023。训练均值MAE 0.02214，正确音频降低约5.3%。同人物留出数据支持进一步测试该监督，提升幅度有限。未训练渲染器，未验证新语音、口型画质或实时速度。

实测JSON位于target-windows/avatar-region-research/dataset-girl/aperture-probe-20261123.json。OpenSpec严格校验通过。下一步固定训练切分、种子和预算，用原训练目标对照加入开口监督的候选，再比较正确和错位音频的实际渲染响应。
