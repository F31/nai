# V4.3 RF05 私有原生试听

2026-10-23。本轮交付可操作的“试听（本机）／停止试听”，完成固定短句测试音频到独立原生输出的工程闭环。RF05/M3完整直播链路与90项ACC仍未完成，不因本切片通过而升级。

## 使用与实现

新工作台：设置 → 模型与预算 → TTS语音模型 → 对已保存模型测试合成 → 成功后点击试听（本机）。试听重用本次有效产物，不追加Provider调用；60秒以内缓存到期或引擎重启后不可恢复。再次合成仍按现有单次费用确认执行。停止按钮、离开面板/切换工作区、页面隐藏和退出请求优先停止，不自动续播。使用系统默认声卡；OBS若采集桌面音频也可能录到试听，界面已明示。

先修改foundation.proto并生成契约，再接消费者。新增StartTtsAudition/RenewTtsAudition/StopTtsAudition、停止nonce与独立AuditionControl/Status。控制帧4096B以内；PCM不经JSON/Base64或控制管道。引擎拥有随机临时媒体文件及内容哈希，worker拒绝链接/Windows reparse、错格式/长度/哈希；最多24kHz单声道PCM16、480000样本。媒体文件在正常结束/取消时由owner回收。

nai-audition-worker是按需启动的独立Windows GUI进程，不新增常驻服务或端口；复用已锁定的CPAL 0.16，使用WASAPI默认输出，支持有界采样率转换与声道复制。进程不接收数据库、Key或Provider配置，启动清空环境，只保留SystemRoot。程序通过继承私有管道控制，网页不能指定文件/程序路径。独立进程是SDK故障边界，不等于OS沙箱/正式IPC认证。

worker使用本地单调时钟，每150ms发challenge；租约<=500ms且从challenge发出时刻起算，拒绝过期/重放/旧epoch。GUI续租600ms，到期即关闭，迟到心跳不得激活旧player；父进程每100ms轮询并重新核对角色、模型/任务版本、哈希和期限。原生回调只读停止/期限原子量，不等待DB或模型锁。独立停止文件每10ms检查；开始时绑定停止nonce，排队旧start不能跨过停止。初始化2秒、总生命周期24秒看门狗；所有队列有界，输入EOF、状态堵塞/失联均关闭，无自动重试或自动重新播放。

输出配置请求约10ms缓冲，并拒绝大于100ms的声明缓冲；实际已排入设备的样本无法由软件状态等同为硬件静音证明。Submitted仅表示完整样本提交回调并等待有限尾部排空，界面明确提示人工确认是否听到。没有机器硬件播放完成ACK。

## 定向验证

- 184条生成Protobuf消息；36个显式夹具经Rust/TS/C++双路径互通、生成无漂移通过。覆盖三条试听命令、nonce、worker租约/状态及响应。私有控制帧越界/截断拒绝1项通过。
- LeaseGate 2项：challenge锚定期限、迟到/重放、旧epoch、TTL边界、过期不可复活和停止拒绝。引擎单元5项通过，包含既有音频缓存与单任务槽回归。
- 宿主优先停止WSL 2项、Windows 1项通过：无需owner或数据库、停止代次改变、超长拒绝，以及Unix链接拒绝。Windows既有真实host 4项通过。
- Windows真实默认声卡显式设备测试1项通过，内部4场景：静音PCM完整提交、停止续租、优先停止文件、控制EOF。无设备不会提前return冒充通过；该项常规测试标ignore，验收时显式--ignored执行。
- Windows真实引擎TTS 3项回归通过，另1项显式设备整链通过：本机虚构HTTP返回静音WAV，经唯一writer/缓存/门控/独立worker到24000样本Submitted；覆盖旧nonce拒绝、GUI失联不可恢复与显式停止。全程合成测试数据和独立临时根，无真实API或生产音频。没有测试真实供应商音质。
- 前端描述符/试听响应2项、typecheck与生产构建通过。Windows新桌面壳构建、GUI PE检查、实际前端挂载及独立真实owner烟测通过。相关Windows/WSL clippy、26包依赖方向与注册表检查通过；未跑全仓测试。

整链验证发现并修复两处真实缺陷：①容量1的状态队列会在进度与终态紧邻时丢弃终态，调整为容量2容纳有界突发，修后原场景连续3次通过；②主循环等待请求期间GUI租约可能已到期，续租入口补到期拒绝，新增750ms失联用例修后通过。失败日志保留在.nai-diagnostics。首次桌面烟测误用PowerShell 5，因缺少路径API未执行；改用PowerShell 7后烟测通过，不计前次为成功。

本轮没有浏览器自动点击（此前策略拒绝，未绕过）；UI人工听感、音量、真实扬声器/耳机路由及硬件停止时延仍待用户体验。不以静音fixture测试声称已听到合成语音。
