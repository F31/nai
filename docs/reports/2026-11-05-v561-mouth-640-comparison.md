# 512 与 640 数字人画质对照

同一授权肖像、2.8 等比例构图、同一 Qwen 语音与种子，分别由原图直接得到 512×512 和 640×640 模型参考并生成视频。两侧最终均显示为 512×512：左侧 512 原始，右侧 640 用 Lanczos 缩至 512；均无锐化。生成各 168 帧，以同一音轨组合 `target-windows/flashhead-acceptance/mouth-512-vs-640-same-display.mp4`，视频完整解码通过。画质和同步以用户动态评价为准；不同生成分辨率可能改变随机噪声空间，不保证表情逐帧相同。

离线无编译测试中，排除首块后 640 块均值 1.244 秒（1.197–1.309 秒），每块对应 0.96 秒语音；现有 512 另一轮均值 0.616 秒（0.594–0.658 秒）。运行时间不同时、资源负载未严格对齐，不可据此算稳定加速比；640 本轮不能证明持续实时。640 编译版、播放链路、OBS、长稳和用户认可均未验证；没有更改模型或工作台默认配置。

记录：`mouth-ratio-28-padded.jsonl`、`mouth-640-native-reference.jsonl` 与同名无压缩帧。用户对右侧清晰度及自然度反馈“两侧差不多”，因此本次不采用 640 为默认，也不把升分辨率作为画质闭环。
