# 口周多帧抽样与锐化对照

从同肖像、512×512、6.72 秒 Qwen 语音生成的未压缩帧中每 12 帧抽取 1 帧，共 14 帧，Face Mesh 均定位成功；按脸宽裁剪口周、缩放到同一尺寸后，灰度拉普拉斯方差的均值约 2.93（范围 2.22–4.49），静态原图约 4.92、VAE 静态重建约 3.58。数字依赖口型、裁剪、插值及纹理，不能作为感知清晰度、嘴型准确性或身份质量的验收阈值；这些采样支持继续调查生成帧口周细节损失，不构成因果证明。

对相同未压缩视频帧分别不处理、5×5 轻度和较强 unsharp，保持相同音轨和时间，制作 6.72 秒三列对照 `target-windows/flashhead-acceptance/mouth-sharpen-compare.mp4`，完整解码通过。用户反馈“左侧原画更好”，因此两档锐化均不采用、不进入生产或默认。该方法不能恢复未生成的唇齿纹理，也无法修复口型形变。

单次 FFmpeg 离线轻度锐化 168 帧实际时钟耗时约 0.107 秒（包含原始帧读取及管线），仅为离线吞吐参考，不代表生产逐帧延迟、与推理并行时的开销或效果认可。下一步应研究保持身份和口型的来源细节修复或更适合当前形象的合规参考素材，并在用户认可后再验证实时；不得以锐化或扩大画面冒充细节恢复。M0、OBS 和画质仍未闭环。
