# V48-05 独立执行租约核心与逐帧回调守门

日期：2026-10-25。状态：核心实现及定向验证完成；生产装配未实现，V48-05仍InProgress，164ACC全部pending。

## 本轮实现

新增独立PublicExecutionLease，绑定完整批准hash、实际描述hash、输出/会话/epoch、本次准备UUID、用途、单调序列和消费者本地挑战。root的签发方法只存在于不可自行构造的PublicMediaPermit上，先复检当前权威，再用剩余期限限制TTL，最长500ms。

消费端注册时核对完整bundle、准备描述与首尾帧回执。健康用途不能授权执行，错误key/身份/hash/准备UUID、重放、取消、过期和时钟倒退均拒绝，失败后不恢复旧流。独立原子callback围栏没有DB/网络/队列锁；owner销毁撤权。相同clip重新准备必须有新UUID。

修复共享设备回调原先仅在整个buffer开始检查一次静音条件的问题：每个设备帧重新检查停止/期限，后续帧归零且不推进提交游标。设备采样率到24kHz源样本的映射和精确尾部由同一游标处理，不积压PCM/像素队列。此游标仅是提交进度，不能作为硬件完成或已排队缓冲撤回证据。
