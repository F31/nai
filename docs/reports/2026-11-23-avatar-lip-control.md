# 唇部加权与错位排序渲染对照

同一GroupNorm初始化、种子42、样本顺序、连续切分和100步预算。候选加入地标定位的唇部L1加权。若同片段错位样本的相对开口差至少0.04，则要求错位音频在固定视觉输入上损失更大。该项是像素排序损失，未接入独立开口预测探针。

905帧留出对照中，基线正确／错位唇部MAE为0.050329／0.050330，候选为0.062437／0.062437。候选正确音频唇部误差恶化约24%，音频替换下唇部输出变化从0.00011639降至0.00004064。该预算下候选未显示音频驱动改善。不能外推至更长训练或专门的口型驱动架构。
