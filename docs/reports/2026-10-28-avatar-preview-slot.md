# 私有形象预览缓存增量（2026-10-28）

## 实现与验证

新增桌面壳内部 `PreviewSlot`：单槽、16 MiB 上限、PNG 签名、工作区与素材包/许可 SHA-256 精确匹配；替换或清除后不能再按旧身份读取。两项 Windows 独立模块测试通过，覆盖尺寸、标识、替换和清除。OpenSpec `v48-avatar-management` 严格校验通过。

模块只检查 PNG 签名和大小，调用者必须只安装从完整准入产生的图像，且每次交付前复核可信权利；缓存不是解码器，也不承担许可或播出判定。已经交出的字节无法通过清除召回。撤权仍必须独立停止公共输出。

## 尚未完成

缓存还未接入导入或 Tauri 二进制协议，不能从用户界面使用。工作区选择与撤权目前只是普通草稿字段，缺少后端原子事务和可信权利源；公共渲染、Windows 实际界面及 OBS 验收尚未完成，不得声称整个功能闭环。原完整桌面测试重链接时遇到 Windows 文件锁，故本轮使用 E 盘独立测试程序验证模块；桌面壳 `cargo check` 通过。未调用模型、修改用户数据或更新运行版。
