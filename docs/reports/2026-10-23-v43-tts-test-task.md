# RF05 固定短句语音测试任务

2026-10-23。实现有预算的异步TTS测试任务与设置页状态，完整试听/媒体输出尚未实现。未调用真实付费服务，不把虚构HTTP音频判为真实音质或设备认证；90项ACC仍pending。

## 行为

模型设置TTS列表新增“测试合成”。打开测试面板后，用户填写单次预留上限并确认可能产生费用；只发送固定短句“你好，这是语音合成测试。”。未知单价须先编辑确认，不自动填免费。使用保存的模型版本、音色和独立TTS密钥。文本生成与TTS测试共享工作区累计预算和持久在途限制。

唯一writer同事务写任务对象、预算预留和outbox，派发前及提交前检查角色revision、模型revision/启用状态、撤销和期限；先持久派发再启动网络线程。单槽、有界通道、15秒网络期限和逻辑超时兜底；线程未退出时不因逻辑结案释放原生槽。取消/权限失效/停止请求取消网络，迟到音频不恢复结果。取消撤销意图独立持久化，审计失败也不能恢复派发。

合成成功只保存样本数和原始PCM SHA256，音频随执行结果丢弃；控制消息、数据库对象和前端均无PCM/Base64/可播放路径。界面显示24kHz/单声道/PCM16与时长，明确“尚未试听”。这不是业务话术语音产物，也不授予发布或播放许可。

费用按字符单价整数估算并至少预留1分；无供应商账单用量证据时，即使合成成功仍保留unknown占用，不谎报known或免费。能证明未发送才释放；派发后取消/超时/强杀重启保持unknown、不重发。正式账单核对/调账仍待实现。
