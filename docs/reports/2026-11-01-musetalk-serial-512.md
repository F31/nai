# 512 合成尺寸对照

## 结果

研究进程在本机 RTX 5090 Laptop 上，沿官方 `decode_latents` 串行路径对照两种合成尺寸。定位缓存命中。潜变量来自 960×540 人脸裁剪缩到 256，512×288 不重建潜变量。画面、人脸框和下颌掩码按同一比例缩小后再贴回。参考运行脚本 `scripts/run-musetalk-reference-sample.py` 和定位缓存都没有改写。没有打开声卡，没有向本机 Qwen 发请求，没有保存画面。

记录在 `target-windows/realistic-avatar-research/video-inspection/musetalk-serial-512-1793519910452194900/serial-512.json`。

960×540 的 100 帧墙钟 4.078 秒，40.78 毫秒/帧。CUDA 事件里 UNet 1.197 秒、解码 1.748 秒、融合 1.154 秒。三段相加 4.099 秒，比这次墙钟多 0.021 秒。32 毫秒线没有达到。窗口前的显卡快照是 49°C、225 MHz、6643 MiB、利用率 0%，窗口后是 56°C、1410 MHz、7733 MiB、76%。这是两个查询瞬间。这次 40.78 毫秒/帧，和 [同进程串行](2026-11-01-musetalk-overlap.md) 的 42.65 毫秒/帧是同一量级。

512×288 紧接在后面。100 帧墙钟 3.187 秒，31.87 毫秒/帧。UNet 0.993 秒、解码 1.964 秒、融合 0.220 秒。三段相加 3.177 秒，比这次墙钟少 0.010 秒。记录里的 32 毫秒标记为达到。窗口后的显卡快照是 55°C、1312 MHz、7733 MiB、利用率 97%。源人脸宽度 145 到 153 像素，缩后 77 到 82 像素。

解码没有变快：960 是 1.748 秒，512 是 1.964 秒。墙钟下降主要在融合，1.154 秒降到 0.220 秒。UNet 从 1.197 秒降到 0.993 秒，但 960 开始前显卡利用率是 0%、核心时钟 225 MHz，512 跑在前一次测量之后。不能把这段 UNet 差额单独记成画布变小的效果。31.87 比 32 少 0.13 毫秒，小于上面 40.78 和 42.65 之间的同尺寸波动。这一窗不改研究时间表，32 毫秒线也不放宽。研究稳态仍用官方解码的串行批次，合成尺寸仍是 960×540。

PyTorch 分配峰值 2386.4 MiB，进程 RSS 2294.5 MiB。

## 没有改变的路径

公共窗口仍按提交样本选帧。没有把 MuseTalk、960×540 或 512×288 研究帧放进 keeper，也没有把 Python 放进正式安装包。没有新协议字段。`openspec validate v49-realistic-avatar --strict` 返回 “Change 'v49-realistic-avatar' is valid”。1.3.19 已按这次测量勾选。1.3.10 和 1.3.11 没有勾选。框缩放单测 6 项通过。这些计时不是直播、OBS、口型评分或平台验收。
