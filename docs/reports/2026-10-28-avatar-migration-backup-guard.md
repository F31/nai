# 模型迁移备份形象缺失保护（2026-10-28）

现有模型迁移备份复制数据库和对象，却不包含自定义形象包。新增检查：源数据库出现形象历史或权利引用时，在创建备份目录前拒绝创建；也拒绝复用已存在的备份，防止加入形象后继续使用不完整备份。引用对象缺失或损坏也失败关闭。没有形象引用时继续既有流程。

Windows 存储定向 6 项通过，包含已有备份与恢复回归、含形象拒绝、旧备份复用拒绝。测试第一次因临时目录生命周期错误失败，修正后通过；链接文件占用导致使用 E 盘独立构建目录。尚未更新运行版。

这是一项临时保护：存在形象引用时模型迁移可能返回能力不可用，直到完整素材备份与恢复实现。未接入许可权威、公共渲染或撤权停播；OpenSpec 保持进行中，164 ACC 不变。
