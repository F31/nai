# 形象构图比例修复与动态对照

用户反馈生成画面嘴部偏大。诊断发现，原始裁剪接触图像边缘时可能由正方形变为矩形，旧实现仍将其直接拉伸到正方形。例如 3.4 构图产生 1087×979 裁剪，会非等比例改变人物外形；这只能证明存在构图失真，不能证明它是口型偏大或模糊的唯一原因。

独立诊断现将裁剪按边缘像素补齐成正方形，再等比例缩放；保存的 `resize_mode` 明确为 `edge_pad_preserve_aspect`。测试以矩形的已知像素行验证没有拉伸，并覆盖原有无脸/多人/无效参数拒绝；4 项测试通过。此处改变的是隔离诊断的形象准备，尚未声称工作台或生产装配已更新。

使用同一原图、Qwen 语音、随机种子、512×512 输出与无编译推理分别生成 2.8 和 3.4 构图，各 168 帧；组合为 6.72 秒本地并排片，左为 2.8，右为 3.4，编码结果完整解码通过：`target-windows/flashhead-acceptance/mouth-ratio-padded-comparison.mp4`。图像边缘补齐并非新增真实画面；构图变化会改变整张脸的显示大小，不能只凭嘴巴绝对像素大小判定口形改善。第一次未修复比例的对照片段不作为画质证据。

短片帧导出仅用于诊断，输入请求最多 7 秒、最终长度按整块向上取整；必须显式指定尺寸且拒绝覆盖。两组各 168 帧、大小各 132120576 字节；不证明实时播放。用户动态评价、嘴形相对脸部比例、细节清晰度和生产音画仍待验证。
