# 原始参考、VAE 重建及说话帧对照

用同一授权肖像先按修正后的 2.8 等比例构图得到 512×512 参考图；通过 FlashHead Lite VAE 做静态编解码；另取同输入、同构图、Qwen 语音的无编译离线生成第 50 帧。通过人脸关键点，以各自脸宽为基准裁出同尺度口周并放大，输出 `target-windows/flashhead-acceptance/mouth-three-stage-comparison.png`，分别标为 REFERENCE、VAE ONLY、SPEAKING FRAME。

本次单帧观察：原图和 VAE 静态重建仍可见较多胡须与唇周纹理，说话帧口周更平滑。该结果支持进一步排查语音驱动的说话生成及其解码过程中的细节损失；静态重建与说话帧在嘴型、表情和时刻不同，不能将差异精确分配到具体网络层，也不能据此证明口型大小、画质或同步已达标。

新增本地对照脚本：脸宽归一化、边界不足拒绝、输出拒绝覆盖并记录裁剪区域；两项几何和失败路径测试通过。VAE 真实运行完成，所有材料仅供本机诊断，不改变生产画面。

下一步应在同一语音时间序列上比较多个口型，验证改善候选是否保留唇齿动态及身份，再对用户评审的候选核验实时负载。不能单纯用静态图贴嘴或盲目锐化来掩盖形变；M0、OBS、口型和清晰度验收仍未通过。
