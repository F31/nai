# 同流 WASAPI 实验写入与时钟故障

将研究后端的写入与设备游标提交收敛为单一边界：先核对停止/撤销，再调用写入，只有成功才提交设备帧；写入或游标提交失败撤销一次性栅栏。设备时钟位置校验失败亦撤销。单测注入写入失败、位置超过已提交、撤销前不得调用写入，确认失败不会凭空推进已提交游标。若硬件写入已成功但后续游标提交失败，已交付缓冲不可回滚，必须撤权停止，不得声称物理数据未提交。

适配器 9 项定向测试、Windows 2 项设备测试通过；设备测试仍为静音。注入覆盖的是隔离函数及真实后端接线，不是操作系统级设备拔出或 COM 卡死测试。写入期间异步撤销有竞态，已有系统缓冲不可硬撤回；时钟读取 API 错误由线程外层撤权，严格期限与独立进程故障隔离未验证。真实业务 PCM、租约、公共输出、OBS 均未接入。
