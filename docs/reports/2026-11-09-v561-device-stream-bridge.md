# 独立设备同源音画接线（2026-11-09）

状态：原生设备回执/窗口工程链路、停止与欠载实测及修复后人工音画体验通过；此前失败和超时保留。34ACC仍pending，M0仍No-Go，不更新安装版。

## 实现

`v561_external_pcm`为既有stream_audio提供有界外部源，最多16条/每包9600字节、总源最多144000样本；非阻塞满槽取消，消费端复检样本与SHA，未封口断开不是EOS。该路径不调用模型，复用原私有音频执行器的认证/300ms租约/设备回执。协议和依赖均不变。

新`v561_stream_av_probe`在GPU owner回调将owned像素入有界Scheduler后推进PcmGate，音频覆盖的PCM再交外部源。主窗口仅依认证设备时钟选择帧，过期/取消安全清空。像素容量按几何与256MiB上限推导、最多96帧；本机768候选使用显式48000样本/2秒预缓冲。预缓冲不解决GPU持续吞吐不足，也不表示首声已加速。整条句子只调用一次本地CosyVoice，不二次合成。

WASAPI执行器原来在运行中短缺时写静音且源时钟不前进；现改为运行中真实短缺退出，只有封口且覆盖真实源尾部时允许不足一个设备缓冲。启动同时检查PCM预填充和已授权play_until，避免把尚未续到的初始授权水位当欠载。
