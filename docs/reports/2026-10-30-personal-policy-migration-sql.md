# 个人偏好迁移 SQL 隔离验证

新增待激活的版本 2→3 SQL：为工作区偏好创建带大小、版本及外键约束的独立表，同时更新 SQLite user_version；不改动已有预算、费用或审批表。该 SQL 只作为事务内迁移材料，尚未接入 Store 启动或提供执行入口。

Windows 下使用隔离内存 SQLite 测试 2 项通过：事务提交后表和版本同时生效、保留已有预算和费用事实；提交前丢弃事务时表和版本共同回滚；另外检查不存在的工作区不能插入偏好，并将提交后的版本交给既有恢复判定。测试使用模拟的备份已核验状态，不构成实际备份或磁盘强杀恢复证据。构建缓存位于 E 盘 `target-windows/live-auto-build`。
