# 所有权传播到模型取消边界

## 实现

为现有纯 Operation 增加一次性非阻塞 permission 谓词绑定；克隆和子任务继承，禁止重绑，父期限保持不变。将 OutputOwner 的弱引用代次检查接入该接口，所有权被替换、stop 或根释放后，既有 LLM/TTS 的请求前检查、20ms 网络取消轮询、结果检查及 Qwen 缓存检查均可拒绝旧任务。不引入后台轮询线程、队列、工作区、审批或预算实体。绑定函数由可信装配调用，不能接收模型提供的函数。

## 验证

- 新增2项集成测试：其中1项覆盖 LLM/TTS × 真人接管/stop/根释放共6种真实回环 HTTP 等待取消；另一项覆盖继承、期限不延长、禁止重绑及缓存音频拒绝。等待响应时撤权，本机调用在1秒测试上限内结束，结果为空且 Cancelled，未重试。
- 相邻模型适配库19项、Operation foundation 3项测试通过。
- 定向 clippy（warnings 作为错误）及 OpenSpec 严格校验通过。构建期间有增量缓存硬链接退回复制提示，不影响测试结果，缓存仍在E盘。
- 首次受限沙箱内新测试及既有父期限测试无法连通回环，前者返回 OutcomeUnknown；在允许回环网络的执行环境重验全部通过。保留失败记录，不修改系统代理、不放宽业务期限。
- 使用本机测试服务和合成凭据，没有调用真实 LLM/Qwen 或付费供应商。
