# V5.6.1 Windows 设备播放时钟适配

在现有 WASAPI 同流设备时钟后端上新增独立 V5.6.1 观察适配。仅在该流已确认从零启动、线程存活且无设备失败时返回观察；拒绝设备代次变化、零时钟频率、已播放超过已提交及样本倒退。当前后端的源 PCM 是 24 kHz；该格式是后端事实，不是推断出来的设备采样率。

验证：转换单元测试 1 项通过；Windows 实际输出设备播放静音约 0.4 秒，观察到已播放样本前进，请求暂停、撤销以及停止并回收后均不再返回有效观察，测试通过。未播放可听语音、未接共享帧和窗口。适配不提供 IPC 身份认证，也不代表硬件最终听感确认。

另用真实 WASAPI 静音时钟驱动新调度器选中 1×1 合成像素，集成测试通过；这是同进程夹具测试，不是模型帧、公共窗口或 OBS 实录。

后续仍需完成：独立 Python worker 与 Rust 间可信有界共享槽、源音频与上述时钟绑定、调度器和窗口装配，再执行真实 Qwen/FlashHead 音画、OBS 和实时性验收。M0 未完成。
