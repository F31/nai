# 单作用域输出所有者内核

新增 nai-kernel::output_owner，单原子状态编码代次、当前所有者和停止锁闭；可信控制面可申请讲解、回答、真人，同级新回答显式替换旧回答，高优先级使旧令牌失效，低优先级不可抢真人。释放以签发实例与原子代次比较交换，旧任务finally不清掉新所有者。停止作用域不允许再申请，恢复需新显式作用域。

令牌通过借用绑定签发实例；它不是可跨IPC序列化的身份、租约、设备静音证明或完整会话epoch。五项定向测试通过：接管／旧释放、停止锁闭、同级替换、跨作用域拒绝、其他线程停止。代码不依赖具体插件、Tauri或网络，不新增常驻依赖。

当前只实现内核行为，尚未接入输出执行门、LLM／TTS取消或真人设备。current检查与设备操作之间仍需独立执行门消除撤权竞态；不能以进程内状态代替媒体执行失联租约。生产装配、协议及实际接管待完成，0.71未勾选，不升级ACC。本轮无模型／麦克风／设备调用。
