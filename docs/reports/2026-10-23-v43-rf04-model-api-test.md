## 使用方式

“模型与预算”选择已保存、启用且有Key的模型，在模型表单下直接点击“测试连接与响应”。测试前填写本次预留上限（默认0.01元）并勾选可能计费确认；编辑未保存参数或Key时禁用测试，避免把旧配置误认为新配置。无需创建产品、场次或发布节目。

测试发送固定非业务短句，最多256输出token、15秒，只发一次，不重试/跳转/换模型。界面显示有界正文、成功或具体失败原因、预留/已知估算/未知费用状态，支持取消。取消后不把已发送未知费用假退回；离开页面、切换工作区或模型时丢弃旧显示，导航先请求取消在途测试。

HTTP认证、拒绝访问、端点/模型不存在、限流/额度、响应不是JSON、缺正文、token截断及异常结束状态有明确分类。网络/超时仍沿用有界错误，不把供应商原始错误体、头信息或Key显示到界面。若正文含原Key则拒绝展示。测试不要求业务JSON候选格式；普通文本测试通过也不代表结构化备稿、事实正确、模型余额或直播能力通过。
