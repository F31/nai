# CosyVoice → Rust → 独立设备进程真实边收边播

日期2026-11-07。C04本机语音试听纵向包完成；不是公共音画/OBS/桌面产品完成。未修改数据库、Key、已有模型配置或CosyVoice容器。真实本地合成1次、无自动重试，从Windows默认输出设备播放固定测试短句；没有录音、推流或付费调用。所有构建/缓存/验收产物在E盘target-windows。

## 实现与职责

先定义stream_audio.proto、cosyvoice-stream.schema.json与cosyvoice-stream.yaml，再通过正式cargo xtask schema生成Rust/TS/C++/Python协议与TS配置/HTTP类型。新增配置和HTTP源加入正式生成器，没有手改生成代码。300条消息、16个Protobuf源生成，schema --check无漂移。

- adapters/llm-openai/cosyvoice：独立表单协议适配，固定stream=true，loopback/no-proxy/no-redirect/no-retry；校验实际PCM格式声明，将奇数网络字节跨块拼接，规范为最多4800样本的PCM16LE块。父取消/期限每10ms观察，读/提交前复检；参考文件10MiB、配置/文本/整句均有限额。它不授播放许可、不做全句缓存或恢复旧Qwen协议。
- nai-media-core/stream_pcm：有界环、来源连续性/块序号/摘要、终止总样本与最终摘要校验；设备区间账本只保留未完成区间，最多64条，已完成即回收，替代旧四段CueSpan限制。
- audio-cpal/stream_device：同一WASAPI流48kHz设备帧映射24kHz源样本，实际IAudioClock观察；缺料静音不推进源样本。音频线程只短暂try_lock环，不等待模型/网络，提交前复检独立租约。每个源样本复制为两个48k设备帧/双声道，后续高级重采样另行测量，不宣称高保真认证。
- nai-v561-stream-audio-output：独立子进程；原始PCM在stdin长度前缀二进制块传输，控制使用本机私有命名管道和每spawn随机HMAC能力、非零epoch、连续命令/块序号。Begin/Chunk/Seal/Renew/Stop均正式契约；回执MAC绑定接收/提交/设备消费，失联独立短租约关闭，不依赖HTTP锁。每次原始块<=9600字节，环默认96000样本/4秒，整句<=480000样本/20秒。
- workbench-engine/v561_stream_audio：composition root装配当前OutputOwner任务、模型Operation、有界两块网络交付队列、独立PCM写线程和短租约控制。空闲时续租，数据突发也优先50ms检查续租，TTL300ms（协议上限500ms），控制交换200ms界限不放宽。取消/失败先失权并回收子进程，阻塞stdin写不会占住普通网络/控制循环。

入口nai-v561-cosyvoice-stream显式接收配置文件、文本文件、执行程序和报告路径，另可指定prefill样本。它是开发试听入口，没有伪装成现有桌面已接通；配置上限32KiB、文本文件8KiB、实际文本1024字符、默认预缓冲2400源样本/100ms。端点、参考音频、参考文本、期限和最大源样本可配置；没有模型Key或工作区/审批/预算。

## 真实音频证据

唯一一次真实验收位于target-windows/cosyvoice-rust-stream-acceptance/real-01，config.json/text.txt/report.json/service.log均保留。使用现有技术测试参考音频，不作为生产音色许可。

| 指标（同一root单调时钟） | 结果 |
|---|---:|
| 首PCM进入root | 4534ms |
| 首次观察设备源样本推进 | 4663ms |
| 供应商HTTP流读取完毕 | 8720ms |
| 全部源样本被设备时钟确认消费 | 12265ms |
| 接收源样本 | 171840 @ 24000Hz，7.16秒 |
| 设备消费源样本 | 171840 |

设备推进比HTTP EOF早4057ms，证明实际边收边播，而不是收完文件才启动。首PCM到首次设备样本观察约129ms，仅是本轮结果，不是P95保证。HTTP EOF统计包含Rust背压；不是模型独立耗时。模型日志分块32640/48000/91200样本，共171840，与Rust签名回执总量一致。

该证据没有人工听感确认，也不证明声卡物理响度、硬件静音、全程无缺料或无间隙。首次观察至完成约7.60秒、源音频7.16秒，包含观察/控制开销和可能的缺料；未单独计量静音总量，不能声称整段无间隙。视频/OBS未启动。用户可继续以业务短句验证音色及听感，但本轮不重复调用来抹去首响或波动。
