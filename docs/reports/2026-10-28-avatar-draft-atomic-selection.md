# 私有形象草稿原子选择（2026-10-28）

## 实现与验证

工作区现有 `PutPreparation` 在选择形象草稿时，在同一个 SQLite 事务内取消其他形象草稿的选择、创建版本并写审计，再提交目标记录；检查版本冲突、撤权状态和不可变素材身份。页面原型切换为只提交目标选择，避免多次请求中途失败留下不一致。无需增加数据库表。

Windows 定向测试验证选择切换、审计失败回滚、旧版本拒绝与同一草稿撤权不能直接撤销；相邻工作区业务草稿保存测试 2 项通过。桌面 UI TypeScript 检查通过：tsconfig 使用项目源码路径定位契约，避免 Windows 无法读取 WSL 工作区链接。构建在 E 盘独立目录；界面原型尚未接入导航，未进行原生 UI 验收。

## 边界与后续

草稿字段可由页面提交，不是可信素材准入或持续许可；同一草稿撤权的不可逆不等于独立权利账本，创建或删除其他草稿不能代替可信撤权。公共输出目前不使用自定义形象，不能据此声称播放或撤权停播已实现。仍需原生目录选择、预览二进制通道、可信素材/权利绑定、正式 UI/IPC 和公共渲染。未更新运行版、访问用户数据或调用模型；OpenSpec 与 ACC 保持未完成。
