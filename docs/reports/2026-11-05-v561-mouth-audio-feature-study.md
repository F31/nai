# 嘴形语音特征对照

用户对修复比例后的 2.8／3.4 动态构图对照反馈“两侧差不多”，不能仅靠调整整体构图认定嘴形改善。进一步检查 FlashHead Lite，预训练模型的 `audio_guide_scale` 不在 Lite 路径中生效；将其当作 Lite 嘴型大小参数不成立。

隔离实验在同肖像、构图、语音、随机种子和分辨率下，把 wav2vec 输出特征缩放到 80%，与原始 100% 并排；语音本身不变，无编译离线生成各 168 帧。视频 `target-windows/flashhead-acceptance/mouth-embedding-100-vs-080.mp4` 已完整解码。用户反馈“两侧差不多”，未观察到足以采用的主观改善。该操作并非官方支持的嘴型参数；实验代码已从诊断移除，默认模型输入不变，保留 JSONL/视频供追溯。

粗略量化：用 MediaPipe Face Mesh 每 0.5 秒从对照片段抽取一帧，两侧各检测到 13/13 张；嘴角宽／脸宽均值左 0.3763、右 0.3755，内唇开度／脸宽均值左 0.0302、右 0.0305。原始单张肖像嘴角宽／脸宽约 0.3725；静态照片与说话视频姿态不同，指标依赖检测器、编码、角度与抽样，不能据此评价同步、自然度或证实生成嘴巴并未变形。注意这些数值未构成客观画质验收。

音频投影包含线性层、ReLU 和可选 LayerNorm，交叉注意力也有归一化；不能据此推断特征缩放不起效的具体因果。后续应区分静态身份保真、动态唇部形变和清晰度：对授权视频／高质量参考图作同尺寸口部放大对照，测量时保留时间序列及未压缩源，并由用户判断；需要时评估更适合该模型的授权参考素材或视觉后处理，不增加未经质量验证的默认参数。真实直播、OBS 与长稳仍待验收。
