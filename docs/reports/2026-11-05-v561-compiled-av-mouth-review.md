# 编译版真实音画及嘴形反馈

Windows FlashHead Lite，512×512、授权肖像人脸构图、已生成的本地 Qwen 语音，模型和 VAE 编译；只在独立本机诊断窗口播放，不推流。

- 6.72 秒短测：168 帧交付并确认，窗口报告 received=168、shown=168、dropped_late=0、blank_ticks=0；最大设备时钟帧迟到 960/24000 秒（40 ms）。除首块外模型平均约 0.58 秒／0.96 秒音频块，首块约 53.98 秒。该指标不代表口型质量或长稳通过。
- 60.48 秒复测：63 块均生成，但发送端关闭后等待接收器结束超过 5 秒并失败；没有最终窗口完成回执，不能报告全部帧已显示或音画播放通过。GPU 遥测在退出时被主动结束，没有 complete 记录且 power limit 字段缺失，不视为完整长稳证据。
- 用户观看时反馈“感觉嘴巴都变大了”。当前单人构图会放大整个脸部，视觉上嘴部也随之放大；但模型也可能生成过大的口形，现有证据不足以区分两者。Lite 路径不使用 pretrained 专用 `audio_guide_scale`，不能直接调该参数假称修复。既有用户反馈还包括嘴部模糊，以上均未闭环。

下一步对相同原图、语音、种子和最终显示尺寸分别保存构图参考与生成帧/视频，测量嘴部相对面宽并做人工并排评价；先定位是全脸构图、模型口形还是窗口缩放，再选择可配置的修复。同时定位 60 秒接收器退出超时，保持有界超时和真实失败报告；不能简单延长等待或以生成完成替代播放完成。M0 和 OBS 均未通过。
