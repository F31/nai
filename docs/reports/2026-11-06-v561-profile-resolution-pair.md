# 512／768 PyTorch profiler 配对

使用同一授权参考、种子 42、49 帧、四步、SageAttention 2.2，无编译、无设备播放、无 Qwen／OBS 并发。分别采集第二块，含 profiler 开销；单轮且未锁定频率和功耗，不能当作性能验收或严格加速比。

| 指标 | 512 | 768 |
| --- | ---: | ---: |
| 第二块墙钟（秒） | 1.8894 | 1.8643 |
| GPU kernel 累计（毫秒） | 637.7 | 1602.0 |
| GPU kernel 数量 | 11716 | 11746 |
| GPU memcpy 累计（毫秒） | 4.15 | 30.70 |
| 最大单类卷积核累计（毫秒） | 201.3 | 485.8 |

768 的两类主要 CUTLASS 矩阵乘核分别累计约 401.1 和 210.2 毫秒。累计时间可能含重叠，且不等于墙钟关键路径；两轮墙钟接近但 kernel 累计差异显著，不能把采样墙钟直接比较或推断 GPU 闲隙成因。该结果支持分辨率显著增加 GPU 工作量，优先研究卷积和矩阵乘；没有证据支持把主要问题归因主机／设备复制。主路径已编译，仍需编译版同条件采集以核对实际热点。

原始文件 `target-windows/flashhead-acceptance/torchprofile512-20261106.*` 和 `torchprofile768-20261106.*`。本次未实现新加速、未改变默认；任务 0.69 保持未完成，编译版、无采样受控计时和 Qwen 争用仍待补齐。
