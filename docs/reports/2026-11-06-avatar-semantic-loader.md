# 语义数据加载与音频窗口

新增独立语义数据加载器，读取版本1目标块和回贴alpha，不伪装上游数据集。检查原帧身份、时间、单调顺序、路径限制、文件存在及图像尺寸；输出 RGB CHW、alpha及原图区域。alpha不等于训练输入遮罩或损失遮罩，后者尚待定义。

音频窗口按原视频帧编号而非局部样本编号计算。25FPS与50Hz特征的默认20帧窗口为40×1024；第250帧取特征480–519，片头夹持而不环绕，缺少中心音频或非法维度／非有限窗口拒绝。4项合成特征定向测试通过；100个真实目标／遮罩经加载器解码和形状检查通过，但音频仍为明确测试用零特征，不授予真实特征／训练集成通过。

尚未启动训练；下一步使用核准的真实音频编码器提取特征并验证全片时间基，再实现训练输入和验证集分割，避免同帧训练验证泄漏。候选许可闭包和最终画质仍待核实。
