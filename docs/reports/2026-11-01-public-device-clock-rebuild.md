# 停止后重开下一条静音流

## 结果

第一条静音流代次为 1。它的设备位置超过 30000 后，重放旧租约把它停下。工作线程退出后再等 50 毫秒，读数仍是已播放 1644、提交 2400、设备位置 43200、频率 384000、流代次 1。

随后用代次 1 打开下一条流，不把 43200 传进去。新流在启动前读到自己的设备位置 0，代次为 2。返回探针时已播放 0、提交 0、设备位置 0、频率 384000。放开发送后读到已播放 1018、提交 2400、设备位置 28584、流代次仍是 2，同一条接纳规则通过。把这条观测的流代次改成 0 则被拒绝。

实验库 9 项通过，不打开声卡。被忽略的 `rebuilt_silent_stream_starts_at_its_own_zero` 本次显式运行通过，用时 1.74 秒。`openspec validate v49-realistic-avatar --strict` 通过。1.3.10 没有勾选。
