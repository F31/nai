# 形象绑定与撤权事务原型（2026-10-28）

## 本轮实现

新增隔离 SQL 模式与 SQLite 内部事务函数：每个工作区最多一个当前绑定，选择使用预期版本 CAS；撤权记录素材包及许可摘要，历史撤权组合不能通过后续选择恢复。绑定变化和审计写入同一事务。调用方必须事先核验身份、权限、素材准入与许可，并先撤销媒体输出；事务函数不签发输出许可。

内存 SQLite 定向测试通过，覆盖首次选择、过期版本、审计插入失败后事务回滚、撤权后禁止恢复、切换其他许可后仍保留历史撤权以及取消不改变状态。测试使用 E 盘构建目录，没有访问或迁移用户数据库。

## 未闭环

新表未安装到生产数据库，尚无一致备份、迁移 journal 或恢复路径；函数未接入 Store、权限和幂等处理、可信权利源、P0 媒体撤权、IPC 和界面。不能把该原型视为已经完成的工作区管理或直播撤权，也不能将输入摘要视为实际许可。相关 OpenSpec、Windows 实机和 OBS 验收及 164 项 ACC 保持原状态；本轮未更新运行版或调用模型。
