# 迁移备份快照对象闭包（2026-10-28）

模型迁移备份现从已经生成的 SQLite 快照枚举所有 object_versions 引用，再复制并校验对象正文；包括已删除对象仍保留的历史版本，避免实时数据库改变或删除状态造成快照与文件不一致。Windows 存储定向 7 项通过，覆盖快照后源库变化、历史引用、取消及既有备份恢复回归。

当前形象包未纳入生产备份，形象引用存在时模型迁移保护仍拒绝创建或复用不完整备份。素材闭包复制、独立验证、迁移日志与恢复、权利和公共渲染仍未完成；本轮未更新运行版或修改用户数据库，OpenSpec 活动，164 ACC 不变。

> 勘误：后续整链验证发现删除对象会清理正文，已改为只复制未删除对象的历史版本；详见 [勘误](2026-10-28-avatar-backup-deletion-correction.md)。
