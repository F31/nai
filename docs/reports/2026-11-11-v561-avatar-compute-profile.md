# 音频特征与视频生成分阶段实测

## 结论

U03b2实现及实测完成。本次业务3个块中，音频特征CUDA流阶段计时合计66.95ms，视频生成4546.70ms，视频占两阶段和的98.55%。应优先拆分视频内部去噪和VAE，而非优先替换TTS或重写传输。该比例不是GPU利用率/纯kernel占用，也不能据单次测量宣称已经优化吞吐。

## 实现

新增scripts/avatar_compute_profile.py，每块3个CUDA事件，分别记录音频特征、视频生成的主机调用墙钟及当前CUDA流经过时间；只在已有块末torch.cuda.synchronize之后读取事件，没有加入阶段间同步，模型参数/随机种子/调用顺序/画质不变。预热epoch0与业务epoch分别记录，每个实际块一条固定数值日志，无文本、PCM或素材信息，不积累逐帧数组。

当前流经过时间可能包含CPU提交空档、同步和调度/并发争用，不能当作独占kernel运行时间。主机调用时间也可能含内部同步，不能命名为纯CPU计算。没有修改上游/环境依赖或控制协议。模型本身原有generate内同步仍保留。
