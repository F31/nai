# 播放指标 Windows 原生故障验证

热态GPU真实模型重放中止后，改用明确标注的16×16合成帧及静音PCM夹具验证原生共享内存／Rust窗口／设备时钟，不运行模型推理或付费API。不是数字人质量或GPU实时证据。

tests/v561/test_flashhead_rust_transport.py 的5项Windows测试全部通过：共享槽循环与确认、接收器退出无ACK、长缓冲耗尽后退出、音频结束生产者未关闭则有界失败、挂起接收器不伪装完成。故障项新增断言实际stderr包含AV_TIMING_INCOMPLETE、音频提前完成原因和24000时钟，未以mock播放器替代真实进程。

6.72秒静音夹具：168帧接收及显示、入口迟到0、合并0、空画面事件0、结束排队0，首次窗口提交为接收器启动后336ms。AV_BUFFER约每秒输出，最后排队帧提前量由约109868下降至909样本（24000Hz），然后完成；不等于整段缓存音频时长或硬件呈现回执。

尚需真实模型可用环境的重放、全部早退统一统计、LLM／TTS首响与生产仲裁装配，0.70保持未完成。前述GPU温度问题没有因静音夹具通过而解决。
