# V48-05 当前公共窗口静音预装载

日期：2026-10-25（本轮跨日）。状态：阶段工程实现/定向实测完成；V48-05仍InProgress，164ACC全部pending。

## 交付

已确认的本句新增“准备本句音画（静音）”。root重新核验持久批准、当前来源/epoch/事实、实际PCM与许可、守门及同一窗口，再通过原生私有能力交付有界原始PCM工件。文件路径在返回网页前被剥离，网页API另行拒绝任何私有路径回执。原生宿主只将能力交给自己持有的固定keeper子进程。

实际常驻窗口读取受控根内的只读文件，复核hash与首尾样本帧，然后在固定worker中静音初始化Windows默认播放设备，返回绑定当前窗口UUID及描述hash的真实回执。界面呈现实际设备名、提交样本0和限时自动回收；设备不可用保持显式未准备。公共画面保持静态待机，音频执行deadline恒0，不授播放能力。

准备4秒deadline，完成后最多5秒持有；队列容量1、每窗一个设备worker、每句最多20秒24kHz单声道/480000样本。取消/停止不等待数据库或SDK锁。Windows临时PCM用新建/删除关闭标志，撤销及生产者强杀均回收，未对现有用户素材执行清理扫描。

共享CPAL设备代码提取到adapters/audio-cpal，私有试听与公共keeper复用，进程实现不互依赖。新增内部库，无新第三方版本/服务/常驻进程；SDK只在媒体进程调用，root不依赖该适配器。
