# V48-06：任务上下文、取消树与问题池增量

日期：2026-10-26。对应 ADR0176 / OpenSpec `2026-10-26-v48-06-context-question-pool`（已严格校验并归档）。

## 实现

- 从 Protobuf/工件 JSON Schema 开始，新增7种消息及4个操作；生成后再实现运行时、存储、宿主和 UI 消费者。
- 共用 AgentTaskContext 绑定工作区、发布快照和事实引用哈希；Operation 子树继承取消及最短期限，深度有界。
- 问题池父工件与 FAQ 子工件持久化，120秒/32条滚动窗口、去重计数不续期。两桶索引读取有界，内部索引不能经通用对象读取泄露。
- 角色、资料头、撤销和有效期变化后拒绝处理或采用；取消父问题结案未采用子候选。事务审计失败回滚，不能返回假取消成功。已采用的草稿不会被父取消删除。
- 问答页增加入池、自动读取/刷新、处理、查看候选及取消；迟到结果按当前上下文隔离，取消未确认时隐藏旧候选并要求读取核对。
- 模型调用次数为零，不修改用户现有内容、Key、模型或系统代理，无数据库表迁移。
