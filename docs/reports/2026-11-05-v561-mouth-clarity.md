# 嘴部清晰度与 512 连续播放检查

用户指出嘴部偏模糊。使用同一授权肖像构图和同一段 Qwen 语音生成 512×512 与 768×768 的离线对照；用户反馈 768「略有改善仍模糊」。768 模型去掉首块后每个 0.96 秒音频块约需 1.48–1.60 秒，明显慢于实时；两种离线结果不代表正式直播。对照文件 `target-windows/flashhead-acceptance/jjf-mouth-512-vs-768.mp4` 左 512、右 768，原始 768 为 `jjf-facecrop768-mouth-review.mp4`。

参考图单独经当前 VAE 编解码后输出 `target-windows/flashhead-acceptance/jjf-vae512-roundtrip.png`，未经过说话驱动。在固定嘴周矩形内测得简单拉普拉斯方差：输入约 245、VAE 重建约 197；该数值仅为局部边缘强度代理，不能独立衡量感知质量，也不能归因全部说话模糊。应继续比较音频驱动输出、牙齿/嘴唇细节和时序表现，而非简单锐化或宣称提高分辨率已修复。先前隔离 OBS 场景本身为 384×384 输出，会额外缩小更高分辨率的来源；具体用户观看的是哪个播放入口尚未确认。

采用用户此前认为口型形变明显改善的人脸构图，512×512、本地 Qwen 语音循环做 60.48 秒音画：1512 帧全部接收和提交，未记录安全画面；排除首块平均 0.7433 秒／0.96 秒音频块，时段 62 个 GPU 样本最高 69°C、10407 MiB。单轮短测不能推断稳定实时。

后续使用本轮新合成 Qwen 语音循环，Qwen 在线和隔离 OBS 同时运行，尝试 600 秒；第 384／625 块后退出，窗口统计接收 9192、提交 5625、最长安全画面约 117640 ms，未完成十分钟。日志为窗口退出后诊断未完成，具体触发窗口退出的原因未确认；发送端随后因管道错误失败。播放相关采样 135 点最高 82°C，整机显存最高 10450 MiB，系统内存最高约 25327 MiB。资源采样进程继续运行到总计 600 秒，期间混入后续 768 试验，因此不得把完整 summary 的最高显存用于这次播放。OBS 限时录制在目标消失后仍运行，已停止隔离进程；留下的录像未正常封装但 ffmpeg 可读取，不能作完整录制通过证据。

本轮性能数据来自 `rust-av-face512-60480ms.jsonl`、`rust-av-face512-fresh600s.jsonl`、对应 stderr 及 `baseline-face512-fresh600/`，均位于 `target-windows/flashhead-acceptance`。M0 和嘴部质量均未闭环；下一步需提高细节并核验完整音画，同时定位长时间安全画面和窗口退出原因，避免降画质掩盖质量问题。
