# Design
增量路径的资源准入：当前句读者激活即签发下一次资源permit，但串行TTS生产者必须先拿到当前供应商真实EOS/成功摘要才会用它；媒体封口和设备播放仍独立复检。PCM分块队列每句最多16×9600字节，避免GPU忙时容量1通道反压推迟供应商EOS和下一句启动；句级仍当前+一个未来，不增加模型并发。该调整不授予播放权限或改变模型/设备期限。
C04b实施：GPU所有权提升为整段Producer，生成和播放以匿名文件的已提交PCM/帧游标衔接，不以RenderComplete作为读取起点。Producer最多领先当前播放句1句；播放提升当前句才允许再下一句生成。读者核对每帧后即可消费，最终完成仍要求真实EOS/hash、RenderComplete及设备回执。文件锁只覆盖单次有界读写，主窗口不持文件锁；Stop撤销全段并有界回收Producer。已有18项CPU/失败证据保留，新增未封口前消费/无完成假象测试，再独立最多3次本地联测。
future-native-02完整159360样本三句，但TTS完成后才开始未来GPU，源提前准备/GPU重叠性能断言未通过，保留失败。改为未来源同样经容量1分块通道，首包即可进入未来GPU，不先等整句TTS；完成后临时帧/PCM统一封口验证再消费。移除不再使用的整句Prepared源分支；当前加一个未来句约束与后续TTS准入不变。独立修订最多3次本地调用，不放松性能断言。
future-native-01因对已继承权限的Operation重复bind而被InvalidArgument拒绝，2次本地TTS、未完成首句；失败保留。修复为直接从当前句派生model_child（自然继承父许可/期限/取消），不改内核绑定规则。独立future-native-02最多再3次本地调用，不自动重放失败测试。
C04候选：当前句GPU完成后，同一GPU线程最多生成一个未来句，设备及主窗口继续播放当前句。未来已校验帧写入配置temp_dir下自动删除的有界临时文件，内存只保留一帧及有限元数据/PCM；不扩大现有当前帧队列。文件上界由该句max_samples、25fps和配置尺寸计算，每次读取再次核对帧hash/epoch。未来句的下一次TTS permit延后到该句成为当前句才释放，避免产生第二个未来句。提前消费的句绑定父取消及当前句控制检查，关闭/停止使准备失效并删除临时文件。主窗口在设备已完成但未来GPU未完成时继续处理事件，报告真实空窗，不延后当前句起播伪造收益。首轮最多3次本地合成，失败保留。
真实补验shared-stop-01在首句播放中SOURCE_BUSY失败（1次TTS，未到停止步骤）。设备线程原try_lock一次失败即退出，会把普通微秒级生产者争用当成设备故障。改为至多1ms的try_lock重试，期间每次复检stop/lease；超预算仍终止，不填补静音或放宽真实欠载/时钟期限。纯锁竞争/撤销测试及独立停止重验，最多再2次本地调用；失败记录保留。
Root装配：整段持有一个ContinuousSession及其独立控制线程，容量1的句请求队列；每句只借Handle，数据仍由有界ExternalPCM提供。控制线程维护script_epoch/全局hash/递增命令，收MAC及真实时钟后映射为句内epoch和偏移，逐句Unavailable→Running→Stopped；完成必须有匹配SegmentProgress。句间继续有界续租而不重复开设备，整段结束FinalSeal；Stop/EOF/期限撤销父操作并回收子进程。当前仍在前句设备结束后开始下一句GPU，不授予视频预取/无缝。
设备装配切片：stream_audio升级wire3（拒绝wire2），增加OpenScript/SegmentBegin/SegmentSeal及MAC覆盖的逐句进度；原有Begin仍表示合法单句业务，不接受旧wire。全段设备只开一次，只有已验证的句尾可静音等待，设备帧到源样本映射不把等待计入播放。普通句内短读仍失败。先交付执行器及真实原生多句测试，再装配Root共享设备；不能以执行器通过宣布工作台已连通。
单设备前置契约采用独立continuous_audio消息：一条script_epoch全局源样本时轴，每句有sentence_id/generation_epoch/source_start_sample；设备全局提交/播放值映射回句内，封口不是设备完成。先实现纯媒体边界跟踪器，不把定义消息或内核测试当作设备已装配。当前及未来句合计最多2项，下一句仅在前句样本数/哈希封口后可确定起点；旧身份、重复封口、越界、回退均终止该跟踪器。PCM继续走独立原始媒体通道，跟踪器只保留哈希和计数。C03拆分契约/内核与设备装配，以免状态混淆。
先将窗口所有权提升至整段脚本协调器，由每句输出借用；诊断/单句原入口仍局部创建。脚本等待未来源时用有界轮询处理窗口消息，关闭立刻取消整段；没有后台持续播放。每句结束清安全画面，不保留上一句活动口型。窗口只在整段完成/停止/异常时销毁。

记录窗口创建数、源等待耗时、前句设备结束到下句首声间隔，使用同一origin。该切片音频子进程和GPU时序保持不变，不能用窗口复用授无缝或性能提升。之后先修改协议定义有界跨句设备源身份/时轴，再消费者；下一句GPU只允许一个有界未来帧集且可立即取消，不能把两句媒体放在JSON控制通道。

第一切片定向CPU等待取消、关闭回调，以及最多3次本地TTS真实三句同窗口验证；保留既有GPU/PCM/时钟边界，不做全量测试。旧运行窗口不强制关闭，候选在独立E盘目录验证后再维护更新。
