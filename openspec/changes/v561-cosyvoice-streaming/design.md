# 设计

C05d2a：HTTP响应提供每进程随机instance与每任务随机request ID；状态端点只保留有界、短期内存生成证据，不保留音频或建立持久账本。Rust仅在传输正常结束且completed回执的instance/request/样本/SHA256全部一致后允许诊断Seal。状态未知、过期、错误或摘要不符拒绝，沿用原Operation期限与取消，不自动重新合成。此切片不证明音色/权重身份，不开放缓存；缓存身份与实际命中另验。

C05d1：生成线程在迭代器正常耗尽且close完成后锁存完成状态、实际PCM样本数和SHA256；清理异常覆盖正常结束。锁存与取消共用短锁，正常结束后的ASGI清理不改写完成证据。空输出、超总样本限额、期限或取消不产生completed。该证据只描述生成，不证明HTTP完整交付、设备消费或播放许可；实例/音色绑定、HTTP查询及缓存发布属于C05d2，尚未装配。

C05首切片：现有桌面主入口仍使用历史工作区协议，故使用同一Tauri/React包的独立V561语音入口、独立窗口label/权限与静态产物，不桥接旧DB。正式v561-start仍拒绝完整直播启动。原生私有stdio控制进程只接受Start/Stop，读线程Stop/EOF立即调用weak StopHandle；外部Operation进入C04播放函数。窄宿主无模型逻辑，只管理固定子程序/显式配置/单飞/状态，停止以原子代次优先撤销，再由监督线程发停止及有界回收。迟到状态按代次拒绝。该入口是必要输出安全/性能体验切片，不表示M0或完整产品UI完成。

C04纵向设计：独立streamaudio包定义Begin/Chunk/Seal/Renew/Stop及签名回执；控制消息不带PCM。stdin单块长度前缀/原始PCM最大4800样本，块摘要与来源范围通过私有命名管道认证，首令绑定非零epoch和每spawn随机能力。接收端环最多96000样本、整句最多480000，播放权不超过已验证范围；独立500ms租约。24k源样本通过48k设备帧区间账本映射，缺料只写静音、不推进源时钟，不复用旧四段CueSpan作为流式环。Rust HTTP适配器有界收发并处理奇数字节/取消/断流；传输EOF只形成当前诊断Seal，未等同供应商应用EOS。CLI为明确本机试听入口，未接桌面或公共音画许可；C05保留生产完整性与联合音画任务。

C07执行设计：模型块长改为请求局部变量，初值默认取模型base hop，可通过COSYVOICE_INITIAL_HOP_TOKENS选择不超过模型最大值的base整数倍。AR线程异常传回生成器，finally等待实际线程退出后清理请求字典。服务使用单个生成工作线程、两块有界交付队列与非排队409准入；断开只关闭交付，后台在原占位下排空模型后才释放。总期限默认60秒，可配置；卡死线程保留busy并使health显式blocked，不能放行另一GPU任务。此设计没有承诺GPU抢占取消；真正取消仍属于C05。
