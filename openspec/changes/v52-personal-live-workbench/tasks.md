- [ ] 1.2 定义并生成个人策略、来源、授权、预算和一键准备状态契约；明确手动/自动选择及撤权边界。
- [ ] 1.2.1 在现有 AgentTaskContext/LiveContext 基础上定义直播目标、知识引用、计划、结构化意图、已播回执、决策原因与取消契约；先生成再接消费者。
- [ ] 1.3 设计一致备份、版本 journal、旧预算与审批数据迁移、崩溃恢复，添加契约和迁移故障测试。

- [ ] 1.4 明确本轮领域、存储、UI、适配器和组合根的职责/依赖；对热点按真实需求渐进拆分，运行依赖边界检查并记录例外。

## 2. 后端策略与直播闭环
- [ ] 2.1 实现默认工作区和场次/内容版本幂等准备及恢复；不覆盖原有资产。
- [ ] 2.2 实现不限预算的个人调用策略与 unknown 费用记录；保留用户已启用限制，验证失败/欠费和并发。
- [ ] 2.3 实现手动单次操作和显式自动回答策略，接入可信来源、有效期、平台权限、P0/真人接管及 epoch 复检；验证不重复和不复活。
- [ ] 2.4 实现可取消一键准备及依赖状态；OBS 进程、来源、音轨和信号分别观察并如实报告未知。
- [ ] 2.5 建立平台公屏连接器能力/房间/权限契约与事件去重；先完成真实获准渠道的接入，缺条件保持不可用。
- [ ] 2.6 实现 0–100% 概率抽样、有界队列/过期/超载计数及动态配置，接通 AI→TTS→数字人回复和句边界归位，覆盖取消与旧代次。
- [ ] 2.7 实现仅主题讲解与主题讲解＋公屏互动的配置、连续讲解和切换取消；无公屏时可独立使用。
- [ ] 2.8 实现单一直播智能体的计划、实时决策、相关性/去重/优先级、语音队列和回执驱动记忆；复用现有问题池/任务上下文。
- [ ] 2.9 实现目标/话题变更、来源过期、工具配额、任务取消与真人接管后的恢复；覆盖无依据及不可信输入。
- [ ] 2.10 将智能体受控讲解/回答、语音样本、渲染帧和真实播出回执绑定同一会话与检查点；可替换后端不改变取消与授权边界。
