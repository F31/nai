# Design
接管更新：受控常驻入口G06暂缓，以下入口段仅为未实施设计；未验证代码与execution_candidate配置已撤回，既有FP8/图诊断保留。当前主线转为512/3候选、TTS首块/预填充及M0真实音画，详见2026-11-11-v561-kimi-takeover-review报告。不得据诊断的短片接受默认改变执行精度。
受控入口切片：avatar-worker配置新增显式execution_candidate（fp8_ffn_graph及层/双预算），默认缺省不激活。先正式生成契约，再修改Rust校验/Python消费者。常驻worker在原编译静音预热后维护安装组合并再次静音预热；每个实际推理块将当前Job绑定到候选，逐步取消不得引用维护Job。候选存活贯穿单模型会话，正常退出显式逆序释放，进程异常由操作系统回收；启动失败不签Ready、不静默回退。该入口仅允许独立候选配置，不修改用户工作台文件；原三句/设备取消证据未有前不激活默认。
组合性能复核可显式指定1–3对交错热测，图保留期间只切换forward的图重放/原FP8调用，权重和图不释放、不重新捕获；每次都复检输入身份/取消。原调用不消费或覆盖图输出，下一次重放仍完整copy全部输入。比较不带profiler或像素留存的相邻热运行，记录顺序及调用/重放计数，不用最佳单次授实时通过。
第二切片显式允许FP8 FFN与图重放组合，但仍禁止profiler/像素留存混入性能运行。先建立BF16参考，再维护安装FP8并留FP8热参考，然后捕获单步图；图输出须与同实例FP8参考逐帧一致。先同步并释放图、恢复原forward，留FP8恢复参考，再释放FFN并恢复BF16；异常同样逆序回收。静态FP8缓存与图缓存分别显式预算，不能在图存活时替换其参数buffer。组合不自动进入默认，新增质量以FP8参照的hash等价为依据，不能把BF16不等价称回归失败。
缓存预算同时核对捕获前后的allocated/reserved增量（事后检测），不能将reserved增量为0解释为零成本。旁流预热期间取消也先同步待完成工作再释放输入，避免异常路径提前回收静态buffer。
仅捕获一次model.forward（单采样步），不捕获完整generate或音频/渲染/传输。四个CUDA Tensor输入复制到同一组静态buffer，每次核对shape/stride/dtype/device；输出clone避免下一次重放覆盖。维护阶段先在旁流预热两次，再捕获；每次重放前后check当前Job，不把CUDA执行当作可硬中断。候选退出同步并reset图，恢复原forward；失败不静默回退。输入buffer加输出的显式静态预算准入，另记录捕获前后CUDA reserved增量并超预算拒绝，后者是事后检测而非硬件内存配额。只有一张图、不建无界形状缓存。原BF16/相同PCM/seed前后hash复核；维护与热测分开，禁止性能运行混入profiler/capture-IO；FP8联用仅按上文第二切片显式执行，首切片已验证单独图重放可用。固定维护240秒/业务45秒。生产取消/失联仍需后续原生验证，离线成功不授34ACC或实时通过。
