# 设计
Root Context用不可序列化的共享身份绑定epoch、参考形象摘要和父Operation。Source只能由Context创建并持有其身份，封存时必须与目标Context为同一对象；相同字符串不等于同一执行上下文。Source ID严格递增，保存独立SHA256、起点与样本数。变化或取消使整批失效，不从旧批次分离前缀恢复。

合并不插入静音、不改字节；总计最多两源/144000样本，按全局ceil(total_samples/960)限制256MiB像素。临时PCM在配置E盘目录create_new，worker独立核对合并摘要。Root在Complete后核对独立像素再进入播放器。帧保持worker原始绑定，不伪造共享槽或按段重写像素时轴。

连续帧网格的段边界记录为原始样本端点。极短第二段可能没有单独的新帧，不能强插一帧或填静音。段呈现归属由累计样本端点对应的全局帧索引计算。当前批次仍完整生成后播出，不能当作在线边播边生。

单一生成任务延续同一模型的运动/音频历史，不在段边界重置；因此不宣称与旧分段任务逐像素相同。尺寸/四步/构图不变，主观接缝与口型质量单独待验，不更新生产默认。已有画面去重/设备就绪门/P0保持。

合并只接受已选定并提交的同一输出单元，不能自动提交仍可替换的一槽预取。上层决定插问句边界切换时机；P0立即取消整体，当前不实现生产插问路由或部分恢复。
