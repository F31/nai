# 设计：真实 Provider 接入纪律与真实调用证据的判定边界

## 背景

W30/W31 把 B01 的**判定机制**（黄金集门槛）与**载荷载体**（题集 schema、目录、`check --golden`）落到 portable；W19 把 A02 的**第二家替换**用同一条调用函数对两家协议实测过；W29 把 B04/R06/B06 的**度量与复盘**落成纯函数。这些机制只差一件事：**一次真实调用**。

真实凭据到位后，风险从「机制不存在」切换成「接入过程会污染仓库或把事实读错」。本设计把接入纪律固化成可检查的形态，而不是写进文档靠自觉。

实测得到的四条事实（构成本设计的输入）：

| # | 事实 | 含义 |
|---|---|---|
| F1 | 文本网关 `/v1/models` 返回 200，其真实模型清单**不含**配置里写的那个模型名 | 配置里的模型名可能不存在于端点 |
| F2 | 同一端点上模型甲 2xx、模型乙 403（报文含**剩余余量为负**） | 可用性是**账户状态**，不是端点的性质 |
| F3 | 语音端点以**显式错误码**拒绝不合书写形式的音色标识；按端点要求书写后返回音频 | 契约差异只能靠实测发现 |
| F4 | 本机对文本端点报证书吊销检查失败，而对语音端点不报 | 主机环境差异，**不是**端点事实 |

## 决策

### D1 落点：`xtask/src/secrets.rs` + `scripts/provider-smoke.mjs`，**不动 provider-core**

`xtask` 是 tool 层，**无依赖限制**，可依赖 kernel 也可调用 `git`；既有 `check-deps` / `check --registry` / `check --golden` 都在这一层。`provider-smoke.mjs` 沿用 `control-smoke.mjs` / `engine-smoke.mjs` 的形态（Node 22 + `--env-file`，零新增依赖）。

**否决**把真实调用做成 `provider-core` 的集成测试：那会把网络与凭据变成普通 CI 的前置条件，与 D01「不引入 GPU/SDK 作为普通 CI 前置依赖」同源。**否决**新增 `Protocol` 分支或适配器：两家端点都是 OpenAI 兼容，`Protocol::OpenAiCompatible` 已同时 `serves` 文本与语音（见 `binding.rs` 的 `serves`），接入只是 `ProviderProfile` 的一份配置。

### D2 扫描域是**git 会发布的内容**，不是磁盘，也不只是暂存集合

扫描域取 `git ls-files --cached --others --exclude-standard`：已跟踪文件 **加** 未跟踪但未被忽略的文件。这是三条边界的取舍：

| 方案 | 后果 | 结论 |
|---|---|---|
| 扫磁盘 | 被忽略的本地凭据文件必然自命中 ⇒ 本机无法持有凭据 ⇒ 检查被绕过 | **否决** |
| 只取 `--cached` | 新增文件在 `git add` 之前不在域内 ⇒ 凭据被发现时错误几乎已铸成 | **否决**（初版即此，实测发现后改） |
| 取 `git diff --cached` | 只拦当次暂存，历史与未暂存皆不覆盖 | **否决**（范围太窄） |
| `--cached --others --exclude-standard` | 拦在暂存之前；被忽略路径（`.env`、`node_modules/`、`target/`）仍不在域内 | **采纳** |

被忽略性由 `.gitignore` 决定，因此「本机凭据放哪里安全」与「扫描拦什么」共用同一份规则，不存在第二套需要同步的约定。

### D2b 该边界由测试钉住，不靠注释

两条测试分别钉住两个方向：被忽略的 `.env` **不在**域内；一个**运行期新建、未暂存**的探针文件**在**域内。缺任一条，未来一次编辑就可能把域收窄回 `--cached` 而无人察觉。

### D3 阈值用「前缀 + 各前缀最小长度」表，避开测试哨兵

仓库里**已有一处同前缀的测试哨兵**（`crates/nai-kernel/tests/monitoring.rs` 里的 `sk-live-must-not-leak`，前缀后 18 字符）。实测确认：把最小长度定为 32 后，全部待发布文件**零命中**，而真实凭据（前缀后 48 字符）会被命中。

| 前缀族 | 最小长度 | 依据 |
|---|---|---|
| `sk-` / `wk-` / `pk-` / `rk-` | 32 | 实测哨兵 18，真实凭据 48；留出余量 |
| `ghp_` / `github_pat_` | 30 | 平台固定长度 |
| `glpat-` | 18 | 平台固定长度为 20 |
| `xox[baprs]-` | 20 | 平台形态 |
| `AKIA` | 16（且须全大写字母数字） | AWS access key id 固定 16 |
| `AIza` | 30 | 平台形态 |
| `Bearer <令牌>` | 32 | 拦住整段粘贴的 curl 命令 |

**不采纳**纯「长度 ≥ N」而无前缀的通用规则：实测会命中 `token: "cloud link unreachable"` 这类**合法词汇**（全库数十处 `Finding` 的 `token` 字段）。**不采纳**在源码里写真实样例：扫描器源码与被跟踪的测试夹具都**不得**含可命中的字面量——测试夹具在运行期拼接。

### D4 扫描器源码不得自命中

`xtask/src/secrets.rs` 自身会被扫到。因此前缀写成**独立短字面量**（`"sk-"` 之后紧跟的不是长度达标的串），测试夹具用 `format!` 在运行期拼装。这既避免自命中，也让「扫描器本身干净」成为一条可断言的性质。

### D5 缺凭据 = `CAPABILITY_NOT_READY`，非零退出，且**不写任何文件**

缺失任一变量时：打印缺失的**变量名**（不打印值），以非零状态退出，**不写出**证据与音频。**否决**「有就用真实、没有就回退桩」：那会让冒烟在缺凭据时依然变绿，正是 §30.1 点名的「用固定素材冒充」。

### D6 模型可用性是**账户状态**，逐模型记录

同端点逐模型发起一次最小调用，逐条记录 HTTP 状态与网关错误码；配额类报文**原样提取**剩余余量数值。结论只覆盖被实测的模型。**否决**「取一个样本代表端点」：F2 说明同一个 key 在同一个 host 上既能通也能被配额拒。

### D7 证据只含事实，**连前缀都不含**

证据字段固定为：`host`、`path`、`method`、`protocol`（协议名）、`auth_scheme`（**只记方案名**）、`model`、`status`、`gateway_error_code`、`usage_fields`、`bytes`、`media_type`、`note`。**否决**记录任何请求头原值、请求行原文或凭据片段。凭据**从不出现在文件名、日志或证据里**。

### D8 音频证据是**真实字节**，字节数与 media type 来自响应

落盘的音频长度取自**响应体长度**，media type 取自**响应头**；本地不得推断或补默认值。空体或错误报文一律判为**未产出证据**。

### D9 端点契约差异**以实测为准**

F3 的教训：音色标识须写成端点要求的完整形式。**否决**在冒烟里对失败输入做静默重试或归一化后只记成功——那样证据不再具备纠错能力。4xx 必须连同错误码如实记录，且**不得**被读作「端点不可用」。

### D10 主机差异是**环境事实**，须记录且不得读作端点事实

F4：本机对文本端点报证书吊销检查失败（`CRYPT_E_REVOCATION_OFFLINE`，schannel 已知行为），对语音端点不报。证据 MUST 把该事实记为**主机环境**注记；**否决**据此宣称端点不可用，**否决**把它静默吞掉。

### D11 冒烟**不是**验收

连通成功只新增连通性事实。B01 仍缺题集与完整评估，O01 仍缺约 10 分钟首句演练与约 30 分钟真实输出验证。**否决**以冒烟结果改动这两项的登记状态。

### D12 不改 `provider-core`，不新增证据目录约定

`Protocol`、`ProviderProfile`、`LlmClient`、`SpeechClient` 全部不变；18 包与依赖方向不变；零新增外部依赖。§30.1 已为 RAG/媒体/升级/UI/性能指定目录，**未为真实 Provider 证据指定目录**；音频与事实记录落 `docs/reports/evidence/`，与既有报告同处 `docs/reports` 之下，不臆造新的顶层约定。

## 验证

- `cargo xtask check --secrets` 在全部待发布文件上零命中；对拼装出的合成凭据命中并列出文件与行号；对被忽略的本地 `.env` 不命中，对运行期新建、未暂存的探针文件命中。
- `scripts/provider-smoke.mjs` 在缺变量时非零退出且不落文件；在变量齐备时对两个端点各产出事实证据；证据文件经扫描确认不含凭据前缀。
- `cargo test --package nai-xtask --lib` 覆盖扫描器判定；portable 门控覆盖其余包。
- registry 的 S07/O01/B01/A02 状态按 D11 的口径更新。

## 环境边界

- 文本端点与语音端点均为**外部付费服务**；余额与渠道由账户状态决定，不在本变更可控范围。
- 本机 Windows 证书吊销检查处于离线状态，故冒烟对文本端点需 `--ssl-no-revoke`；这是**主机**差异。
- 冒烟产生**真实计费调用**；因此每次运行只发最小请求（每个模型一次最小调用、语音一次短句），不跑批量。
- 真实凭据只存在本地未跟踪 `.env` 与进程环境中，不进仓库、不进证据、不进日志。
