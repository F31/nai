# Proposal

## Why

R1 窗口预检已接通，但宿主直接读取固定路径：新进程未写报告时可能展示旧结论。损坏报告还会被默认空字段掩盖。该缺陷阻断当前首次设置交付的可信预检。

## What Changes

- 每次宿主预检先失效旧报告，同一宿主并发请求具名拒绝。
- 失败与超时不保留本次残留报告；报告有界读取并严格检查必要字段。
- 不把子进程原始输出拼入预检错误；有效拒绝报告仍正常展示。
- 增加真实子进程故障测试及真实 engine 重复运行测试。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-shell`: 窗口预检只呈现本轮生成的完整报告。

## Impact

对应 W09/W10 与 R1 交付顺序 3（D14 仅追溯），依据 V3.11 §11.5、§12.3、§15、§28.6，ADR 0131。只修改独立原生壳及测试，不改契约字段、生成代码或依赖，不增加常驻资源。A12/O01 与 Windows/设备认证状态保持原值。
