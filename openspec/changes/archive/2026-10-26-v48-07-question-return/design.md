# Design
采用protected live_run中的单个interruption及唯一ID，绑定FAQ任务哈希、当前发布源、epoch、模型与已存在自动范围。入选时请求句边界暂停；实际暂停后记住sentence_cursor，再以独立回答身份准备音频，回答不增加原稿submitted_sentences。root公共守门必须核验FAQ原文及事实，原生只复用现有实际确认/输出路径。返回仅在可信提交完成后发生；取消和失败保留暂停，不自动重放未知回答。普通页面不能准备内部音频或确认媒体。
范围有固定期限、单飞、单次合成和费用计入原范围；取消、来源修改、停止nonce与epoch变化贯穿父任务/TTS/媒体。重启不恢复旧范围。实现先修改Schema并生成，之后修改消费者。按组件运行存储/守门/宿主/UI及Windows真实IPC/输出测试，优先本地Qwen；构建缓存使用E盘约定目录。更新运行版前完成验证，保持用户数据与密钥。
