## Context
沿用上一轮 ProgramCommand/ProgramView、共享幂等账本和原生控制传输；不新增协议。原面板的本地进度与手工五面归位退出生产入口。
## Goals / Non-Goals
提供真实桌面消费者。仍为人工辅助单轮，不自动审批/播放，不补硬件完成证据或五面机器生产者。
## Decisions
ControlClient 增加严格节目解析、已生成契约类型和有界命令校验。面板用引擎 entered/confirmed/request/candidate 展示，关联本段候选播放时必须显式选定精确哈希；确认前重新读状态，再发送 confirm 并读回，不本地递增。所有变更先禁用，错误保留不确定状态，成功只读刷新后才能再操作；生成结果使用有界只读轮询，不重发。P0 仍使用既有独立入口和 generation token 废弃迟到回调。

商品配置继续兼容旧1–16段。新UI提供四段字段及明确清空旧提纲转换；四段长度超限须编辑，不截断。草稿仍经既有数据库和发布操作持久化。刷新与重连可显示引擎既有进度，提示文本仅从已发布同快照草稿读取；不可把未知提示当作当前引擎内容。
## Risks / Trade-offs
- 命令ACK丢失 → 不自动重试，明确提示刷新；下一段仍有引擎状态和序号守门。
- 数据库旧草稿不是四段 → 明确转换、保存和发布。
- 引擎暂停后无归位能力 → 先明确静音结束旧轮，再启动新轮，不伪造恢复。
## Migration Plan
新增桌面消费者，无DB迁移。仅源码和构建交付，本轮不替换安装文件。
