## 背景

§284 要求「至少 100 个**贴近真实直播的问题**」。§5.9 只承认三条**题集**来源，且 ADR 0033 规定
本仓库**不生成**题集内容。使用者提供的 LiveChat 是真实直播对话语料，能直接命中「贴近真实直播的问题」
的**措辞与语境**——但它既不是「按场景编写」的题集，也不是「坏案例回流」，若被当作第四条题集来源，
就突破了 §5.9 与 ADR 0033。

## 决策

### 1. 语料是「素材」，不是第四条题集来源

§5.9 的三条来源描述的是**题集如何产生**；外部语料描述的是**问题措辞从哪来**。二者层次不同：
素材是**上游输入**，题集是**下游产物**。因此不改 §5.9 的三条来源，而是**定义素材层**：
素材供措辞与语境，题集仍由三条来源产生（人工编写或经确认的候提升）。

### 2. 候选仍然只能经具名人工确认进入题集

候选池**不进仓库**。要成为 `tests/rag-golden/` 的用例，仍走**既有的**机制：`origin.kind = promoted`
+ 非空 `confirmer`（该机制已在 W30/W31/ADR 0033 落地，无需改动）。这样「机器提议」与「人工确认」
的边界不变，素材只是**扩大了提议的来源**。

### 3. 不自动分类到 §5.9 类别（一次被实测推翻的尝试）

初版曾按词映射类别：`连麦/上麦/管理` → `privilege_escalation`，`给你` → `injection`。
**抽样推翻了它**：

- `injection` 档几乎全是打赏互动（「给你批个华子」「我给你花了好几毛」）；
- `privilege_escalation` 96 条里真正求权限的不到 10 条——「上麦/连麦」是**正常直播功能**，不是越权。

结论：**单句观众评论无法可靠区分 §5.9 的非 `normal_answer` 类别**。故整段移除类别映射，工具只输出
**原始信号词**（`question` / `term:连麦` / `may-be-personal` …），类别**100% 交人工**。这条否证本身
是产物的一部分：它说明**该语料可靠覆盖的只有「问题措辞」**，其余类别需另行编写。

### 4. 零仓库代码：数据在仓库外，且读 pickle 需要 Python

- 语料 459M + 候选 50M，**不应入库**；
- 仓库 Rust 侧读 pickle 需**新增依赖**（违反「零新增依赖」），而工具只需 std 的 Python 即可完成；
- 与 ADR 0033「不新增证据目录/命令」一致。

故摄取与提取工具留在**落地区**（`E:/nai-external/livechat/`），仓库只登记**来源与边界**。

### 5. 摄取先验后读

`.pk` 是 pickle，反序列化即**任意代码执行**。核验**不先 `pickle.load`**：先 `pickletools.genops`
枚举 opcode，仅当每个 opcode 属于**数据白名单**时才加载。白名单不含任何可命名可调用者的 opcode，
故结构上无法执行代码。自检**非空洞**（含 `os.system` 的 pickle 被具名拒绝）。
解压先校验成员路径（拒绝 `..`/绝对路径/盘符）防 zip-slip。

### 6. 来源须可追溯

登记逐文件 SHA-256、出处、许可、结构与规模，使「问题措辞从哪来」在需要时可回溯——与 W47 的 SBOM
同属「记录事实，不认证结果」。

## 否决方案

| 方案 | 否决理由 |
| --- | --- |
| 把语料当第四条题集来源写进 §5.9 | 改写设计规格的验收口径，超出本仓库授权；且混淆素材层与题集层 |
| 把候选池提交进仓库 | 候选非真值；ADR 0033 明令仓库不生成题内容 |
| 用候选自动生成题集 | §5.9 要求人工确认；自动生成会让黄金集自己给自己出题（ADR 0033 已否决） |
| 按词把候选自动分类到 §5.9 八类 | 实测假阳性极高（见决策 3），会造出「注入/越权」的假样本 |
| 仓库内加 xtask 命令读语料 | 需新增依赖 + 新命令 + 约定外目录；数据在仓库外，命令无对象 |
| 直接 `pickle.load` 后统计 | 反序列化即任意代码执行，先执行不可信字节码是安全缺陷 |
| 因素材到位而把 B01 升为 `implemented` | 素材不满足 §655 达标验收（题集与知识库仍未提供），登记纪律禁止升级 |

## 后果

- 「贴近真实直播的问题」的**素材来源**有了登记与边界，且与既有题集机制（`promoted` + `confirmer`）无缝衔接。
- 语料**不会**被读成题集：素材 ≠ 题集在规格、文档与 registry 三处同时写明。
- B01 结论**不变**（`blocked`）：§④ 真实知识库与参考答案仍是外部投入。
- 遗留：100 题内容与真实知识库仍未接；本语料对非 `normal_answer` 类别覆盖有限，需另行编写。
