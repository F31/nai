# Design

当前768/49帧配置有9帧运动历史，新增40帧需38400个24kHz样本（1.6秒）。worker通过缓存历史音频生成特征；不得每块调用render重置运动，也不得对每块独立librosa重采样制造边界。此轮只实现输入层，块几何来自已验证Ready的block_frames，采样/画面格式仍24000/25。同步回调天然背压，一个待装配块，消费失败或网络/EOS失败取消父Operation。完整块是临时计算输入，不是播放授权；尾块和Completed只在供应商回执验证后产生。未来协议需要独立原始PCM传输、序号/摘要/累计样本、EOS和取消，Python维护重采样及motion状态；本切片不假定这些已经实现。
