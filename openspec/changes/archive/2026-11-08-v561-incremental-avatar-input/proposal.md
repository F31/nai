# Proposal

## Why
当前形象工作进程一次读取完整PCM并整段重采样，真实TTS必须结束后才能启动视频。本任务先交付真实HTTP块到固定推理块的有界输入层，后续以明确的协议和有状态重采样接入GPU，避免直接重置模型造成接缝或将提前计算冒充供应商完成。

## What Changes
新增Rust固定几何音频块装配与真实CosyVoice输入入口，满块可提前交给同步计算消费者；尾块只在校验EOS后交付。所有块携带epoch、任务及样本偏移，错误立即取消已交付的临时计算。无自动重试、不创建第二TTS或播放许可。

## Impact
仅Rust内部输入层及定向测试。当前worker协议6、安装版和媒体播放路径不变。
