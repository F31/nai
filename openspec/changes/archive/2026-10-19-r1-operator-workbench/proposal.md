# Proposal

## Why
R1 的审批、升级计划与作业状态接口已有实现，但实际桌面缺少最终文本展示和升级查询入口。继续扩展判定面不能让操作员完成这些操作；本轮把已有能力交付到真实页面。

## What Changes
- 审批列表展示最终文本；缺失时显示现有具名缺口，保留哈希身份与二次确认。
- 桌面提交包清单查询真实成本、按作业 id 查询持久化状态；查询失败清除旧结果，断连不保留旧连接结果。
- 制定 R1 产品闭环优先级，明确仓内实现与外部认证的边界。

## Capabilities
### New Capabilities
无。
### Modified Capabilities
- `local-control-surface`: 审批文本展示与可交互的只读升级面板。

## Impact
V3.11 §425/§662、§14/§15；关联 O02/O05，不新增 D 编号。影响 desktop、既有 UI 测试与交付计划；复用现有 HTTP 契约和客户端，零新增依赖。不提升验收状态。
