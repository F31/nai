# Proposal: W153 — 指针的域收口：引用式链接与锚点

## Why

W151 立的判据、W152 扩的域，都留了同一句话：**「锚点与引用式链接在域外，理由是全仓 0 条样本」**。
ADR 0125 的残余 1 与残余 2 就是这两条。它们的形状比「还没写」更糟——**判据对它们完全无感**：
一旦有人写下 `[x]: url`，那条指针不论指向哪里都判不绿也判不红，直接不存在。

W153 先量（tracked **1460** / 文档 **996**）：

| 形状 | 代码段外 | 代码段内 |
| --- | --- | --- |
| 内联链接 | 962（其中相对 924） | 12 |
| 引用式定义行 `[x]: url` | **0** | 0 |
| 引用式使用（label 命中定义） | **0** | 0 |
| 引用式使用 `[x][y]` 形态（不论有无定义） | **6** | 0 |
| 纯锚点 `[x](#a)` | **0** | 0 |
| `file.md#anchor` | **0** | 0 |
| HTML 锚点 `<a name=` | 0 | — |

**第二行的 0 与第四行的 6 合起来才是本轮的关键事实**：定义行确实一条都没有，但「用了引用式写法」
的有 6 处——按「有定义才算」的口径量，这 6 处会被算成 0，于是「引用式链接没人用」这个假结论
会一直立着。量法错了，结论就反了。

逐个核实这 6 处（V3.2 三处、V3.5 一处、V2.3 两处）：**它们不是断链，是引注写法与 markdown
引用式语法撞车**。同一份文档的资料清单写成 `- [S2] …`（V2.3 是 `- **[S1] …**`），不是 `[S2]: url`；
V3.2 第 1032 行自己就用 `（[S1]、[S4]–[S16]）` 这种并列写法。`[S2][S3]` 在 CommonMark 里因为
`S3` 无定义而退化成**字面文本**，读者看到的正是作者写的字 ⇒ **没有读者可见的缺陷**。

这条实测推翻了我在设计判据时的假设（「无定义的引用式使用 = 笔误」）。假设被推翻就得改规则，
不能为了保住规则去改记录：把 6 处判红，等于要求三份已发布的设计文档改排版。

## What Changes

- **判据的域收口为一条原则**：**域 = 「markdown 认为是链接的东西」，不是「看起来像链接的东西」**。
  - 定义行 `[label]: url` **进域**：URL 走与内联链接**同一套**可达性判定（一个 `targetErrorOf`，
    两个调用点）。这是本轮真正关掉的盲区。
  - 引用式使用 `[text][label]`：label **有本文件定义** ⇒ 它**是**链接，落点由定义那一侧判；
    label **无定义** ⇒ CommonMark 降级为字面文本 ⇒ **不是指针，只数不判**。计数单独一列
    （`undefinedReferences`），因为它就是这条域边界的可见形状。
  - **带 `#` 碎片的指针改为「拒绝」**：`[x](#a)` 与 `[x](b.md#a)` **都是** inline link（在域内），
    但碎片怎么生成由渲染器决定 ⇒ 判据无法校准 ⇒ 拒绝。带文件名的：文件部分照判，碎片单独失败
    （两个缺陷两条话，合并成一条会让修的人只改一半）。
  - shortcut `[label]` 仍在域外：与普通方括号字形不可区分。
- **规格**：`Every relative pointer …` 这条 Requirement 用 `MODIFIED` 表达（名字不变，域与规则变了）。
- **不订正 6 处**：核实后判定它们不是缺陷，登记在报告 §四与 ADR 0127，正文一字不动。
- **如实登记**：定义行与锚点今天仍是 **0** 条真实样本 ⇒ 这两条规则的全部证据是**合成样本 +
  8 条注入**。它们不是「已被真实语料检验的判据」，只是「已经会喊的判据」。

## Impact

- 受影响代码：`scripts/contracts/doc-links.mjs`（新增 `normalizeLabelOf` /
  `referenceDefinitionsOf` / `referenceUsagesOf`，抽出 `targetErrorOf` / `pointerErrorsOf`）、
  `tests/contracts/doc-links.test.mjs`（11 → 16 条用例）。
- 不受影响的记录：**零份文档被改**。这是本轮与 W151/W152 的形态差别——前两轮都是「先量出一批红
  再修」，本轮量出来的 6 处**不是红**，所以唯一的产出是判据本身。
- 不受影响的门控登记：改的是**已有**测试文件与已有站点，`engineering_checks` 与
  `TEST_REGISTRATION_SITES` 都不新增条目。
- 一并处置：ADR 0125 的残余 1（锚点未判）与残余 2（定义行未判）由 ADR 0127 结清，
  ADR 0125 末尾追加勘误段指过来（已发布记录，不就地改写决策正文）。
