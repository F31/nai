# Proposal: W151 — 文档内部指针的可达性

## Why

W150 的 ADR 0124 留了四条残余。本轮先量第一条（归档 `tasks.md` 的段结构），它不是一条能立的判据：
147 份里 **39 份没有 `## ` 段**（任务平铺）、段标题 **375 种**（**311 种只出现一次**）、
**52 个段内 0 条任务**。⇒「结构」没有统一形状，能写的只剩「非空 + 全勾选」，而后者已由
`validate --archived` 覆盖。照抄立项会写出今天必然全绿、没有真实失效模式的判据。于是转向同族的
下一格，那一格有**现成的红**：

| 事实 | 值 |
| --- | --- |
| `docs/**/*.md`（已跟踪） | **328**，链接 **831**（相对 **794** / 外部 37 / 纯锚点 0） |
| 相对链接走不到的 | **36**（断链 **32** + 通配 **4**），跨 **25** 份文件，全是已发布记录 |
| 类型 | 缺 `../` **15**、多一层 `docs/` **4**、基线文件名缺 `../` **5**、目录深度 **2**、兄弟文档写成子目录 **2**、日期笔误 **2**、ADR 文件名笔误 **1**、通配 **4**、指向从未存在的文件 **8** |
| 现有门控的信号 | **零**——`--strict` / `--archived` / registry / 各契约判据都不解析 markdown 链接 |

这些指针是「记录的记录」：报告指向 ADR、ADR 指向基线、报告指向归档变更。断链不报错、不阻塞，
只让读者落在空处——正是「缺了没人喊」的形状。

## What Changes

- 新增 `scripts/contracts/doc-links.mjs`：`linkTargetsOf`（行内链接扫描，含图片）、
  `isExternalTarget` / `resolveTargetOf`（域与解析的唯一出处）、`docLinkErrors`（纯函数，入参可注入）。
  规则四条：相对链接的落点 MUST 在 `.git/index` 里；**目录算存在**（前缀下有已跟踪文件）；
  **通配直接失败**（`*`/`?` 不是指针）；外部链接与纯锚点在域外（域边界写进 ADR 0125）。
- 新增 `tests/contracts/doc-links.test.mjs`：9 条用例，三层独立输入域（真实语料 / 合成样本 / 域函数）。
- 修 **36 处**：机械可定的就地订正 URL；指向**从未存在的文件**的 8 处降级为纯文本并在各自 ADR
  追加具名勘误段（MUST NOT 猜一个编号上去）。
- 接线：`engineering_checks` 加一步（纯静态，不需 protoc）+ `TEST_REGISTRATION_SITES` 增加
  `xtask-doc-links`（`tier: portable`）+ 逐字清单「十九个」→「二十个」。
- ADR 0125：裁定「指针订正」的边界——URL 就地订正不构成「改写历史记录」，死链降级 + 勘误段
  才是不可复原情形的处置。

## Impact

- 判据纯静态（读索引与 markdown 文本），不编译、不需要 protoc，跑在 `engineering_checks` 里。
- **首跑有 36 条红**，修复后为绿：这不是「先绿后绿」的装饰判据，它的红是真的。
- 不改任何决策正文、不改任何判据的既有口径；6 份 ADR 各追加一段勘误，正文一字未动。
- 域边界（未跟踪文件、锚点、引用式定义、外部链接）具名写进报告 §五，MUST NOT 当作「已覆盖」。
