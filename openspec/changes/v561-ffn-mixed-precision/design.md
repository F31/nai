# Design
F04c诊断允许同一实例依次留存BF16与FP8单块算子trace；各自先维护预热，trace不记录Tensor内容，且不与像素留存混用。FP8 trace仍处于原作用域，结束恢复BF16并核对帧hash。只按实际kernel事件汇总，CPU归因/嵌套范围不得重复相加；profiler墙钟不作为实时性能通过依据。输出使用新路径并拒绝覆盖，独立保留未插桩热测。
候选只覆盖两层FFN Linear；GELU、归一化、注意力、VAE和四步语义不变。意向为静态权重量化、逐调用动态激活量化、FP32缩放/累加、BF16输出，不启用快速累加，不在不支持时静默回退称成功。正式候选尚未实现。

第一门使用当前配置推导token数和模型dim/ffn_dim，随机输入仅做显式硬件探针，不装载形象模型。记录实际torch/CUDA/GPU能力、API执行、非有限值、相对L2及交错BF16/FP8事件耗时；包含激活amax/缩放/转换，权重预处理单列。输出拒绝覆盖，输入配置有界、内存按显式字节预算准入、运行45秒硬期限、重复次数有限。当前运行包不依赖探针。

后续门顺序：实际层捕获输入/输出验证误差及异常尾值；固定随机源的整段图像/口型/身份/衣物与边界连续性人工确认；不含profiler/捕获I/O的原三句性能门槛；取消/期限/单GPU/OBS长稳。随机矩阵误差或PSNR不能替代主观质量，若不能像素等价则没有自动质量通过。所有新模型精度必须明确标为候选，经正式配置契约及维护激活后才可进入产品。

硬件首探发现宽输入的eager激活量化约1.8ms，核心FP8 GEMM约0.6ms。增加显式compile-activation-quantization候选，仅编译量化函数，不改权重/模型；外层原维护240秒硬退出，各层正式测量仍配置45秒。记录实际新图/内核及量化是否与eager一致。全部编译/驱动/临时缓存显式沿E盘数据目录，不写全局环境或依赖。模型质量门槛不因量化函数编译通过而放宽。

F03复用profile_avatar_gpu生命周期，仅一个已有PCM真实块。显式层索引/采样步索引和字节/重复上限；预热后在240秒维护捕获阶段，用禁用Dynamo的pre-hook取得实际Tensor，拒绝FakeTensor。hook不改输入或输出，结束恢复。代表层可选首/中/末及首/末采样步；局部样本不是覆盖全部层。随后以原FFN权重执行BF16参考和两层FP8/BF16输出候选，GELU调用原模块；候选结果不进入人像渲染。静态FP8权重限于当前诊断模型，复用量化算子，完整两层激活量化计入时间，逐样本记录误差，退出释放张量。全部帧回归和真实音画质量仍为独立门。

首轮实际编译模块未执行后加hook，样本数不足明确失败。当前Dynamo skip_nnmodule_hook_guards=True，因此采集阶段显式将指定层临时替换为同权重原始模块，退出恢复原编译wrapper，不改全局guard或重置所有编译缓存。采样为真实权重/真实音频驱动的受控eager层输入，可能与编译融合路径有数值差异；不得据采集阶段墙钟授生产性能或称完全复现编译路径。正常前后基线仍走原编译块。

F04完整候选以显式层列表/静态权重缓存字节预算安装同一类型FP8 FFN模块，注册量化权重和缩放buffer并复用原GELU/bias；forward只做可编译Tensor运算，FP32缩放、非fast累加、BF16输出。对指定块重新torch.compile(dynamic=False)，保持原eager SDPA与VAE；维护/热测间保持相同实例，回归前恢复原FFN和原编译块。安装预先检查全部资源/结构，异常回滚，源权重版本变化拒绝。候选片段原始帧与同PCM基线保存，编码预览不替代原始像素指标；有差异必须人工确认口型/身份/衣物/跨块，质量门前不启用生产。
