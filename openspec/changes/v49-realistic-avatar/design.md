# 设计

## 真人视频优先及对照路线

用户优先选择或导入有权使用的真人视频、选择已配置声音并私有预览；照片作为能力独立验证，素材质量不足给出可执行提示。视频底版只提供已拍摄外观及动作，语音驱动嘴型，任意表情/全身动作和人声直驱均为独立能力。视频/模型/音频/许可绑定版本与可撤销身份，预处理隔离有界，正常不暴露内部文件与参数。

吸收 CreatorBox 公开展示的素材选择、实时插播和音画统计思路，不推断其受保护模型实现。可选外部服务只有在使用许可、接口、身份、取消、回执、音画出口与受控停止实测合格后才进入独立 profile；外部 Python 服务不等于 NativeOnnx，也不隐式修改正式 Windows 运行包限制。服务若能直接外发而无法受 keeper 控制，仅可在其授权范围内隔离预览。CreatorBox 对照非唯一依赖，失败不阻断自主后端。

渲染以样本时钟、会话/epoch/帧序和 PTS 对齐；整句音频预计算与流式首包分别测量，缓存绑定音频/形象/模型及配置版本；预览不反压生产。待机、声音、画面、字幕和 OBS 音视频分别观测，缺证据为未知。首个验收采用合法真人视频、本地 Qwen、单句真实音画，随后连续待机/讲解、插问与真人接管、OBS 和分级长稳；不得以模型独立 FPS 或 2D 占位当整链通过。

研究性能优化先缓存固定真人底版逐帧定位结果：限 120 帧和固定尺寸、视频/定位模型/模型配置/定位代码及运行环境哈希绑定，失配或损坏不采用；不保存面部图像或音频，不将研究缓存视为使用权或输出授权。对照首轮和缓存命中的时间、逐帧差异及用户观感；正式实现另绑定形象版本、许可、撤权与生命周期，研究脚本不能直接成为正式缓存。

输入为经用户确认的照片或真人视频、已许可的声音和显式范围。形象制作过程独立于直播工作台；素材、模型、推理与输出均绑定不可变身份。公共链路由可信 root 检查工作区、内容、形象身份、授权范围及撤销水位；实际媒体帧及 PCM 通过独立有界媒体通道，不经 JSON 或 Protobuf 载荷传输。

首选实验候选为 MuseTalk 1.5：官方支持图片或视频与语音，提供实时推理示例；声音驱动嘴部不等同于全身动作或任意指令表演。项目声明代码 MIT、权重可商业使用，依赖模型及预处理组件须逐个核验；测试样例不得作为生产素材。RTX 5090 Laptop 约 24 GB 显存只说明硬件可进入验证，不构成支持或性能结论。图片真实性、可用姿态、头部与待机质量须实际人工评估；如静态照片不足，明确要求用户提供授权的视频，不以合成占位声称真人效果。

隔离研究环境和所有缓存存放 `E:\projects\nai\target-windows`；不会把照片或语音上传外部服务。Python 推理实验仅研究验证，正式 Windows 运行包须采用符合项目约束的原生运行时或通过明确批准的外部服务，不将实验脚本伪装成可发布组件。研究环境不写入用户业务库，权重/模型不提交仓库。

媒体执行保持样本时轴与实际提交游标绑定；帧队列、预取、超时和取消有界。失联、超期、撤权、真人接管和停止独立终止输出；不以渲染成功证明播放完成。模型失败显示 Unavailable，禁止自动复播或悄然切成伪真人画面。

验证顺序：依赖和权利闭包核查；隔离真实模型照片+语音及性能记录；选定生产宿主和生成契约；实现媒体、授权与取消故障测试；桌面私有预览；Windows 公共输出与 OBS 录制、长稳和真人接管验收。

稳态帧率与启动分开记录。研究探针可在时钟开始前预填有限帧，预填等待不计入 60 秒窗口；窗口内仍丢弃过期帧，不用旧帧填补。达到研究比例只说明预录音频特征下的模拟时钟，不代表硬件播放、OBS 或公共输出通过。未达比例时不得把该后端接进公共输出。

本机设备时钟只消费已经稳住的研究帧流。预热和 8 帧预填完成后再打开默认播放设备，避免冷启动占住声卡。帧序号只由 WASAPI 已播放的源样本决定，提交游标只记录、不选帧。同一条实验写入由现有公共执行栅栏的租约续期控制；栅栏失效、停止或租约中断后不再提交音频，也不再呈现帧。这条链路使用门控要求的 512×288 夹具身份，不批准 960×540 研究像素，不推流，不进入正式 keeper，也不把 Python 研究进程变成生产渲染器。研究桥可以在同一条 WASAPI 流上暂停：Stop 不调用 Reset，暂停期间已播放样本和提交样本保持不动，外部租约继续续期，恢复后仍按已播放样本选帧。OBS 和平台输出仍不在这条链路里。

## 与个人模式共同适用的架构与完成标准

与 `v52-personal-live-workbench` 的“共同适用的架构与完成标准”一致：职责按领域、适配、媒体、存储与组合根分离；核心只依赖契约/端口，新增渲染模型按相同能力接口接入并以独立消费者或第二个实际实现核验替换边界。研究脚本不进入生产依赖；可选模型不选则不启动，新增宿主/依赖需记录资源、故障和 profile 成本。使用有界队列和取消，P0 独立于模型与图形锁；大文件不是机械拆分理由。

日常只测试改动闭包及相关契约/IPC/媒体取消故障；发布组合另执行完整适用测试及真实人员体验。在同机 Qwen＋写实 Avatar＋工作台＋所选直播软件组合下测启动、首音、端到端帧率与卡顿、音画同步、停止响应、CPU/RAM/VRAM峰值与释放，并逐级执行适用长稳；记录版本、设备、负载、样本、阈值与失败。无实测不得宣称性能或用户体验达标，不能通过关闭授权/停止等守门换取帧率。


## 公共输出音频时钟接入边界

宿主接受设备时钟观测的条件是：它绑定同一条状态的输出实例和准备身份，会话格式有效，观测代次等于批准该句的租约代次，流代次和设备频率非零，采样率为 24 kHz，已播放样本不超过该句已提交的源样本上限，也不超过提交游标和片段长度。这个上限可以小于整段长度，并且不能超过片段长度。没有回执的状态仍拒绝该字段。公共状态没有单独的 cue 字段，宿主把该状态上的提交游标当作这条状态能给出的上限。实验流把该句已经提交的源样本数当作上限。同一条受控实验流在确认设备位置为零后公布本流代次，并在驱动循环里把这次 WASAPI `IAudioClock` 读到的频率和原始位置与已播放源样本一起发布。用这些读数填出的观测走上面同一条规则。公共 CPAL 播放（`nai-audio-cpal::open_controlled`）仍然只提供回调提交游标，不读 `IAudioClock`，也不填写观测。

设备流建立时确认零点。恢复或重建设备流必须取下一流代次并新建游标，不继承旧位置。静音实测按这个顺序打开两条流：第一条停止后，下一条用上一流代次算出代次 2，并在自己的设备位置仍为零时启动，不拷贝第一条停下时的位置。句子开始前实验栅栏不放开。这段时间设备位置继续前进，已播放样本和提交样本保持 0；放开后该句只从 cue 起点计样本。句子进行中插入静音时不停止设备流。音频线程注意到静音之后，已播放样本停在当时该句已提交的上限，提交样本不再增加，设备位置继续前进；这段静音结束后已播放样本再超过该上限。暂停仍停止流并冻结时钟，不用于这段静音。重放已经用过的租约会让该租约失效并停掉同一条实验流。流退出时已提交样本不再增加，已播放样本不超过这个提交上限；退出后再等一段时间，设备位置也不再前进。取消会停住时钟，和句中静音不是同一条路径。实验流另外公布第一段 cue 的设备帧起点、终点和已提交区间数。句子开始前区间数为 0，起点和终点都是 0，已播放和提交保持 0。放开后区间数到 1，起点晚于前置播放位置折成的设备帧。句中静音不恢复时不增加第二段。音频线程注意到静音后，起点不变，终点只含注意到之前已经提交的缓冲区，已播放停在这段区间折成的源样本。终点之后设备位置继续前进，已播放不再增加。公共状态没有起点或终点字段。回调提交上界与硬件观测分开记录：硬件位置单调、频率和身份一致且不得超过已提交帧；异常、撤销及停止不再继续提交。设备失联已接到公共执行路径。实际设备位置不可用时必须明确报告 unavailable，不得降级成提交位置或墙钟并声称同步。

根与宿主控制面只传递有界时钟元数据及状态，媒体 PCM/帧继续走独立受控通道。先在 `schemas/workbench/foundation.proto` 明确来源、流代次、设备播放位置及有效性，再生成并检查跨语言契约；保留提交位置的原含义，不把设备观察当作扬声器声学完成或 PlaybackAck。输出目标、租约、授权和身份复检不因时钟连接而放宽。Windows 公共执行用同一条受控 WASAPI 流填写设备时钟观测，并用 `PlayedFrameBoard` 按已播放源样本选择当前帧；提交游标不作为选帧输入。时钟尚未确认时画面安全待机。`PlayedFrameBoard` 按已播放源样本选择当前帧：截止时间前到达、且当时尚未被播过的帧留在最多 16 帧的队列里；迟到帧丢弃且不追播；没有可显示帧、代次不符、已播放位置回退或撤销时返回安全待机。它不保存像素，不读取提交游标，也不调用研究渲染。字幕仍按提交游标决定是否可见。设备时钟/画面进度可观测但不能授予播放权限。流代次、撤销、停止已接到这条公共执行路径。探测端失败时理由为 DEVICE_LOST，清空设备时钟观测并撤销选帧，宿主拒绝仍带着旧观测的失联状态。Windows 默认输出上一次静音 PCM 加内置 2D 的公共执行里，设备时钟成立，当前帧源样本 8000，已播放 8601，提交 9840，提交窗口超前为真。该次不是 OBS 或平台验收。公共执行用同一条受控流上已绑定的第一段 cue 设备帧区间把设备位置映射为句内源样本后再选帧。区间尚未成立以及区间前后的静音不推进该句。取消或 DEVICE_LOST 后拒绝映射。隔离的同流 WASAPI 实验后端在同一 AudioClient 上写入并读取 IAudioClock。未激活时只写静音。门控撤销后不再提交。关闭走有界 stop_within。该后端不授予输出授权，也不替换 CPAL open_controlled。实验后端只接受最多 480000 个 24 kHz 单声道样本。空或超限在打开设备前拒绝。写入或时钟故障撤销一次性栅栏。过期租约不能再激活。失败后用新栅栏和下一流代次再开。隔离 Windows 子进程卡住时，父进程在期限内强制结束该进程。等待超时保留子进程所有权。进程退出不是硬件静音。本地单次租约最长 500ms，不续租；到期视为失联并撤销，同一栅栏不能再激活。外部受控武装状态不在本地到期。武装后的实验写入在暂存前和提交前消费调用方的无阻塞租约回调。回调失效则撤销并停止提交，该停止不是设备故障。便捷入口对外部受控栅栏返回 CLOCK_PROBE_EXTERNAL_FENCE_REQUIRED。探测析构最多等待 500ms；超时脱离线程所有权，该超时不是硬件静音。撤销后已提交游标保持原值，新写入拒绝；该保持不是操作系统缓冲区被撤回，也不是硬件静音。暂停路径在发布观测前同样消费外部租约；失效则撤销并停止观测发布，该停止不是设备故障。事件等待返回后先检查停止再消费同一外部租约，才允许发布观测；等待上限内仍可能跑完当前等待。OBS 检测分开报告进程、场景/来源、窗口捕获、声音路由和实际信号；未观察为未知。进程存在或安装路径存在不得标接入成功。窗口捕获或虚拟摄像头不得当作公共音轨或平台开播。

频率换算、超过提交、回退和拒绝旧代次已有确定性单测。Windows 静音硬件验证了同一条实验流的观测、停止后按下一流代次重开、句子开始前和句中时钟仍在走的静音都不推进该句，观测代次必须等于批准该句的租约代次，已播放样本不得超过该句已提交的源样本数，以及重放旧租约后提交停住、已播放不超过当时上限、流退出后设备位置停住，以及第一段 cue 的设备帧区间在起点之前和终点之后都不增加已播放。已播放源样本选帧已有确定性单测，公共窗口按映射后的句内源样本选帧。这些静音结果不证明公共 CPAL 输出接线或对口型。授权本地 Qwen 与隔离 OBS 的设备时钟证据见后文。

研究进程在本机分开记录了两路重叠、官方 `decode_latents` 串行和 400 毫秒语音特征。单独两路重叠 100 帧墙钟 4.86 秒，48.6 毫秒/帧，预填 8 帧 0.468 秒，没有达到 32 毫秒。同一进程的串行是 100 帧墙钟 4.265 秒，42.65 毫秒/帧；紧接着的两路重叠窗口是 3.016 秒，30.16 毫秒/帧，其 UNet 事件仍为 2.273 秒。32 毫秒和 0.8 秒两条线都不放宽。研究稳态继续使用官方解码的串行批次，两路时间表只留在测量脚本里。400 毫秒特征在另一个进程里耗时 0.027512 秒，得到 12 帧，与整文件第一帧的最大绝对差是 2.359375，稳态批次仍用整文件特征。本地 Qwen 与重叠同机的一次请求返回 200、69164 字节、5.219 秒，当时重叠窗口是 47.81 毫秒/帧。60 秒真实播放没有跑。定位缓存命中，参考运行脚本和缓存都没有改写。这些数字只属于研究计时，公共窗口按映射后的句内源样本选帧。

同一研究进程随后在官方解码串行路径上对照了合成尺寸。潜变量仍来自 960×540 人脸裁剪，512×288 只缩小画面、人脸框和下颌掩码。定位缓存命中，参考运行脚本和缓存都没有改写。960×540 的 100 帧墙钟 4.078 秒，40.78 毫秒/帧；512×288 的 100 帧墙钟 3.187 秒，31.87 毫秒/帧。UNet 事件 1.197 秒对 0.993 秒，解码 1.748 秒对 1.964 秒，融合 1.154 秒对 0.220 秒。解码没有变快。960 窗口开始前显卡是 225 MHz、利用率 0%，512 窗口在前一次测量之后。31.87 比 32 少 0.13 毫秒，小于同尺寸串行在相邻运行之间的波动，所以这一窗不改研究时间表，32 毫秒线也不放宽。没有打开声卡，没有请求语音，没有跑 60 秒播放。

同一条串行路径随后把 512×288 融合分开重复。顺序是一次 512、一次计入的 960×540、再一次 512、然后再重复一次 512，每次计入前丢掉两批。三次 512 的 100 帧墙钟是 4.766、4.797、4.875 秒，合 47.66、47.97、48.75 毫秒/帧；融合是 0.638、0.689、0.642 秒。中间 960 是 6.344 秒，63.44 毫秒/帧，融合 2.251 秒。不紧跟 960 与紧跟 960 的 512 墙钟相差 0.31 毫秒。上一窗的 31.87 毫秒/帧和 0.220 秒融合没有再次出现。这一进程的 UNet 事件是 2.336 到 2.439 秒。三次 512 都高于 32 毫秒，研究时间表不变，32 毫秒线不放宽。没有打开声卡，没有请求语音，没有跑 60 秒播放。

Windows 正式公共画面后端选择内置几何 2D（BuiltinAvatar / nai-media-core）。依据是隔离研究里 MuseTalk 1.5 三次 512 墙钟 47.66、47.97、48.75 毫秒/帧高于 32 毫秒、Python 不得进入正式运行包、没有原生 ONNX 实现、也没有已批准的外部服务适配。该选择不关闭 1.3.1 写实样片，也不把 2D 写成写实生产。

生产宿主装配前，形象身份、版本、运行状态、动作和有界媒体走 `schemas/domain/media.proto` 的 `CharacterIdentity`、`CharacterRuntimeView` 和 `CharacterBoundedMedia`。结构校验在 `nai-contracts`。公共尺寸钉在 512×288、24 kHz 单声道、每帧 800 样本、最多 480000 样本。PCM 和像素仍走独立通道。该契约不装配独立宿主，也不把设置页选择写成公共执行。

独立私有预览宿主落在 `nai-media-core`。它消费上述契约，打开即为 Preview，按已播放源样本选帧（每帧 800，上限 480000）。取消进入 Revoked，失联进入 Lost；此后视图不含动作或媒体，时钟推进被拒绝。该宿主不发出 PublicActive，不打开声卡，不接入公共 keeper，预览不是播放许可。工作台接入见后文。

许可绑定落在 `nai-media-core` 的内存账本。已准入许可的 `package_sha256` 与 `rights_sha256` 必须与 `CharacterIdentity` 一致才打开预览宿主。撤权取消宿主并清空动作/媒体引用，该许可进入撤销集合。恢复已撤权利或旧 epoch 被拒绝。该绑定不发出 PublicActive，也不是播放许可。工作台接入见后文。

工作台接入落在 `nai-media-core` 的 `CharacterWorkbench`。一键生成绑定已准入许可并打开私有预览。预览动作只允许 idle 与 speak，其他动作返回 UNSUPPORTED_ACTION。选择记录工作区形象，状态仍为 Preview。切换选择释放当前预览，不把原许可记入撤销。公共输出状态的后端固定为 builtin-2d。该接入不发出 PublicActive，不替换公共 keeper，选择不是播放许可。视频导入已接入工作台私有草稿与源预览。虚拟摄像头和独立音轨按目的地分别报告连接、源与真实信号，公共画面仍走窗口；外部渲染服务仍开放。
