# 真人效果数字人主线

## 目的与范围
按用户调整优先级，面向真人照片/视频和语音驱动的自然口型、表情与直播输出，覆盖 V4.9 §V4.9-3、V48-05/07 及相关 INV。基础三层开闭嘴组包不再作为前置里程碑；已有内核留作历史资产。照片、声音和许可保持本地隔离，公共使用必须复检身份、许可、场次和执行租约。

以真人视频底版＋语音驱动口型为优先体验路径，MuseTalk 1.5 为首选验证候选；照片作为独立可选能力。先在本机隔离环境以合法视频与本地 Qwen 语音完成真实样片、延迟、画质和显存验证；再决定符合现有架构规则的 Windows 原生推理或独立外部服务。Python 仅用于离线模型制作/导出与隔离研究验证，不作为 Windows 正式运行包依赖；若未来采用 Python 外部服务 profile，须先单独 ADR 与规则裁决，不静默变更该限制。CreatorBox 仅为待明确许可、真实性能及可控边界的可选对照，不能当作已集成或已认证。模型及依赖许可、权重哈希、系统资源和运行成本必须在装配前逐项核实。整体目标见 `docs/v52-agent-avatar-creatorbox-optimization.md`。

非目标：将静态照片或简单嘴型标记为真人生成成功；宣称实时性能、动作或平台认证已完成；上传照片到第三方；变更既有数据及 ACC 状态。
