# optional-llm-pricing Specification

## Purpose
简化新增文本模型的服务配置，移除非连接必需的输入输出单价填写与确认要求；明确区分单价未知和免费，保留现有单价，并确保API测试及业务生成在未知价格下仍经过单次额度确认、预留和未知费用账本处理。

## Requirements

### Requirement: 新增模型不要求单价
系统 SHALL 允许新增文本模型不填写输入输出单价，明确记录价格未知并保留预算门控，不得将未知金额视为免费。
#### Scenario: 保存无单价模型
- **WHEN** 用户填写服务、模型及Key保存
- **THEN** 模型正常保存且单价标记未知，无需单价确认
#### Scenario: 使用未知单价模型
- **WHEN** 用户确认本次调用额度并发起请求
- **THEN** 按本次额度预留，已发送且无法计价时费用保持未知，未发送可释放
