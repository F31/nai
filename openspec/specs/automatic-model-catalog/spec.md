# automatic-model-catalog Specification

## Purpose
确保模型设置默认读取数据库中的统一平台模型，将已有工作区配置的备份、独立映射、凭据验证与中断续办作为内部有界流程执行；免除手工导入，同时保留来源数据并明确展示异常。

## Requirements

### Requirement: 模型默认加载与透明目录整理
系统 SHALL 默认读取数据库平台模型；首次整理已有工作区模型时保留全部来源、独立映射与备份，自动完成既有事务且不要求用户点击导入。
#### Scenario: 已有工作区模型
- **WHEN** 平台目录未就绪且数据库存在LLM或TTS配置
- **THEN** 自动备份并独立映射所有来源，提交后显示统一列表，不调用付费API
#### Scenario: 中断后重启
- **WHEN** 存在未完成目录整理journal
- **THEN** 沿原映射有界续办，不创建第二份迁移或覆盖来源
#### Scenario: 条件不满足
- **WHEN** 容量、活动任务或凭据验证阻止整理
- **THEN** 显示具体错误并保留原模型与journal，不宣称数据库为空
