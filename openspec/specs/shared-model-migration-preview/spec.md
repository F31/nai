# shared-model-migration-preview Specification

## Purpose
为本机共享模型安全迁移提供只读来源预览，包含活动和回收工作区中现有模型的身份、版本与冲突。预览不得解密、泄露或修改配置和凭据，结果提供稳定摘要但不表示已经迁移或可以执行；实际迁移仍需独立备份、映射、验证和恢复机制。

## Requirements

### Requirement: 迁移前来源预览
系统 SHALL 仅允许可信本机管理员只读预览各工作区及回收区的现有模型来源、版本、hash与冲突，不输出密文或Key，不调用付费API。
#### Scenario: 模型位于回收区
- **WHEN** 管理员请求共享模型迁移预览
- **THEN** 包含回收区未删除模型，清楚标记来源，不解密或移动配置

### Requirement: 无静默合并
系统 SHALL 在同名或重复ID时标记冲突并提供稳定预览hash，不能将预览视为已经完成迁移。
#### Scenario: 预览期间未确认迁移
- **WHEN** 请求只读预览
- **THEN** 原始配置、凭据与审计均未写入
