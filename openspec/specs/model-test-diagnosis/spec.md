# model-test-diagnosis Specification

## Purpose
在模型与 TTS 测试中呈现经过校验的响应和受控的请求标识，并提供不重发、不污染正常配置的受限诊断路线，使失败可定位且不泄露凭据。

## Requirements

### Requirement: 模型响应与可查询请求编号明确呈现
系统 SHALL 显式显示受校验的成功文本测试正文，并为支持跟踪的TTS请求绑定安全任务UUID；不得回显凭据或未经验证的原始响应。
#### Scenario: 文本测试成功
- **WHEN** 已取得成功且通过正文校验的测试结果
- **THEN** 页面以模型响应内容展示正文，不再次调用模型

### Requirement: 真实路径诊断不重发且不污染正常配置
诊断 MUST 仅通过受限debug原生启动选择路线，不向页面开放路由覆盖，按显式授权最多派发两次。
#### Scenario: 直连或代理请求失败或结果未知
- **WHEN** 已记录该路线派发凭证
- **THEN** 不自动重发，正常启动清除诊断覆盖，业务预演路线与用户模型不被修改
